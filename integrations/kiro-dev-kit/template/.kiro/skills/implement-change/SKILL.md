---
name: implement-change
description: Implement a requested repository feature or behavior change and verify its acceptance criteria.
---

Translate the request into observable acceptance criteria. Inspect neighboring code, interfaces, tests, and repository conventions. State a short plan for a multi-step change. Implement the complete behavior without unrelated dependency or architecture changes. Run checks appropriate to the changed behavior and required repository gates. Inspect the diff and report what works, the evidence, and any unverified integration.
