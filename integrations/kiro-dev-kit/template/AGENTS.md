# Project collaboration
Read the repository's own contribution rules and existing instructions first.
Use the outlands-developer agent for implementation, outlands-investigator
for source inspection, and a fresh outlands-reviewer chat for review.

Discover the actual build/test commands and supported runtimes from this
repository. The kit targets Python 3.15 for its own Python examples; changing an
existing project's Python requirement is a separate compatibility decision.
Preserve existing dependency locks and the user's unrelated changes.

Use .kiro/skills for recurring methods. Inspect the final diff, report meaningful
checks, and distinguish offline setup, local code checks, and live agent proof.
Store requested session handoffs under .kiro-kit/handoff.md.
