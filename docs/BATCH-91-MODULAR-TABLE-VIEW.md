# Batch 91 - Independent table-view and pagination integrity tools

Four fresh generic MIT modules use invented HVAC parts, game assets and AI/software
evaluation records. [Example themes](FICTIONAL-EXAMPLE-THEMES.md) remain unchanged.
Remaining table/grid/filter/view audit filenames and ledger entries identify concept
scope only. Original implementations, schemas/rules, customer/user data, private paths,
credentials, deployment details, operating instances and assets were not consulted.

| Independent tool | Scope |
| --- | --- |
| [Table View Contract Checker](../tools/table-view-contract-checker/README.md) | Validate typed columns, explicit scalar predicates, null ordering and row-ID tie-breakers. |
| [Filter & Sort Projection Checker](../tools/filter-sort-projection-checker/README.md) | Check claimed ordered row IDs against exact view and embedded record-snapshot pins. |
| [Pagination Coverage Reconciler](../tools/pagination-coverage-reconciler/README.md) | Reconcile page slots, boundaries and ordered coverage against a pinned validated projection. |
| [Table View Scenario Comparator](../tools/table-view-scenario-comparator/README.md) | Compare the same pinned record cases under two declared view versions. |

Exact scalar types, explicit null tests/placement, ordered sort priorities and mandatory
row-ID tie-breakers define one bounded deterministic projection contract. Complete
snapshot/view pins bind claims; wrong order cannot pass on equal membership. Pagination
plans bind validated projections and explicit sizes. Missing/extra/ambiguous page slots
withhold global coverage; invalid projections withhold page conclusions entirely. Shared
cases compare one actual embedded snapshot under two view versions; selected equality
does not establish whole-view or UI compatibility. No SQL or browser executes.

Each complete directory runs independently with Python 3.12/3.13 standard library.
Seven public MIT JSON/I/O/identity helpers are byte-pinned with origins. Known-answer,
adversarial, native Windows/Ubuntu fixtures, standalone copies and connected fictional
CLIs qualify supplied declarations. Existing collection browser/render qualification
remains separate evidence for those applications. No network, model calls or updates.

Root README, three starting workflows, theme guide, existing systems/downloads/workshops,
frozen package/future inventory plans and prior source announcements are preserved.
A new source announcement follows the index. Packaging remains deferred. Actual inputs/
reports stay private; hashes are not anonymization. Original-family/whole-drive clearance
remains incomplete.
