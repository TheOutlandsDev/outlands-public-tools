# Batch 70 - Independent quality and inspection integrity tools

Four fresh generic MIT modules use fictional HVAC air handlers, demo-unit readings,
inspection records and ordinal attempts. Future example/demo themes are limited to
[HVAC, AI and game development in this repository](FICTIONAL-EXAMPLE-THEMES.md).
No original private implementation, schema, equipment specification, operating policy,
customer/user record, path, credential or asset was consulted/selected/executed.
Original-family and whole-drive clearance remain incomplete.

| Independent tool | Scope | Evidence limit |
| --- | --- | --- |
| [Measurement Contract Checker](../tools/measurement-contract-checker/README.md) | Exact decimal readings and selected rule revisions | No calibration, equipment suitability or approval |
| [Inspection Coverage Checker](../tools/inspection-coverage-checker/README.md) | Required specimen/check pairs and declared outcomes | No physical inspection, source-byte proof or result recomputation |
| [Yield & Scrap Reconciler](../tools/yield-scrap-reconciler/README.md) | Selected dispositions and exact whole-cohort fractions | No quality target, population truth or inspection coverage |
| [Rework History Checker](../tools/rework-history-checker/README.md) | Narrow attempt/state protocol and derived dispositions | No actual repair, measurement recomputation or private route policy |

Each complete directory runs independently with Python 3.12/3.13 standard library.
Native Windows/POSIX I/O is pinned existing public MIT source. Exact normalized
snapshots count once; conflicting groups withhold every member. Invalid structures,
references or histories withhold the complete result. Valid scoped outside readings,
coverage findings and explicitly pending cohorts retain complete review diagnostics.
PASS is contract consistency, not physical quality or authority to operate.

The four-platform matrix tests source pins, known results, mandatory native fixtures,
independent copies and actual connected CLIs. Separate before/after demo readings
explicitly feed selected coverage records, invented repair/scrap events and the
derived disposition cohort: first-pass 1/3, eventual yield 2/3, scrap 1/3. Complete
records can contain outside readings; reconciled yield cannot prove inspection
coverage. No implicit latest snapshot, repair decision or real threshold is inferred.

These additions remain modular source tools outside the frozen package plan. Existing
systems, downloads, workshops and package definitions are unchanged by this pass.
No combined workbench, runtime bundle or new release asset is created. Real inputs
and reports remain private; these tools do not anonymize data or clear publication
rights. See each tool's contract, origins and validation limits before use.
