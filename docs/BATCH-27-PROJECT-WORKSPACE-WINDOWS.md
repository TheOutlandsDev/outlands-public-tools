# Project Workspace Windows hardening review

Only the existing public MIT workspace/native mechanisms and invented opaque
fixtures are selected. No original private helper, operational template,
configuration, record, credential, identifier, capture, asset or real input is
exported. TheOutlandsDev remains the MIT identity; required notices remain.
Held originals/rights and existing release assets are unchanged.

The POSIX creation body, path/source checks, template, folder/name rules and
original combined 47-method test file remain preserved. Windows gains a separate
backend for local-volume/path/reparse checks, retained native handles, bounded
binary input reads and sampled identity/name checks. Planning still creates
nothing, including when a selected source is read for validation.

Windows exclusively creates new directories and every output. Observed
directory handles are retained, short writes complete or fail, flushes are
requested and output identities/names/link counts are checked. All expected
bytes are read back. Source hard links remain allowed; output hard links are
refused. Input copies remain opaque with neutral names and size/hash records.
Platform text newline encoding, layout and summary fields remain compatible.

Local Windows/Python 3.12.7: the original six workspace methods passed; 40 new
methods had 29 passes/11 skips. Eight unavailable native link/junction cases and
three POSIX-only cases account for skips; short-name rejection ran. CI uses
Windows/Ubuntu Python 3.12/3.13, requires native Windows link/junction cases and
reports optional short-name/platform availability separately. Other versions
are unverified. Exact-commit CI/walkthrough/publication results are recorded
separately.

A separately copied two-file runtime passed 21 fresh-process scenarios: 18 direct
CLI invocations and three controlled zero-write/late-flush/interruption failures.
The prior public implementation was frozen and hash-verified before editing;
100 fictional cases matched complete layouts and bytes, including platform text
newlines. Inputs/runtime stayed unchanged and no bytecode appeared. The original
combined suite had 46 passes/one native-symlink skip locally; collection checks
had 532 passes/27 skips; 441 documentation/JSON checks passed.

Runtime/test fixtures contain invented bytes only. Real workspaces, inputs,
source mappings, private marker lists, reports, captures and finding dispositions
stay private. Publication uses exact selected-byte hashes, frozen/revised public
auditors and manual review, not pattern silence as a rights or secrecy clearance.

Read the [filesystem contract](../tools/project-workspace/docs/WINDOWS.md).
Partial or complete-looking failed output is retained without automatic cleanup.
The ignore file can be missing/incomplete and is not an access control. Sampled
checks/permissions depend on the filesystem and OS/Python version; hostile
mutation, drive rebinding, live providers, blocking I/O, power loss and all-stream
backup acceptance remain outside scope.
