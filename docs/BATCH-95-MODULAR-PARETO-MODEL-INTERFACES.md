# Batch 95: Pareto and model interface sources

Four independent MIT source tools describe exact supplied category contributions, apply a caller-selected cutoff without splitting ties, validate declared model input/output port shapes, and compare two pinned interface revisions. Each module is a standalone offline CLI with fictional examples and its own checked-file helpers.

Pareto contributions use bounded nonnegative decimal strings and exact rational cumulative shares. Equal category totals form one ranked block. A zero-total cohort has no defined shares or cutoff selection. The cutoff planner chooses no threshold itself and performs no operational action. The model tools validate caller-declared artifact pins, port types, static or symbolic shapes, and selected revision changes; they do not open or authenticate model artifacts.

No original private source, records, model weights, report schema, or assets are included. These tools do not run SQL, load models, infer preprocessing, establish cohort completeness, or authorize deployment. Real input and reports may disclose IDs, amounts, shape metadata, or pins and should remain private. Combined packaging remains deferred.
