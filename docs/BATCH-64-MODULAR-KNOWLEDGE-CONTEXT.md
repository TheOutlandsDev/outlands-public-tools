# Batch 64 - Independent knowledge and context tools

Four fresh generic MIT modules use explicit fictional contracts. Audit filenames
identified concept candidates; original implementation files were not consulted
or selected. No private code, user/customer data, paths, credentials, operational
configuration, model/training assets or third-party material is included. Original
files and filenames remain untouched; original-family clearance stays incomplete.

| Independent tool | Behavior | Interpretation limit |
| --- | --- | --- |
| [Context Manifest Checker](../tools/context-manifest-checker/README.md) | Exact embedded text pins/revisions and dependency graph | Declarations only, no source authority or execution proof |
| [Document Chunk Planner](../tools/document-chunk-planner/README.md) | Fixed code-point windows, offsets and hashes; no text output | No semantic/tokenizer guarantee, index or target writes |
| [Retrieval Evaluation Calculator](../tools/retrieval-evaluation-calculator/README.md) | Supplied binary judgments and exact macro precision/recall/MRR at k | No search execution, judgment authority or real model-quality proof |
| [Answer Evidence Checker](../tools/answer-evidence-checker/README.md) | Revision/pin and exact quoted span checks | No claim entailment, factual truth or publication approval |

Each complete directory runs independently on Python 3.12/3.13 standard library.
Inputs are explicitly selected, bounded JSON; exact duplicate/conflict/rejected
row accounting prevents silent loss. Any issue withholds all derived results.
Reports omit bodies but identifiers, hashes, relationships, offsets and metrics
can remain private information. Source pins establish bytes, not rights/privacy.

The dedicated Windows/Ubuntu matrix checks core known results and required native
file fixtures, standalone source copies and actual connected four-tool CLI outputs.
No GUI or external provider is involved. The existing Corpus & Model Workbench
is unchanged; these modules provide independent checks/arithmetic that can be
considered for integration later. No private original application is run.

Combined packages/workbenches and release assets remain deferred until remaining
drive candidates and the user's additional list are reconciled. The frozen
Toolkit 0.6.0 package plan/downloads stay unchanged.
