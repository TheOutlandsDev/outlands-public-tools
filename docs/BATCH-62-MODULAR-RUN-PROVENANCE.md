# Batch 62 - Independent snapshot and run provenance tools

Four fresh generic MIT source modules extend selected run/snapshot/publication
concepts using fixed invented text/JSON contracts. Private original implementation
files, historical runs, customers/users, mappings, business rules, credentials,
operational configuration, paths, databases and assets are not selected or executed.

| Independent tool | Included behavior | Evidence boundary |
| --- | --- | --- |
| [Run Artifact Manifest Builder](../tools/run-artifact-manifest-builder/README.md) | Hash explicit symbolic artifact bindings into a path-free manifest | Byte observations; roles are declarations, contents are not sanitized |
| [Ingestion Receipt Reconciler](../tools/ingestion-receipt-reconciler/README.md) | Rerun public typed CSV/XLSX intake; compare pinned preview and row accounting | Actually recomputed bounded counts; no source-authority/import claim |
| [Run Provenance Checker](../tools/run-provenance-checker/README.md) | Check actual artifact pins, declared step graph and public snapshot contract | No execution proof; opaque evidence and snapshot count assertions remain unverified |
| [Publication Plan Checker](../tools/publication-plan-checker/README.md) | Check exact selection, proposed names, reviewed pins and declarations | Plan consistency only; no privacy/rights proof, copying, upload or publication |

Each complete directory runs independently with Python 3.12/3.13 standard library.
Public I/O, intake and snapshot copies are byte-pinned in each origins/source
manifest. Runtime inputs are explicit regular single-link files; the Windows and
POSIX guards retain their protections. Optional output is one new external private
report; no overwrite, target mutation or automatic recovery cleanup.

The dedicated four-job Windows/Ubuntu matrix checks fictional core cases, required
native link fixtures, source pins, independent copied CLIs and the connected
four-module flow. Tests include fresh XLSX generation, typed preview forgery,
complete row accounting, stale snapshots/pins, invalid graph ordering/cycles,
held/incomplete reviews and source-tree output refusal. Only the opposite-platform
method per module may skip in qualification. No original workflow, live provider,
browser app, authenticated review, real publication or production result is tested.

Hashes, symbolic IDs, counts and graph relationships can disclose private details.
Matching replaced declarations do not authenticate a source or establish rights.
Consistent false snapshot counts deliberately remain marked unverified. Separate
receipt recomputation and real content review must not be replaced by plan PASS.

Combined packages, workbenches and release assets remain deferred until the
remaining drive audit and additional user list are reconciled. Existing fixed
Toolkit 0.6.0 downloads are unchanged. Original-family/whole-drive clearance
remains incomplete; this pass covers only the exact new public source inventory.
