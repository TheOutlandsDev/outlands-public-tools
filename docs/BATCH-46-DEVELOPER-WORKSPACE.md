# Batch 46: Offline Developer Workspace & Validation Workbench

The [complete application](../systems/developer-workspace/README.md) adapts authored extension/Python-AST validation and explicit editor draft/save boundaries into a private local project/review application. It includes import, file browsing/editing, immutable revisions, nonexecuting checks, comparison, forks, optimistic review, historical source exports and state backups. See [contract](../systems/developer-workspace/docs/CONTRACT.md), [origins](../systems/developer-workspace/docs/ORIGINS.md), [design](../systems/developer-workspace/docs/DESIGN.md) and [validation](../systems/developer-workspace/docs/VALIDATION.md).

Only selected generic mechanisms, public first-party helpers, fresh application source and invented projects are included under MIT/TheOutlandsDev. Original project bodies, business rules, assistant/operational histories, service configuration, runtime discovery, credentials, records and assets remain private. Original files are preserved and not executed; the whole original IDE family is not cleared.

Fifty-five core methods and fourteen real Chromium methods cover source/hash boundaries, complete edit/check/review/export workflows, deliberate parser failures, stale revisions/reviews, draft retention, literal source display, owned worker cancellation/deadline/shutdown, native I/O and private export integrity. CI requires applicable native links on Windows/Ubuntu Python 3.12/3.13. Exact files and focused source assets require frozen/current scanner agreement, private-marker dispositions, deterministic source packaging and clean extraction replay.

Passing static checks is not runtime correctness or privacy clearance. Markdown/HTML/CSS/JavaScript remain explicitly unchecked text. Exports pin the exact reviewed historical source and stay private; review is an assertion, not publication authorization. The shared directory registers this app as source-only until a later explicitly reviewed toolkit snapshot includes it. Existing frozen toolkit releases remain unchanged.
