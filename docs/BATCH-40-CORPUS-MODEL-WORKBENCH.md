# Whole-program corpus/model workbench adaptation

This batch publishes the owner's complete authored corpus/model application
core, relational schema, CLI and browser interface as the
[Corpus & Model Workbench](../systems/corpus-model-workbench/README.md).
Review, deduplication, group holdouts, FTS, SFT/RAG exports, model comparisons,
manual scoring, recommendation evidence and multi-role discussions remain
implemented. This is an application adaptation, not only a conceptual checker.

New private-instance bootstrap, guarded Windows/POSIX file I/O, strict JSON,
schema acceptance, fixed diagnostics, opt-in loopback model access and API-read
tokens replace historical environment assumptions. Fresh fictional fixtures and
a fake model client exercise the full workflow without an installed model.

No original instance configuration, customer/user content, historical benchmark,
local source path, hardware inventory, credential, model, database, log or asset
is selected. Third-party runtimes are separately supplied. The existing public
first-party I/O helpers retain MIT; see [origins](../systems/corpus-model-workbench/docs/ORIGINS.md).

The test matrix targets Windows/Ubuntu Python 3.12/3.13, requires applicable
native link fixtures, checks a full fictional demo and compares pinned source
ZIPs. See [validation and limits](../systems/corpus-model-workbench/docs/VALIDATION.md).
No real inference, browser acceptance, training, production deployment or
actual-data migration is claimed. Runtime stores and generated outputs stay
private. The [migration roadmap](PROGRAM-MIGRATION-ROADMAP.md) records larger
cohorts without publishing the private drive inventory.
