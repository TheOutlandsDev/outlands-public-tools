# Batch 48: Offline Assessment & Evidence Management Workbench

This selected complete application adds private scope assertions, bounded opaque
submission receipts, severity/narrative findings, duplicate/risk dispositions,
manual retests and explicit reviewed resolution. It adapts generic first-party
management methods into a separate standard-library CLI/browser application.

Hash-linked immutable snapshots are replay-checked on reads. Exact assessment and
finding revisions guard changes; stale commands preserve saved history. Private
exports need explicit quality/privacy/rights/context assertions for the current
hash and include a byte manifest. Schema-checked backups retain exact histories.
Existing neutral assessment records import through the unchanged public checker;
consistent closure claims remain separate, unverified declarations.

All fixtures are newly invented. Original assessment records, received packages,
identity/organization details, private paths, credentials, operational profiles,
runtime settings, scanner/lab workers, deployment code and third-party assets are
excluded. Original source is inspected only and stays unchanged. A private ledger
records selected-source hashes; no source locations or private inventories are
published. This selected adaptation does not clear the original application family.

Validation covers fictional transitions, atomic rejection, replay tampering,
receipt byte integrity, legacy drafts, exact private exports/backups, native file
guards and real Chromium workflows. CI requires Windows/Ubuntu Python 3.12/3.13,
mandatory native hardlink/symlink cases, a fictional CLI walkthrough and deterministic
source packaging. See [validation boundaries](../systems/assessment-evidence-workbench/docs/VALIDATION.md).

The management app never executes targets, uploaded code, scanners or package
hooks. Authorization, reviewer identity, outcomes and review checks remain operator
assertions. No operational containment, encryption, multi-user authentication or
production acceptance is claimed. Private exports are explicitly not public-release
approvals. The focused source release contains only inventoried source, documentation,
fictional examples and tests under MIT, copyright TheOutlandsDev.
