# Batch 68 - Independent resource and flow integrity tools

Four fresh generic MIT modules use fictional resource IDs, capability tags,
ordinal intervals, event histories and whole-unit quantities. Private original
implementation, scheduling/routing policy, business formula, employee/equipment
identity, customer record, path, credential, configuration or asset was not
consulted/selected/executed. Original files/filenames remain untouched; original-
family and whole-drive clearance stays incomplete.

| Independent tool | Scope | Evidence limit |
| --- | --- | --- |
| [Reservation Conflict Checker](../tools/resource-reservation-checker/README.md) | Declared half-open reservation capacity and availability | No physical capacity, live calendar, optimizer or schedule changes |
| [Assignment Eligibility Checker](../tools/assignment-eligibility-checker/README.md) | Selected task/resource capability, capacity and availability claims | No certification, combined-load verdict or work assignment |
| [Process Event Duration Analyzer](../tools/process-event-duration-analyzer/README.md) | Explicit complete start/hold/resume/finish histories and exact durations | No live clock, actual completion proof or total wall-clock makespan |
| [Flow Balance Reconciler](../tools/flow-balance-reconciler/README.md) | Opening + movements + adjustments = declared closing per bucket | No physical inventory truth, intermediate balances or target updates |

Each complete directory runs independently with Python 3.12/3.13 standard library.
Native I/O guards are pinned existing public code. All rows are accounted for;
conflicts never select a latest snapshot. Structural/reference problems withhold
results; valid capacity, eligibility and arithmetic findings retain complete
diagnostics for review. Invalid event histories withhold all duration totals.

The dedicated Windows/Ubuntu matrix tests known results, required native fixtures,
independent source copies and actual connected CLIs. It checks a shared resource
contract, adjacent reservations, complete process histories and a fictional transfer.
An individually eligible proposal is not a combined capacity or execution approval.
Real IDs, timings, counts and hashes remain private; PASS is not publication rights.

These four tools remain source-only, outside the existing package plan, until
explicit integration review. Prior systems and the pinned package plan/downloads
remain unchanged by this pass. No new workbench, service or release assets are added.
