The public candidate uses fixed-code argument errors and the static name markdown_docx.py. Missing python-docx imports are handled without an import traceback; static help works without that dependency. Input/output rejection, explicit paths, table limits, exclusive no-replace outputs and neutral core properties remain in place. The retained private version is unchanged.

## Boundaries

This is a small Markdown subset, not an HTML/template/image interpreter. It does not fetch Markdown links or image URLs. Trusted, quiescent local paths are required; path checks are not a sandbox against hostile ancestor replacement. Linux fixture results do not establish Windows junction/reparse behavior or Office rendering quality.

Copied input text is not anonymized. Neutral core properties do not remove inherited default-template parts, application fields, a thumbnail, custom XML or ZIP member timestamps. The fictional package inspection is not clearance of every future document. Generated outputs remain private unless separately reviewed. The direct dependency version declaration is not a complete transitive lock, vulnerability audit or supply-chain guarantee.
