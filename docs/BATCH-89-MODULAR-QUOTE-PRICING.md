# Batch 89 - Independent quote-pricing integrity tools

Four fresh generic MIT modules use invented HVAC service, game and AI/software
examples. [Example themes](FICTIONAL-EXAMPLE-THEMES.md) remain unchanged. Audit ledger
entries identify concept scope only; no original implementation, real pricing policy,
customer/user data, records, private paths, credentials or operating instance was
consulted or selected. Original-family/whole-drive clearance remains incomplete.

| Independent tool | Scope |
| --- | --- |
| [Price Book Contract Checker](../tools/price-book-contract-checker/README.md) | Validate explicit price-book items, units, quantity tiers and decimal rules. |
| [Quote Line Pricing Checker](../tools/quote-line-pricing-checker/README.md) | Check supplied line prices against an exactly pinned declared price book. |
| [Quote Total Reconciler](../tools/quote-total-reconciler/README.md) | Reconcile rounded line extensions, ordered adjustments and declared quote totals. |
| [Quote Pricing Scenario Comparator](../tools/quote-pricing-scenario-comparator/README.md) | Compare one supplied basket cohort under two complete declared price books. |

All-units quantity tiers, exact rational arithmetic and explicit minor-unit rounding
avoid inferred pricing rules. Line pricing binds the whole normalized price book.
Total reconciliation independently checks every supplied extension/adjustment, coverage,
subtotal and total. Ordered adjustments apply to the current rounded balance; no tax
rules or currency conversion are inferred. Scenario comparison uses one shared basket
cohort, rejects currency/minor-unit incompatibility and requires new revisions for
changed same-ID books. Equal selected results do not establish whole-catalog compatibility.

Each complete directory runs independently with Python 3.12/3.13 standard library.
Public MIT JSON/I/O/identity helpers are byte-pinned with origins. Known-answer,
adversarial, native Windows/Ubuntu fixtures, standalone copies and a connected HVAC
CLI projection qualify supplied declarations. Reports may contain necessary amounts
and IDs and remain private; hashes do not anonymize. No browser, network, live quote
changes, invoices, payment, identity or actual approval validation occurs.

Root README, three starting workflows, theme guide, frozen package plan, existing
systems/downloads/workshops and prior source announcements are preserved. A new source
announcement follows the index. Packaging remains deferred.
