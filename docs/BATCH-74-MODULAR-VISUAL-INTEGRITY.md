# Batch 74 - Independent visual dataset and geometry integrity tools

Four fresh generic MIT modules use newly invented HVAC panel and game hitbox metadata.
No image assets are included or opened. [Example themes](FICTIONAL-EXAMPLE-THEMES.md)
remain HVAC, AI and game development. Original private code, schemas, geometry/label
policies, images, annotations, models, customer/user records, credentials, private paths,
endpoints and operational configurations were not consulted or selected. Original-family
and whole-drive clearance remain incomplete.

| Independent tool | Scope | Evidence limit |
| --- | --- | --- |
| [Annotation Manifest Contract Checker](../tools/annotation-manifest-checker/README.md) | Declared image, taxonomy and annotation snapshot references | No actual image bytes or geometric validity claim |
| [Polygon Geometry Checker](../tools/polygon-geometry-checker/README.md) | Bounded simple integer polygons, exact area and edge contacts | No repair, masks or image alignment |
| [Bounding Box Contract Converter](../tools/bounding-box-converter/README.md) | Explicit half-open pixel boxes and exact normalized rational centers | No implicit rounding, clipping or object matching |
| [Annotation Export Handoff Checker](../tools/annotation-export-handoff-checker/README.md) | Exact category maps, snapshot approvals and selected counts | Manual review only; no authentic approval, geometry or export authority |

Each complete directory runs independently with Python 3.12/3.13 standard library.
Native I/O and identity/fraction helpers are pinned public MIT copies. Visual logic
is fresh. Identical identity snapshots count once; conflicting groups withhold every
member. Invalid references/scope contracts withhold qualified results. Valid geometry
or count/approval findings retain complete diagnostics. Pixel conventions and all
bounds are explicit; no latest selection, coordinate guessing or automatic correction.

The native matrix checks source pins, adversarial known results, mandatory filesystem
fixtures, independent copies and actual connected CLIs. An invented two-image HVAC
flow reconciles annotations, checks geometry with areas 800 and 1,600, explicitly
adapts envelopes to normalized boxes, round-trips exact pixel edges and reviews pinned
handoff counts. A game-tile fixture checks hitbox fractions. Counterexamples distinguish
reference consistency from valid polygons and declared approval from real alignment.

These additions remain outside the frozen package plan. Existing systems, packages,
downloads, workshops and theme guide are unchanged. No combined application or new
release assets are created. Keep actual inputs/reports private: synthetic checks and
consistent declarations do not establish authentic image bytes, actual object bounds,
label truth, privacy, rights or authorization to export, publish, train or deploy.
