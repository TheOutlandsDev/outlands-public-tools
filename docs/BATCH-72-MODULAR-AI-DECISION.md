# Batch 72 - Independent AI decision and change integrity tools

Four fresh generic MIT modules use newly invented HVAC request classifications and
game-event labels. [Example themes](FICTIONAL-EXAMPLE-THEMES.md) remain HVAC, AI and
game development in this repository. No private original implementation, prompt,
taxonomy, classifier rule, corpus, model, user/customer record, credential, private
path, endpoint or configuration was consulted/selected/executed. Original-family
and whole-drive clearance remain incomplete.

| Independent tool | Scope | Evidence limit |
| --- | --- | --- |
| [Prompt Contract Diff](../tools/prompt-contract-diff/README.md) | Ordered literal messages, placeholders and declared output interfaces | No rendering, response validation or model behavior claim |
| [Label Mapping Contract Checker](../tools/label-mapping-contract-checker/README.md) | Explicit revisions, complete source coverage, splits and merges | No inferred semantics or record relabeling |
| [Score & Abstention Policy Checker](../tools/score-abstention-policy-checker/README.md) | Exact recorded-score decisions and explicit tie/abstention rules | No inference, calibration or true-label claim |
| [Candidate Evaluation Gate Planner](../tools/candidate-evaluation-gate-planner/README.md) | Same declared cohort, actual embedded scope pins and exact criteria | Manual-review eligibility only; no deployment or quality authority |

Each directory runs independently with Python 3.12/3.13 standard library. Public MIT
native I/O is copied with exact pins. Normalized duplicate identity snapshots count
once; conflicting groups withhold every member. Invalid scope/reference/version
contracts withhold qualified results. Valid prompt changes, split/merge findings,
wrong recorded decisions and metric failures retain complete diagnostic assessments.
Policy-consistent abstentions can PASS; they remain in full evaluation denominators.

The four-platform matrix checks source pins, known results, mandatory native file
fixtures, standalone copies and actual connected CLIs. The invented HVAC workflow
aligns prompt/taxonomy pins, explicitly adapts one-to-one baseline labels, checks two
selected labels/one abstention and compares candidate 2/3 against baseline 1/3 accuracy.
A stricter evaluation criterion rejects the same policy-consistent predictions.
The separate NPC-event fixture demonstrates one quest label and one tie abstention.
No provider, model, real prompts, weights or private datasets are required.

These modules remain outside the frozen package plan. Existing systems, downloads,
workshops and package definitions are unchanged by this pass. No combined application
or new release assets are created. Keep actual inputs/reports private; pin consistency
and synthetic tests do not clear rights, establish authentic evidence or authorize
model use, real decisions, operational actions or publication of future records.
