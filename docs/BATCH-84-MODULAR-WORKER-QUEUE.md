Each complete directory runs independently with Python 3.12/3.13 standard library.

fresh. Complete identity accounting prevents silent latest/best selection. Structural
ambiguity withholds complete assessments and scope pins. Invalid lease histories
also withhold downstream acknowledgement/result assessments. Logical review findings
retain diagnostics without qualified scope. A current consistent claim never erases
earlier expired-owner, missing, ambiguous or future records from the selected scope.

Time is explicit integer metadata with a caller-supplied common basis. Ownership is
half-open; renewal at expiry cannot resurrect a lease. Tokens increase per item;
rejected overlapping acquire claims still count toward declared issuance history.
These are limited caller assertions, not authenticated or enforced distributed locks.

Known-answer/adversarial/native filesystem qualification and actual standalone CLI
acceptance cover expiry/takeover, acknowledgement gaps and stale result/commit claims.
Connected invented HVAC records bind identical item, lease and delivery cohorts across
tools. Explicit adapters call the existing public Retry Budget Checker and Idempotency
Ledger Reconciler with invented attempts/terminal claims and rejection counterexamples;
their engines are not duplicated. No jobs, retries, acknowledgements or commits occur.

unchanged by this pass. The three starting workflows and all prior announcements are

the frozen package plan; packaging is deferred. Actual inputs/reports remain private.
