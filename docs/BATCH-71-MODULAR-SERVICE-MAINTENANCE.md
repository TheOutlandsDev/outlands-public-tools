# Batch 71 - Independent service and maintenance integrity tools

Four fresh generic MIT modules use fictional HVAC counter histories and service
jobs. [Example themes](FICTIONAL-EXAMPLE-THEMES.md) remain HVAC by default for
manufacturing/service, with AI/game-development examples permitted in this repository.
No private original implementation, schema, interval policy, equipment specification,
customer/user record, asset identifier, path, credential or operating configuration
was consulted/selected/executed. Original-family and whole-drive clearance stay incomplete.

| Independent tool | Scope | Evidence limit |
| --- | --- | --- |
| [Meter Reading History Checker](../tools/meter-history-checker/README.md) | Explicit readings, reset boundaries and cumulative usage | No live collection, physical truth or counter changes |
| [Maintenance Due Planner](../tools/maintenance-due-planner/README.md) | Caller-supplied ordinal/usage intervals and freshness | No interval recommendation, clock or scheduling |
| [Work Order Lifecycle Checker](../tools/work-order-lifecycle-checker/README.md) | Selected snapshots, contiguous revisions and state histories | No dispatch, service proof or order edits |
| [Service Completion Contract Checker](../tools/service-completion-checker/README.md) | Exact order pins, required tasks/evidence and parts accounting | No lifecycle recomputation, physical work proof or operational updates |

Each complete directory runs independently with Python 3.12/3.13 standard library.
Native Windows/POSIX I/O is pinned existing public MIT code. Normalized identity
snapshots count once; conflicting groups withhold every member. Invalid scoped
references/history withhold the entire tool result. Valid due/staleness findings
and incomplete completion contracts retain full diagnostic assessments for review.
PASS is consistency, never independent truth or execution authority.

The four-platform matrix checks source pins, known results, mandatory native fixtures,
independent copies and actual connected CLIs. The service exercise accounts for twelve
demo-cycles across an explicit reset, calculates a supplied due threshold, then
explicitly supplies a manual order and completion declarations: two tasks, one filter
installed/one returned and an invented evidence pin. A completed state alone cannot
establish task completion or balanced parts. No automatic integration or action occurs.

These additions stay outside the frozen package plan. Existing systems, packages,
downloads and workshops are unchanged by this pass. No combined workbench or new
release assets are created. Real inputs/reports remain private; tools do not anonymize
data, validate actual maintenance policy or clear future publication rights.
