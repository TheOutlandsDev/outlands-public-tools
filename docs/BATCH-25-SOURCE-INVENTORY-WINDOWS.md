# Source Inventory Windows hardening review

This batch adapts only the collection's existing public MIT source and native
file mechanisms, with invented disposable fixtures. No original inventory
helper, real project tree, private path, credential, user record, configuration,
runtime capture, game asset or third-party implementation is exported. Selected
MIT scope uses TheOutlandsDev; required notices remain. Held originals,
historical source/rights gaps and existing release assets are not cleared.

Windows now validates path spellings, local drive type, reparse state and
normalized native-volume names; retains observed root/ancestor/file handles;
guards each directory before one-level enumeration; and compares native/CRT
identity before and after bounded hashing. Cooperative writers remain allowed
and detected changes remain failures. Only unnamed data is hashed, and regular
hard links remain separate rows. Native keys strengthen overlap/alias checks.

Fresh reports never replace existing entries. Short/zero/failed writes,
flushes and identity/name/size/link-count checks have explicit failure paths.
Partial or fully written but unconfirmed outputs remain, including summaries.
Windows interruption returns 130 with a fixed incomplete result and closes
owned resources. POSIX bodies, report/rendering/exclusion contracts, classifier
source, all original 92 methods and example generators are preserved.
Classifier input reading remains its original sampled implementation; its
shared Windows directory/exclusive writer gains these checks.

Local Windows/Python 3.12.7: original 92 discovered, 85 passed/seven skipped;
new 32 discovered, 22 passed/ten skipped; no failures/errors. Nine new native
link/junction fixtures are unavailable locally, plus one Linux-only method.
Short-name alias rejection ran. CI requires Windows link/junction fixtures on
Python 3.12/3.13, retains Ubuntu POSIX coverage and reports optional short-name
availability separately. Skips never count as passes.

A separate three-file package passed 28 fresh processes (25 direct CLI and
three controlled failures). Fictional hashes/counts, deterministic CSV, tree
limits/hash, classifier compatibility/manifest, no-overwrite, partial writes,
late unconfirmed summary and interruption were checked. Input/runtime bytes
stayed unchanged and no bytecode appeared. Reports/captures remain private.

The exact selected publication files receive an export/hash inventory and
unchanged public-detector/private-marker review. CI and merged bytes are
verified separately. This is not clearance of full history or unrelated work.

Six retained pattern flags are invented invalid Windows/UNC/device/stream
spellings in negative tests. Native access is blocked in those fixtures. Exact
lines and file hashes have private review dispositions; scanner status remains
`REVIEW_REQUIRED`, with zero unresolved/private-literal findings or errors.
No detector or source-checking rule was weakened.

Read the [Windows contract](../tools/source-inventory/docs/WINDOWS.md) and
[usage](../tools/source-inventory/README.md). Sampled checks, creation/open gaps,
version-dependent/inherited ACLs, blocked native calls and output retention
remain explicit. No hostile-filesystem, live-provider/share, power-loss,
complete-stream backup, anonymization, secret-detection or publication-rights
guarantee is made. Real names, timestamps and hashes remain sensitive metadata.
