# Generic Data & Services Stack system batch

This batch publishes one coherent local application: shared public ingestion,
baseline forecasts/evaluation and outbox outcomes; new strict job configuration;
persistent run history and notification state; restart review; CLI; source
manifest and deterministic release packaging; and complete fictional validation.

It uses reviewed first-party public MIT components and fresh neutral contracts.
The evaluator's sole adaptation is relative ingestion import. No original
business application bodies, schema, query, formula, source mapping, private
template, provider destination/configuration, credential or operational record
is selected. Original held families remain held. Existing repository branding
and historical metadata outside the selected files are not cleared by this batch.

Runs record intent before calculation; a result and its notification become
visible together. Transport attempts commit intent before the callback, then
commit the observed result. Recovery holds interrupted runs/attempts for review
without automatic replay. Only definite non-acceptance enables retry. Matching
delivery reports remain unverified caller assertions. The included transport is
fake only; no real email service, background worker or provider configuration
is bundled or exercised.

Append-only checked snapshots/commit markers preserve prior history and partial
new output. The workspace is private, bounded, one synchronous operator and
stable trusted local storage. Hash chains are not authentication, confidentiality
or rollback protection without an independent checkpoint. No power-loss,
exactly-once, multiuser or hostile filesystem guarantee is made.

The dedicated Windows/Ubuntu Python 3.12/3.13 workflow requires 65 application
methods, the 104 original public component methods, a real fictional restart
demo, source checks and reproducible packaging. Required native link cases may
not silently skip; the opposite-platform FIFO/junction method is the sole
expected skip. Child-process exits test interrupted run/claim/acceptance recovery.
The exact full-system publication set and source ZIP bytes are reviewed together.
