# Batch 56: Data and Services browser workbench

Upgrade the existing [Generic Data and Services Stack](../systems/data-services-stack/README.md)
with a complete local browser workflow: neutral job configuration, explicit CSV/
JSONL preview, pinned runs, saved forecast/evaluation inspection, checked private
reports, durable fictional queue attempts and restart without replay.

The public core algorithms, journal/state schema and native Windows/POSIX helpers
remain unchanged. New controller operations are serialized and head-pinned;
preview/result hashes detect stale content. Strict loopback API boundaries,
nonce-based scripts and finite/depth-bounded JSON support the private workflow.
Reports are exclusive new files under a separate new private report root.

The pass selects existing public source and new fictional implementation/tests
only. No original private application code, business mapping/formula/schema,
recipient, user record, path, provider setting, credential, log or asset is selected.
MIT notices remain. Runtime workspaces, reports, screenshots and test traces stay
outside publication. Remaining original sources and drive families remain held.

Qualification requires Windows/Ubuntu Python 3.12/3.13, 99 core and 24 actual
Chromium methods plus 104 original component methods passing per job, all five
applicable native boundary methods and one opposite-platform skip. Exact source
files/assets are separately audited. Real delivery, useful real-data forecast
accuracy, hostile storage, production/distributed hosting and full journal restore
remain unverified. See [browser contracts](../systems/data-services-stack/docs/WORKBENCH.md)
and [validation limits](../systems/data-services-stack/docs/VALIDATION.md).
