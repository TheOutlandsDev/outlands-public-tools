# Batch 67 - Independent time-series and backtest integrity tools

Four fresh generic MIT modules use fictional series, ordinal periods and pinned
invented observations. Private original implementation, model, feature formula,
calendar, business rule, user/customer record, credential, path, configuration or
asset was not consulted/selected/executed. Original files and filenames remain
untouched; original-family/whole-drive clearance stays incomplete.

| Independent tool | Scope | Evidence limit |
| --- | --- | --- |
| [Time-Series Grid Checker](../tools/time-series-grid-checker/README.md) | Expected cadence, gaps, duplicates and off-grid points | Declared ordinal grid only; no imputation or real calendar proof |
| [Rolling-Origin Backtest Planner](../tools/rolling-origin-backtest-planner/README.md) | Bounded training windows, gaps, stride and full multi-horizon folds | No observation verification, training or actual forecast evaluation |
| [Point-in-Time Observation Resolver](../tools/point-in-time-observation-resolver/README.md) | Exact pinned revisions available at declared inclusive cutoffs | Supplied history/timing claims only; no authenticated availability |
| [Feature Window Lineage Checker](../tools/feature-window-lineage-checker/README.md) | Exact selected lag/rolling contributors, pins and as-of revisions | No feature values, execution proof or universal leakage detection |

Each complete directory runs independently on Python 3.12/3.13 standard library.
Native I/O guards are pinned existing public code. JSON is bounded, identities
are explicit, all rows accounted for and conflicts never resolved by silently
selecting a version. Quality gaps retain diagnostic grid coverage; malformed
points withhold it. Other tools withhold entire derived outputs after any issue.

The dedicated Windows/Ubuntu matrix runs known cases, required native fixtures,
standalone copied CLIs and a connected four-tool cohort. The public last-value
baseline receives actual resolved fictional prefixes; no private model or source
system is used. Scores describe invented numbers only. Cutoffs/availability can
be false, and repeated backtest targets are not independent validation evidence.
Reports omit values but metadata/pins remain private; PASS is not release approval.

Combined packages/workbenches and release assets remain deferred until remaining
drive candidates and the user's additional list are reconciled. Existing systems
and frozen Toolkit 0.6.0 downloads/package plans remain unchanged.
