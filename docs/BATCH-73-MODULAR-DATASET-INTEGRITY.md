# Batch 73 - Independent AI dataset and evaluation integrity tools

Four fresh generic MIT modules use newly invented HVAC fault labels, equipment groups,
content-hash declarations, categorical reviews, training selections and evaluation
memberships. [Example themes](FICTIONAL-EXAMPLE-THEMES.md) remain HVAC, AI and game
development in this repository. Original private implementations, schemas, datasets,
policies, models, customer/user records, credentials, private paths, endpoints and
operational configurations were not consulted or selected. Original-family and
whole-drive clearance remain incomplete.

| Independent tool | Scope | Evidence limit |
| --- | --- | --- |
| [Dataset Partition Integrity Checker](../tools/dataset-partition-checker/README.md) | Declared record, content hash and equipment group overlaps | No content reading or proof of independence |
| [Annotation Agreement Reporter](../tools/annotation-agreement-reporter/README.md) | Categorical reviews, missing slots and exact matched-pair agreement | No adjudication, truth or reviewer authenticity |
| [Training Selection Contract Checker](../tools/training-selection-checker/README.md) | Full-snapshot/policy pins, explicit approvals and exclusions | Manual export review eligibility only; no export or training |
| [Evaluation Slice Coverage Checker](../tools/evaluation-slice-checker/README.md) | Explicit slices, unique memberships and exact coverage thresholds | No representativeness, model scoring or comparison authority |

Each complete directory runs independently with Python 3.12/3.13 standard library.
Native I/O, identity accounting and exact fraction helpers are pinned public MIT
copies. New generic dataset logic is shared locally within each complete directory.
Identical identity snapshots count once; conflicting groups withhold every member.
Invalid scope/reference/pin contracts withhold qualified results. Valid overlaps,
disagreements and criterion failures retain complete diagnostics for manual review.

The native matrix checks source pins, adversarial known results, mandatory filesystem
fixtures, independent copies and actual connected CLIs. An invented HVAC exercise
checks four records, eight reviews, two training selections and two held-out cases.
An explicit test adapter passes the cohort to the existing candidate gate, comparing
declared baseline 1/2 with candidate 1/1 accuracy without inference. Separate acceptance
shows training approval does not clear a train/test equipment-group overlap.

These modules remain outside the frozen package plan. Existing systems, packages,
downloads, workshops and example-theme guide remain unchanged. No new combined
application or release assets are created. Keep actual inputs/reports private:
declaration consistency and synthetic tests do not establish authenticity, truth,
privacy, independence, rights or authorization to publish, export, train or deploy.
