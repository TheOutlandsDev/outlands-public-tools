# Batch 58: Offline Dataset Review Workbench

Build a full local browser workflow around the existing public Dataset Review Manager:
explicit JSONL import, search/filter/pages, text/provenance/duplicate-linked groups,
review history and assertions, private checked exports and database-only backups.

Preserve the legacy schema, review/normalization/deduplication/holdout algorithms,
CLI results, native Windows/POSIX helpers and original tests. Optional transaction
callbacks add state-pin checks and before-commit view validation for new-interface
operations. Existing stores are explicitly copied read-only into fresh private
instances; no migration or original store mutation. Standalone source-root selection
preserves repository protection in normal collection checkouts.

The interface adds draft protection, stale refusal, unchecked fresh review forms,
nonce/Host/Origin/token boundaries, lost-response holds without replay, exclusive
outputs and owned server shutdown/recovery. Required Windows/Ubuntu Python 3.12/3.13
qualification covers the original and new core tests, 25 actual Chromium methods,
mandatory applicable native fixtures, full fictional demo and exact source ZIPs.

Only public source and new generic code/invented fixtures are selected. No private
original, corpus/user record, credential, deployment path/configuration, browser
profile, runtime state or asset is included. Runtime exports/backups stay private.
Structural/pattern checks and review assertions are not anonymization, rights proof,
authenticated identity, hostile-storage protection or public release approval.
