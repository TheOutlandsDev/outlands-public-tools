# Source origins

This is fresh first-party MIT code, copyright TheOutlandsDev, informed by an
owner-confirmed authored import workflow. The selected methods are explicit source
registration, row provenance, normalization/deduplication, visible import-error
accounting and keeping imported material unapproved until human review.

The original importer was read only. It is not copied, executed or included; its
historical input formats, source mappings, configuration, operational paths,
benchmark records, existing corpora/conversations and databases remain private.
No original dependency, asset or historical record is relicensed by this release.
The broader original application family is not cleared by this selected adaptation.

The workbench adds exact typed field mappings, canonical private previews, key
conflict blocking, independently pinned inputs, reviewed fresh SQLite destinations,
logical readback, durable attempts, interruption review, CLI/browser UI, private
handoffs and fictional platform tests. It does not claim compatibility with the
original operational instance or its domain-specific schemas.

The native I/O helper files are unchanged first-party MIT source from the public
Backup & Recovery Workbench. Session, bounded JSON, journal-storage, loopback HTTP,
test-runner and deterministic source-packaging patterns are adapted from that
public application. Original schemas and data bindings are not imported.

Python, SQLite, Windows/POSIX APIs and optional pinned browser tooling are separately
supplied under their own licenses. Windows native junction tests use separately
installed PowerShell 7. No Python runtime, browser binary, model, downloaded package,
third-party asset, database, instance data or generated report is bundled. Future
inputs/exports retain their own privacy and rights requirements.
