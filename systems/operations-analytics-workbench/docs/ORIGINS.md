# Source origins and publication scope

MIT first-party application, copyright TheOutlandsDev. The owner approved this
implementation after a read-only scope review of an educational portfolio design.

That portfolio supplied concept categories and discussion of fictional workflows.
Its executable code, generated databases/archives, outputs and fixtures are not
copied into this application. New domain/application code and fresh invented
examples implement the selected scope. General arithmetic is documented with
explicit assumptions rather than presented as an original operating policy.

The native `vendor/store_io.py` and `review_io_windows.py` files are unchanged MIT
snapshots from this collection's Production Planning Workbench. The instance/store
runtime, HTTP boundary pattern and deterministic source packager adapt the same
public first-party implementation to this app's schema/names. Their MIT grant is
retained. No third-party source or binary is bundled; Python/SQLite/native APIs
remain separately supplied under their own terms.

No original employer/customer source, schema/query, environment configuration,
operating policy, mapping, identity, credential, endpoint, record, workbook,
database, model, log, deployment code or asset is selected. Private audit paths,
source ledgers, scanner markers and historical metadata remain outside source.
The earlier portfolio's missing license is not silently interpreted as a grant
for its code; this release contains the fresh implementation and public MIT reuse.

The exact selected changed files and focused source assets receive their own
review. This does not clear unrelated original applications, existing collection
branding/history or future runtime inputs and outputs. Independently invented
examples and passing tests do not establish manufacturing suitability, verified
observations, ownership of earlier work or disclosure permission for other files.
