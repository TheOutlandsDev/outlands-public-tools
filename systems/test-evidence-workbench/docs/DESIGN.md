# Design and implementation boundaries

The application separates case editing, execution trust, explicit plans, child observations, evidence review and private exports. Import/save/trust never execute code. Exact latest case and trust pins are checked for the entire plan before side effects. Any revision creates fresh trust requirements; an accepted plan captures its approvals, so later revocation does not silently rewrite its context. Cancellation is an explicit separate action.

The owner-authored IDE supplies the starting methods: an owned Popen handle, output streaming, cancellation and hidden Windows consoles, plus a dashboard that selects named reviewed cases and distinguishes observed outcomes. The new implementation removes runtime/executable discovery, inherited PATH/environment, business registry keys/parameters, credential-dependent UI and real evidence. Fresh neutral schemas and a CLI/browser UI retain these general methods without importing the original application. [Origins](ORIGINS.md).

Python [subprocess](https://docs.python.org/3.13/library/subprocess.html) starts a fixed current interpreter with isolated/no-site/no-bytecode/UTF-8 flags, no shell or interactive stdin, minimal environment and an owned working directory. Supplied source is trusted local code with the user's permissions. This is not adversarial code containment, account separation or a total resource quota. The child can spawn descendants, access files/network and make claims unrelated to real systems. Only the immediate owned handle is cancelled/reaped; no externally supplied process IDs are accepted.

Two byte readers capture stdout/stderr concurrently, without line-based blocking. POSIX uses readiness polling; Windows uses [PeekNamedPipe](https://learn.microsoft.com/en-us/windows/win32/api/namedpipeapi/nf-namedpipeapi-peeknamedpipe) availability before bounded reads. Each stream retains at most 16384 bytes; overflow triggers termination and records prefix scope. Raw bytes/base64/hashes are separate from UTF-8 display and parsed JSON. JSON comparisons normalize integral floats within declared numeric bounds and distinguish booleans. Stderr alone normalizes CRLF to LF for comparison, retaining raw original bytes. Readers stop after the immediate child exits; they do not guarantee capture of descendant output.

Monitoring applies the declared deadline after process creation. OS creation and native scheduling/I/O are not hard real-time guarantees. Termination escalates to kill/wait if necessary. Normal shutdown cancels the owned child and joins work; hard parent kill, escaped descendants, power-loss/mid-write durability and hostile local races are outside acceptance. In-memory jobs are not restart checkpoints; never automatically replay an interrupted/uncertain action.

Public first-party native I/O helpers guard input/parent links, applicable Windows reparse/hard-link/stream cases and POSIX special files. New files/directories are exclusive and the source repository is protected from becoming a private instance. Exact SQLite schema/version, append-only records and a bounded store protect ordinary local state. These do not support hostile-database import, cryptographic attestation or concurrent remote operators. Database backups omit inbox/run/export files; no complete restore is claimed.

The loopback browser has Host/Origin checks, random API session token, bounded requests, no-store/no-referrer headers and object/frame restrictions. Code/captures/results are literal text. Source/history loading is atomic; editor-mutating requests lock controls, while a draft edited during a running plan stays separate from captured source. Stale case/trust/review writes refuse without losing text. Selecting/completing evidence replaces its review form; unsaved notes remain browser memory only. Reviewer identity is not authenticated.

Complete failure evidence is useful evidence. Approval therefore records capture/privacy/rights/context assertions without changing expected/observed verdicts. Comparisons expose case-revision and raw-output differences, not causation or operational truth. Exports pin the captured source/input/trust snapshots rather than today's edited case; escaped summaries do not render raw source/output. Every future input, script, note, capture and export stays private until a separate exact-file release review.
