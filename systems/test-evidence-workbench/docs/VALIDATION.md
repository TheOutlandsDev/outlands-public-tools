# Fictional validation and acceptance limits

The 56-method standard-library suite covers exact JSON/number/byte/count contracts; atomic imports; immutable case hashes/parents; fresh trust for revisions; strict assertions, revocation and stale-plan refusal before any child; real sum and expected-nonzero checks; deliberate mismatch/deadline; simultaneous byte capture, exact/overflow boundaries without newline, invalid UTF-8 and malformed stdout; minimal environment/isolation flags; trusted local effects; actual cancellation/reaping and remaining not_run cases; normal active shutdown; independent review identities, complete failure review, export gates and raw-member hashes; historical pins/comparisons; schema/append-only/store rollback, backup, API guards and native I/O.

Sixteen actual Chromium workflows exercise case import/editing, separate trust and execution, unchecked/untrusted refusal, stale source/trust/review conflicts with retained drafts/notes, real run/cancel, timeout versus expected nonzero, output overflow, literal untrusted output, failed-evidence review without verdict changes, repeated-run pending review, comparison/backup, atomic history-fetch failure, draft editing during runs and narrow keyboard use. Only invented scripts/inputs execute. Browser routes refuse outside requests; this is not proof that arbitrary Python code is network-isolated. Automation is not manual usability or full accessibility acceptance.

Four native link fixtures can be unavailable on the local drive; those skips and one opposite-platform case are recorded. Windows/Ubuntu Python 3.12/3.13 CI requires all applicable native fixtures, both suites, full demo, documentation and pinned deterministic source package. A local unavailable fixture is not a pass. Idle server hard termination/recovery is tested separately from active cancellation; no active hard-parent-kill cleanup or crash durability is claimed.

The complete demo executes four invented cases and records two matches, two unmatched cases and one timeout; an explicitly expected nonzero exit matches. A second two-case run starts pending review. The first artifact exports thirteen private files without altering verdicts, and a database backup is schema-checked. Independent fresh ZIP/CLI replay verifies every application source byte, case/revision/input/script pins, an independent sum oracle, expected versus observed values, canonical JSON/raw capture hashes and every private export member. Runtime durations/raw newline bytes may differ by platform; focused source ZIP bytes must match.

Excluded acceptance: hostile/unreviewed code containment; descendant cleanup/capture; total memory/CPU/disk/network quotas; hard real-time guarantees; signed source or result attestation; independent truth of script-reported values; original operating checks/records/services; credential secrecy against trusted code with filesystem access; universal secret detection/redaction; authenticated multiuser review; hostile stores/races/network storage; hard parent kill, power-loss/mid-commit durability or complete-instance restore. These source/fictional runtime checks never clear unrelated original systems or real future evidence for publication.
