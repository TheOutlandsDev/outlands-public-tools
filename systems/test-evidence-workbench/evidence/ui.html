Trust is an unauthenticated local assertion. It is pinned to this whole case revision and must be renewed after any revision. Revocation blocks future starts; cancel is separate for a run already started. Only the owned immediate child is cancelled; descendants are not contained or terminated.

4 · Explicit run plan

Up to eight cases run in order, each in a fresh private directory. The entire plan is checked before execution. No shell, executable, arguments or inherited credentials are accepted through the case format. Python code itself is trusted, not restricted. Stdout/stderr capture is limited to 16 KiB per stream. Runs are never replayed on restart.
