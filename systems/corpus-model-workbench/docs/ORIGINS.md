# Source origins and publication boundary

MIT first-party application adaptation, copyright TheOutlandsDev. The owner
confirmed authorship of the original systems and authorized sanitized release
of reusable implementations and methods.

The corpus engine, model orchestration, relational schema and browser UI retain
the original implementation. Changes replace implicit instance bindings with
explicit new private workspaces; remove historical hardware/environment details,
autostart references and default model/service settings; add guarded filesystem
operations, strict JSON, schema checks, bounded loopback access, authenticated
API reads, fixed diagnostics and a complete fictional client/workflow.

The Windows backend is a byte-identical copy of this collection's first-party
Dataset Review `review_io_windows.py`. `vendor/store_io.py` contains selected
unchanged helper functions from its public `review_store.py`, with a small
application-specific import/constants prefix. Their MIT notice is retained by
this application's license. No downloaded dependency implementation is bundled.

Fresh fixtures, tests, private-instance bootstrap, source packaging and these
guides were authored for publication. No original configuration, local path,
corpus, benchmark set, record, model, hardware inventory, database, log, exported
output or third-party asset is included. The selected source and focused ZIP
are reviewed separately from earlier repository files and commit history.

Future private inputs and model-generated outputs do not acquire a publication
clearance or a license merely by passing through this program. Preserve notices
and review any additional third-party implementations before redistribution.
