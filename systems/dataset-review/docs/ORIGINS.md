# Source origins and rights

This pass uses only the already-public Dataset Review Manager, its MIT Windows/POSIX
I/O and canonical-schema helpers, existing public packaging/browser-test conventions,
and new neutral workbench code and fictional fixtures. No private original program,
conversation/corpus, customer records, operational mapping, deployment configuration,
credential, hardware identity, private path, model or third-party implementation was
selected. It does not clear any remaining private source family.

Legacy algorithms/schema and I/O helper bytes are retained. Optional transaction
callbacks wrap legacy import/review/export operations; absent callbacks retain the
original behavior. Source-root selection also supports a standalone focused package
while preserving the normal collection boundary. The browser/CLI shell, bounded
snapshots, session handling, private backups, reports and acceptance tests are fresh
implementation. MIT, copyright TheOutlandsDev; see [license](../LICENSE).

Python, SQLite, Playwright, Chromium and optional test dependencies are separately
supplied under their own terms. No dependency implementation, runtime or binary is
redistributed here. Existing public third-party notices elsewhere remain unaffected.
Future user inputs/outputs and operator assertions require their own privacy/rights
review before sharing; structural checks are not anonymization.
