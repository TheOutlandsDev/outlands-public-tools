# Source origins and selected publication scope

MIT first-party code, copyright TheOutlandsDev. The owner confirmed authorship
of the original systems and authorized sanitized implementation/concept release.

Five original modules supply the selected engines:

- Allocation models and deterministic planning/conservation functions.
- Versioned-order demand reducer, conflict/replay checks and event arithmetic.
- Lot proposal dataclass, sequence helpers and factor/whole-lot calculation.
- Operator request/state models and command transition function.
- Shipment-readiness decision tree, adapted from a customer-schema projection.

Original files remain untouched and are privately hash-recorded. Source origin
paths and exact selection ledgers are not part of the public package. The
application shell, instance contract, storage schema, browser UI, CLI, reports,
source packaging, docs, tests and fictional fixtures are authored for publication.

Adaptations remove implicit project searches, original data/config loaders,
customer contract identifiers, product-prefix constraints, fixed operating
policy values, customer source-sheet fields and live backend imports. New
explicit typed contracts replace them. Original pure calculation/transition
methods are retained; the public priority horizon is narrowed to the existing
output range, and boundary checks prohibit ambiguous or oversize inputs.

The `vendor/store_io.py` and `review_io_windows.py` snapshots are unchanged
first-party MIT helpers from the published Corpus Workbench (originally Dataset
Review). The source packager is adapted from the same public first-party app.
Required dependency terms remain separate; see [notices](../THIRD-PARTY-NOTICES.md).

No original settings, policies, customer schema/query, product/route mapping,
review identity, source inventory, endpoint, credential, workbook, record,
database, log, exported output, deployment script, runtime or asset is selected.
This focused adaptation does not clear the rest of the original application
family, historical instances, related analytics/database code or repository
history. Further modules require their own selection and review.
