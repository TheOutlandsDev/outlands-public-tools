# Validation and limits

The 60-test standard-library suite covers retained masking/preflight, neutral type/size/parameter contracts, XML/entity/external-content rejection, report fields, hash/path boundaries, independent Python join/sum results, literal bindings, SQLite authorization independent of preflight, immutable file hashes, explicit truncation, VM budgets, result refusal, real owned-child cancellation/reaping, parent timeout of a deliberately stalled child, active-worker shutdown, single-job policy, immutable revisions/artifacts, optimistic reviews, approval gates, CSV/HTML handling, state rollback, snapshot orphan retention, append-only/schema/backup controls, HTTP guards and native file rejection.

Twelve real Chromium tests exercise import, actual saved-query execution, revisions/stale drafts, report inspection/validation and explicit SQL transfer, XML rejection, literal result rendering, authorization refusal, VM-budget results, actual cancel, fresh pending review, comparisons, backup, truncation, stale-note retention, reviewed export and a narrow keyboard workflow. Fresh private instances use fictional data and refuse external requests. Automated interaction does not establish manual usability or complete accessibility conformance.

Local unavailable link creation is recorded as four skips plus one opposite-platform fixture. CI requires applicable native link cases and both suites on Windows/Ubuntu CPython 3.12/3.13. An unavailable local fixture is not a pass. JavaScript syntax, documentation references, shared catalog coverage and exact source pins are checked separately. Browser dependencies/runtimes install only into the test environment.

The fictional complete demo returns alpha 8/beta 11, filtered alpha 5/beta 11 and revised alpha 9/beta 12. It records two query versions, four artifacts, a passing one-dataset field validation, an approved seven-file export and a verified state backup. Independent clean ZIP replay checks every source byte/archive member, computes aggregates outside SQLite, verifies source revision/parameter bindings, report mapping/results, CSV/JSON consistency and every export length/hash. Physical SQLite files and query-plan details are runtime-specific; source ZIP bytes must match across platforms.

The idle child termination test stops a server and requires an explicit stopped-session assertion before reopening. Active owned-worker cancel/shutdown and a deliberately stalled-child deadline are tested separately. These do not prove hard-parent-kill cleanup, power-loss/mid-commit durability or a complete restore. Other excluded acceptance: hostile SQLite imports (not supported), hostile local process/filesystem races, shared/network-storage guarantees, full OS sandboxing, total process-memory quotas, multiuser/remote deployment, SQL Server compatibility, complete RDL schema/layout validation, report rendering, live databases, actual business records or universal spreadsheet/secret sanitization. Source/static evidence and fictional runtime results never clear unrelated original data or source.
