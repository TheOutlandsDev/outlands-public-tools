# Data and export contracts

Dataset fields are exactly `format`, `dataset_id`, `title`, `classes`, `split`. Format: `outlands-visual-dataset-v1`. IDs and class labels are bounded ASCII tokens; class IDs are unique integers 1–255. Split contains a token `seed` and positive integer `train_per_mille`, `validation_per_mille`, `test_per_mille` summing to 1000. Configuration is immutable and bound by canonical JSON SHA-256.

Partition: SHA-256 of UTF-8 `seed + NUL + specimen_id`; interpret the first eight hex characters modulo 1000, then use cumulative train/validation/test thresholds. All views sharing a specimen within a dataset share its partition. This grouping is not representative sampling: mislabeled specimens or duplicated content across different IDs can still leak. Different datasets have separate policies.

View import: `dataset_id`, `specimen_id`, `view_id`, `file`, `polygons`. File must be inside the selected private workspace. Canonical PNG and original-file hashes remain private. Same identity with different original bytes/proposal is refused; identical imports are idempotent. Ancillary metadata is not copied into the canonical image; the original inbox file remains untouched.

Polygons map every configured class ID as a string to lists of polygons. Each polygon is a list of integer `[x,y]` pixel-edge points, bounded by inclusive `[0,width]` and `[0,height]`. Do not repeat the closing vertex. Self intersections, non-adjacent touching, repeated vertices, zero area and out-of-bounds shapes are refused. Same-class polygons union; different classes overlap. Rasterization uses pixel centers and half-open vertical/left-inclusive, right-exclusive horizontal spans. Holes are not represented.

Correction: `dataset_id`, `specimen_id`, `view_id`, `expected_sha256`, `polygons`. Expected hash must match the latest annotation. Initial origin is `proposal`; saved corrections are `manual_correction` with immutable parent/version. Hash binds configuration, view/image identity, split, geometry, origin and version. Identical geometry creates a first manual correction; identical latest manual corrections are idempotent. Hashes are consistency checks, not signed provenance.

Review: `dataset_id`, `specimen_id`, `view_id`, `annotation_sha256`, `expected_version`, `status`, `training_selected`, `actor`, `note`, `checks`. Status is `pending`, `approved` or `rejected`; selection is a strict boolean. Checks are strict booleans `quality`, `privacy`, `rights`, `context`; approval requires all four and manual origin. Training selection requires approval and train partition. Review version starts at zero before the first record. A later annotation has its own pending review. Actor/note are private free text without authenticated identity.

Export format: `outlands-visual-export-v1`. Training includes latest approved manual corrections explicitly selected in train; evaluation includes latest approved manual corrections in validation/test. Old approvals do not qualify newer pending corrections. Selection holds the application lock throughout export. Each item contains canonical image, independent binary PNG per class and annotation/review JSON. Manifest binds configuration, implementation version, selected annotation/review versions, file lengths/hashes and mask convention. It states training/inference not executed. It is not signed and does not authorize sharing. Unknown future formats are not implicitly compatible.

Strict UTF-8 JSON rejects duplicate keys, nonfinite numbers, depth over 64 and raw input over 4 MiB. SQL is parameterized; schema/version are checked before application reads. Runtime state is private and excluded from the source package.
