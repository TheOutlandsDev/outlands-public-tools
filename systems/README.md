# Larger systems

The [Keep Awake](../tools/keep-awake/README.md) update validates bounded native
Windows request/Tk lifecycles using public source and invented faults. It does
not export machine layouts, runtime captures, configuration or private programs,
and does not establish idle sleep, security-policy or mixed-DPI acceptance.

The [Safe File Mover](../tools/safe-file-mover/README.md) adds Windows CLI/engine
guards and generated move/recovery/restore/purge fixtures. It does not export
original deployment tools, journals, recovery data, game assets or operational
records, and it does not establish GUI, live-share or production backup acceptance.

The [Markdown Document Builder](../tools/document-builders/README.md) adds
native Windows file checks and exclusive DOCX output while preserving its
public parser/layout and Linux behavior. Fictional package inspection does not
clear operational documents, logos, user content, private templates or records.

The [XML Recipe Inspector](../tools/xml-recipe-inspector/README.md) supports
Windows native input/new-directory output alongside its preserved POSIX and XML
logic. This public adaptation does not clear actual recipes, images, vendor
schemas/assets, derived records, private configurations or operational systems.

The [Dependency Lock Tools](../tools/dependency-lock-tools/README.md) now support
Windows native input checks and exclusive new output alongside the preserved
POSIX implementation. This public addition does not clear held environment
configuration, private dependency locks, package origins, records or artifacts.

The [Package Layout Checker](../tools/package-layout-checker/README.md) now
supports declared-file review on Windows through a separate native-handle
backend while preserving its POSIX protections. This public implementation
does not clear original private packaging applications, manifests, configuration,
records or third-party assets for release.

The [Offline Dependency Lock Diff](../tools/dependency-lock-diff/README.md)
compares a fresh selection of two supported public-format locks without
collecting an environment, installing packages or clearing private dependency
configuration, package origins, artifacts or redistribution rights.

The [Offline Source Inventory Diff](../tools/source-inventory-diff/README.md)
compares supplied saved reports for source-version and duplicate review without
opening inventoried bodies or selecting a canonical copy. It does not clear
held source archives, private inventories, origins or redistribution rights.

The [Offline Workflow Plan Checker](../tools/workflow-plan-checker/README.md)
reviews a fresh neutral task/prerequisite/state format. It provides static
consistency and dependency ordering without exporting a held worker contract,
executing tasks or clearing private orchestration/configuration and records.

The [Offline Backup Chain Checker](../tools/backup-chain-checker/README.md)
reviews a fresh neutral full/incremental dependency format. It complements the
independent-full retention planner; actual backup/server implementations,
private configurations, records and third-party assets remain held separately.

The [Dataset Review Manager](dataset-review/README.md) is included as a standalone private-store application. It implements import, exact deduplication, conservative group splits, review and approved export without bringing a historical corpus or model configuration into the repository.

The [Offline Assessment Record Contract Checker](../tools/assessment-record-checker/README.md)
checks a fresh neutral ledger format for declared relationships and workflow
consistency. It does not export or clear the assessment management application
below, ingest evidence, perform testing or verify outcomes.

The [Offline Assessment Workbench](../tools/assessment-workbench/README.md) adds
an empty-start private store, structured desktop/CLI drafts, history and guarded
import/export and logical cloning around that public format. It is fresh
application source; the held original assessment system, records, evidence and
live integrations remain separate and uncleared.

The [Offline Evaluation Metrics Calculator](../tools/evaluation-metrics-calculator/README.md)
adds arithmetic over a fresh aggregate-count format. It executes no model and
does not export or clear the broader AI application, corpus or configuration.
