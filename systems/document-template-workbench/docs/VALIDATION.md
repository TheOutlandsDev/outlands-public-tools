# Validation boundaries

Fictional core checks cover exact typed template/value/selection rules, marker
refusal, nonrecursive literal substitution, quantities, limits, revision lineage
and comparisons, historical previews, stale/concurrent requests, fixed OOXML parts,
neutral properties/ZIP metadata, Letter layout, repeated headers, widths/borders,
literal markup, line breaks/tabs, deterministic bytes and unknown-part refusal.

Artifact/schema/hash/type tampering, partial failures, orphan completed markers,
uncertain successful responses, current verification, reviewed handoff hashes and
private index backups are checked. An actual owned child is killed after a durable
started event and partial output; stale-session refusal, stopped recovery, retained
bytes, no adoption/replay and unchanged invented inputs are required. This does not
prove power-loss or hardware recovery.

Seven native fixtures cover hardlinked input/index/template/document, symlink
input/parent and an output-parent directory link. The last uses a real Windows
junction through PowerShell 7 or a POSIX directory symlink. Local filesystems may
skip fixture creation; CI sets `WORKBENCH_REQUIRE_LINKS=1`, requiring all seven.
Only the opposite-platform FIFO or stream-selector case skips in the matrix.

Actual Chromium acceptance covers save/edit/parent/compare, typed values, optional
and required sections, visible semantic tables/totals, preview pins, required
review, historical builds, real private DOCX downloads, exports/backups, stale/lost
responses, draft retention, read failures, literal markup, partial output, artifact
tampering, keyboard/narrow layout, history and owned shutdown.

Windows/Ubuntu Python 3.12/3.13 also run the complete CLI demo, JavaScript syntax,
source inventory, documentation checks and deterministic source ZIP. Exact ZIP
extraction/setup, independent XML/body/table/property/relationship oracles, file
hashes, private report manifests and journal backup replay must be verified before
publication. All four platform source archive digests must match the reviewed ZIP.

A separate Ubuntu job installs LibreOffice Writer/Poppler and generates invented
short and 44-row documents. It checks Letter PDF pages, expected text, every item
label and quantity total, then rasterizes every page. Every resulting PNG must be
visually inspected before release. Those artifacts are qualification evidence and
are excluded from the focused source package. Local Windows rendering was unavailable
because LibreOffice was not installed; its failure log is retained privately.

The browser semantic preview is not a pixel render. Microsoft Word rendering,
universal viewer/font fidelity, original operational documents, financial/business
accuracy, external services and production suitability are not established. Future
inputs and all generated documents/handoffs/index data remain private. No original
source, customer record, price, logo, credential or operational template is tested.
