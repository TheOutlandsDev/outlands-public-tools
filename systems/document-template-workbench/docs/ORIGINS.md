# Source origins

Fresh first-party MIT code, copyright TheOutlandsDev, informed by the remaining
owner-confirmed authored document-method catalog: explicit section selection,
styled headings/repeated table headers, and structured item/quantity tables.
The published Markdown Document Builder is a public behavioral reference, not a
dependency of this application. Its code and output format are not silently changed.

No original private source file is exported or executed. Original document programs,
operational covers/templates, section/pricing policies, source mappings, customer
identifiers, text, logos, workbooks, generated outputs and private configuration
remain held. This selected generic application does not clear the original family.

The workbench adds exact typed JSON contracts, literal substitution, immutable
template lineage/comparison, pinned semantic previews, a fresh constrained OOXML
writer/inspector, durable attempts, private exports, CLI/browser UI and fictional
platform/render tests. The native I/O helper files are unchanged first-party MIT
source from the public Import & Migration Workbench; its session/JSON/journal-store,
loopback web, test-runner and source-package patterns are adapted here.

The writer emits only the documented eight Office Open XML parts, without copying
Office templates or default-template assets. XML namespace/relationship identifiers
refer to public format conventions and are not network requests or operating
endpoints. Python, SQLite, Windows/POSIX APIs and optional Chromium/LibreOffice/
Poppler/PowerShell test tools are separately supplied under their own licenses.
No runtime, font, renderer, downloaded binary, model or third-party asset is bundled.
