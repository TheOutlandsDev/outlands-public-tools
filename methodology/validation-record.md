# Validation record

- Exact source/export revision:
- Runtime/platform/dependency versions:
- Synthetic fixture identity and expected behavior:
- Command or procedure, with sensitive values removed:
- Actual result and retained private evidence:
- Failed/skipped checks and reasons:
- Untested platforms and remaining uncertainty:

Use distinct labels: inspected, implemented, syntax checked, fixture tested, runtime tested, and accepted against named criteria. Simulated calls do not prove native behavior. A successful startup does not prove integration, concurrency, recovery or multiplayer operation. Never turn an expected result into an observed pass.

The [Offline Workflow Plan Checker](../tools/workflow-plan-checker/README.md)
can review declared prerequisite/state consistency. Record actual task execution
and acceptance as separate private evidence; declared completion and eligibility
are not proof of either result or authorization to act.
