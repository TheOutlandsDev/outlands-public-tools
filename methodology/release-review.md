# Release review

For [Environment Contract control/report I/O](../tools/environment-contract-checker/IO-SAFETY.md), preserve schemas and metadata-only target checks. Use invented controls, targets and reports; require native fixtures and verify new report bytes. Actual inventories, installed-program paths, credentials, observations and captures remain private. Presence is not runtime or publication acceptance.

For [Verified Transfers I/O checks](../tools/verified-transfers/IO-SAFETY.md), review the exact source inventory and an independent pin before packaging; audit the resulting payload separately. Preserve formats, exclusions and no replacement. Test only invented disposable trees. Real source/data manifests, credentials, records, backups and restores remain private.

For [Release Preflight file checks](../tools/release-preflight/IO-SAFETY.md), preserve external pins, manifest/launcher rules and plan-only output. Test invented packages and new reports on both platforms; actual manifests, deployment paths, arguments, credentials and reports remain private. Native I/O checks are not ownership or deployment acceptance.

For [Server Maintenance input checks](../tools/server-maintenance/INPUT-SAFETY.md), review only public source and invented requests. Preserve plan-only rules; require native Windows and POSIX fixtures. Real plans, player observations, endpoints, credentials and reports remain private; sampled file checks do not authorize publication.

For [Dataset Review store acceptance](../systems/dataset-review/docs/STORE-SCHEMA.md),
use generated canonical and mismatched stores. Do not convert or repair actual
stores as an audit fixture. Schema validity and approval assertions do not clear
data rights; preserve refused sidecars and failed initialization privately.

For [Dataset Review](../systems/dataset-review/README.md), keep actual stores,
reviewer/provenance metadata and exports private. A complete-looking failed
export is unconfirmed. Four review assertions and hashes do not independently
clear sharing rights; publish only a separate exact reviewed export.

For [Python Helpers](../tools/python-helpers/README.md), preserve JSON and
redaction contracts when hardening file I/O. Fixed errors and selected-key
redaction do not sanitize retained exception objects, unknown fields, free text,
decoded results or logs. Publish only a separately reviewed exact export.

For [Documentation Check](../tools/documentation-check/README.md), keep actual
reports private because relative names/line numbers can identify work. Compare
frozen grammar results against fictional fixtures when changing I/O; PASS is
limited documentation hygiene and never publication or rights approval.

For [Project Workspace](../tools/project-workspace/README.md), publish only a
separate exact reviewed export. Input copies and generated control/evidence
trees stay private. Check command success as well as bytes; a failed operation
can leave a complete-looking unconfirmed tree and an ineffective ignore file.

For [Public Release Audit](../tools/public-release-audit/README.md), retain an
independently frozen baseline when changing I/O. Review exact bytes and semantic
context: no pattern findings or matching manifests grant release approval.
Reports retain names/hashes that can identify private work; keep them and real
marker lists private.

For [Source Inventory](../tools/source-inventory/README.md), use fictional
trees and keep real reports private: names/timestamps/hashes can identify work.
Distinguish selected unnamed-data hashes from an atomic tree/ADS/ACL snapshot.
Retained or internally consistent reports can be unconfirmed after failure;
exclusions and user categories are not sharing clearance.

For [Keep Awake](../tools/keep-awake/README.md), distinguish simulated control
flow, native request returns, Tk lifecycle and actual sleep/policy acceptance.
Keep native runs short and captures private. Use fictional fault details and
verify cleanup on the creating thread; a local flag is not physical sleep proof.

For [Safe File Mover](../tools/safe-file-mover/README.md), use only generated
disposable trees for public examples and destructive regression tests. Real
journals, source/recovery copies, logs and history contain operational data and
stay private. Native fixture success is not live-share durability, GUI acceptance,
authorization, a full metadata backup or release clearance for original systems.

For the [Markdown Document Builder](../tools/document-builders/README.md), use
fictional input and inspect generated DOCX text, core properties and relationship
parts privately. Copied input/title and default-template fields remain. Neutral
properties do not establish anonymity, authenticity, sharing rights or Office
rendering acceptance. Keep real documents and generated outputs outside GitHub.

The [XML Recipe Inspector](../tools/xml-recipe-inspector/README.md) can exercise
fictional XML and report creation on POSIX or supported Windows local volumes.
Real recipes/reports retain identifying fields and geometry; keep them private.
Windows permissions inherit from the chosen parent and failed exports retain
unconfirmed output. Parsing and synthetic geometry checks do not establish
anonymization, vendor compatibility, measurement accuracy or sharing rights.

The [Dependency Lock Tools](../tools/dependency-lock-tools/README.md) can convert
fictional reports and check narrow-format locks on POSIX or supported Windows
local volumes. Keep actual report/lock names, versions, hashes and results
private. Windows outputs inherit parent ACLs and errors can leave unconfirmed
new files. Neither conversion nor validation verifies artifacts, dependencies,
origin rights, an installed environment or release readiness.

The [Package Layout Checker](../tools/package-layout-checker/README.md) can run
declared-file checks on POSIX or supported Windows local volumes. Select stable
fictional inputs for public examples; keep real manifests and findings private.
PASS does not inspect unlisted files, establish the exact publication set,
detect arbitrary secrets or clear ownership/licensing. Audit the actual selected
export bytes separately. Read the [Windows limits](../tools/package-layout-checker/docs/WINDOWS.md).

The [Offline Dependency Lock Diff](../tools/dependency-lock-diff/README.md)
can identify changed lock declarations for private release review. Keep actual
package names/hashes and results private; differences do not establish upgrade
direction, artifact authenticity, compatibility or vulnerability status.

The [Offline Source Inventory Diff](../tools/source-inventory-diff/README.md)
can compare saved report metadata and expose exclusion/coverage uncertainty.
Keep real comparisons private. Matching hashes or grouped names do not select
an authentic original, establish ownership or approve a source release.

The [Offline Record Ingestion](../tools/record-ingestion/README.md) reference demonstrates a fresh neutral contract and invented records. Keep real source adapters, mappings, accepted/rejected data and diagnostic reports private. A clean batch establishes contract validity only; it does not establish anonymization, business correctness or redistribution rights.

The [Offline Forecast Baseline Evaluator](../tools/forecast-baseline-evaluator/README.md) uses only clean public ingestion batches and generic baseline arithmetic. Keep real histories, predictions, scores, source mappings and business forecasting policies private. Prefix-only evaluation prevents the included predictor from seeing its holdout; it does not validate private data provenance, model selection or production usefulness.

The [Offline Notification Outbox Reference](../tools/notification-outbox/README.md) separates adapter acceptance, matching caller delivery assertions and uncertain attempts. Keep real messages, routes, keys, receipts and provider evidence private. Retryability is an adapter assertion, not independent proof of non-acceptance. Fake acceptance and caller reports do not establish real delivery, durability or exactly-once behavior.

The [Generic Data & Services Stack](../systems/data-services-stack/README.md) is reviewed as one complete application batch: reusable public cores, new neutral workflow/storage, fixtures, CLI, manifest and deterministic source ZIP. Treat every workspace, journal/history, input, hash, notification, receipt and export as private. Verify the exact package bytes alongside source/privacy review and platform/crash evidence. A source hash, fake transport or recovered review state does not clear original business source, authenticate provider evidence or authorize replay.
