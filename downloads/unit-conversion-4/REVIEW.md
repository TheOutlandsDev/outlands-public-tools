# Source bundle release review

The exact selection is four already public MIT tool directories at source commit `807328001893d82bb3daaa6349c4ebb787b91a76`. No private original implementation or dataset is read by the builder. A candidate artifact qualifies only when its ZIP hash matches `plan.json`, all member and nested source pins match, ZIP metadata is fixed, both privacy scanners report no errors or findings, and Windows/Ubuntu Python 3.12/3.13 builds and fresh fictional exercises return the documented outcomes.

The archive is deliberately narrower than the repository. It excludes unrelated catalog entries, complete Toolkit source, runtime packages, screenshots, logs, CI artifacts, user input and Git history. The manifest contains only member names, sizes, SHA-256 hashes, version and the public tool names. The MIT license attribution is the public TheOutlandsDev project identity. GitHub release and repository pages necessarily display public publisher and timestamp metadata outside the archive.

Real input, external service, device, production workflow and original private-family clearance are outside this review. A checksum proves byte consistency, not publisher identity.
