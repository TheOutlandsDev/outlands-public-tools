# Data & Services Stack — portable Windows x64

Compare the ZIP with SHA256SUMS.txt, **Extract All**, then open
**Data Services Demo.cmd**. Official Python 3.14.10 is included; supply a modern
browser. No Python installation, pip, account, administrator setup or PATH change
is needed. The outer ZIP is unsigned.

Follow **FIVE-MINUTE.txt**: preview six invented records, run a pinned baseline
forecast, inspect predictions 10/10/10 and three holdouts with MAE/RMSE 4, then
review a private three-file report. Follow a definite fake retry at tick 0,
refuse a premature attempt, record fake acceptance at tick 1, and retain an
accepted-but-unknown second attempt for review without replay. Matching caller
delivery assertions remain explicitly unverified. **Data Services Exercise.cmd**
runs 22 original CLI commands with independent numerical, result-export and
preservation checks in a new private directory. Five minutes is approximate.

Publication requires byte-identical Windows/Ubuntu Windows ZIPs and receipts,
eight packaging tests, all 101 original core methods on bundled Python
(100 pass, one opposite-platform skip; five required applicable native boundary
methods), and all 25 original Chromium methods on the separate Python 3.12 test

bundled Python server through empty startup, JSONL/CSV previews and runs, independent
metrics, private report hashes, fake retry and uncertain-outcome boundaries,
restart preservation, fresh report roots, narrow keyboard layout and owned-server
shutdown. acceptance.json records 18 stages and capture hashes. Ubuntu builds
but does not execute the Windows runtime.

The default demo journal persists across launches and is never reseeded. Each UI
launch makes a fresh private sibling report directory; earlier report folders
remain retained and are not rediscovered by the UI. Browser drafts and selection
do not persist. A result report is not a journal backup. Preserve the complete
stopped journal and all prior report roots separately. Recovery requires an
independent stopped-owner assertion, retains incomplete output and review states,
and performs no arbitrary repair, reset, replay or deletion.

**Fake transport only.** No real email, provider connection or delivery verification
is performed. Ticks are explicit integers; there is no autonomous scheduling,
background retry loop or automatic replay of uncertain entries. Baseline errors
over invented data do not establish useful real-data forecast accuracy. Private
reports omit original input text but retain saved results, job metadata and review
notes. Review assertions do not anonymize data or authorize public sharing.

One trusted local owner and bounded stable storage are assumed. Exactly-once
delivery, full backup/restore, hostile filesystem protection, distributed service,
universal ACL/volume support and power-loss durability are not established.
Manual Explorer/default-browser use on a separate Python-free PC remains
unperformed. Existing source, Toolkit and Windows releases remain unchanged.
