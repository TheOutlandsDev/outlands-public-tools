# Document & Template Workbench — portable Windows x64

Download the ZIP, compare its SHA-256 against SHA256SUMS.txt, Extract All, and open
**Document Demo.cmd**. Python 3.14.10 and SQLite are included; no Python, pip or
administrator installation is required. The outer distribution is unsigned.

Follow the included **FIVE-MINUTE.txt**: save the invented template, preview two
sections/two item rows totaling seven, observe an unreviewed-build refusal, explicitly
review and build, revise the heading and include notes, then reopen the original
unchanged. Saved templates, previews and builds persist across restarts. Unsaved
form drafts do not. **Document Exercise.cmd** automates the story using 18 original
CLI commands in a new private instance, with independent DOCX ZIP/XML checks.

The complete official CPython embeddable runtime and its license are retained; only

user database, credential, local configuration, generated document or raw log is
shipped in the ZIP. Every later instance, value and handoff remains private.

Publication requires matching Windows/Ubuntu package bytes and fresh Windows CMD,
source inventory, all 71 original core methods (70 pass, one POSIX-only skip, seven

Ubuntu builds the Windows ZIP; it does not execute its Windows runtime.

not Microsoft Word visual layout. The existing Toolkit exercise's LibreOffice page

processes and preserve the whole instance for complete recovery. Review assertions
