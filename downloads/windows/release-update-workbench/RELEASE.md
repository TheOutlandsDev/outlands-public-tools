# Release & Update Workbench — portable Windows x64

Compare the ZIP with SHA256SUMS.txt, **Extract All**, then open **Update Demo.cmd**.
Python 3.14.10 and SQLite are included; supply a modern browser. No Python
installation, pip, account, administrator setup or PATH change is needed.
The outer package is unsigned.

Follow **FIVE-MINUTE.txt**: capture two invented packages, retain five blockers,
inspect ADD 1 / REMOVE 1 / REPLACE 2 / UNCHANGED 1, review one exact manual plan,
export private evidence, verify that a new plan inherits no approval, revoke
future handoffs and reopen the saved decision. **Update Exercise.cmd** performs
34 original CLI calls with independent copied-file and handoff hash oracles.
Selected input files, copied snapshots and an invented target sentinel remain
unchanged. Five minutes is approximate.

Publication requires byte-identical Windows/Ubuntu Windows ZIP builds, eight
packaging tests, all 55 original core methods on bundled Python (54 pass, one
opposite-platform skip; eight required native fixtures), actual Windows CMD,
the automated exercise, Chromium blocker/approval/new-plan/revocation flows,
private handoff hashes, persistence, narrow keyboard layout, package preservation
and owned-server shutdown. Observed results and fictional capture hashes are
in acceptance.json. Ubuntu builds but does not execute the Windows runtime.

**Target updates stay plan-only.** No package installation, payload execution,
target-file change, target-service control, host discovery or network probe is
performed. A snapshot is a copied package, not measured target state or proof of
a recoverable backup. Comparison-policy statements are operator assertions.
Dependency checks inspect limited declarations without resolving packages,
checking advisories or establishing runtime compatibility. All actual update,
acceptance and recovery checkpoints remain NOT_PERFORMED.

Approval applies to one exact plan. Revocation blocks later exports but cannot
recall already exported files. Handoffs omit payloads while retaining private
names, hashes, launcher/dependency declarations and journal inputs. Index backups
omit payload/artifact files and are not complete instance backups; preserve the
whole stopped instance separately. Manual Explorer use on a separate Python-free
PC and real operational acceptance remain unverified. Earlier source, Toolkit
and Windows releases stay unchanged.
