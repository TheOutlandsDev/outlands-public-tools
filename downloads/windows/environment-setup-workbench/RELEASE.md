# Environment & Setup Workbench — portable Windows x64

Download the ZIP, compare it with SHA256SUMS.txt, **Extract All**, then open
**Setup Demo.cmd**. Python 3.14.10 and SQLite are included; supply a modern browser.
No Python installation, pip, account, administrator setup or PATH change is needed.
The outer package is unsigned.

Follow **FIVE-MINUTE.txt**: save an invented profile, evaluate a missing runtime
declaration, compare a satisfied declaration, inspect nine checks and the ordered
manual plan, observe missing review being refused, save/reopen a reviewed plan
and inspect a six-file private handoff. **Setup Exercise.cmd** automates 19
original CLI commands with independent artifact and hash checks in a new private
instance. Five minutes is approximate.
