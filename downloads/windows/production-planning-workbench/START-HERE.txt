   Python 3.14.10, SQLite and five pinned Pydantic dependencies are included.
   No Python installation, pip, account, administrator setup or PATH edit.
   Supply a modern browser. This is an unsigned local advisory application.

   160 remaining = 25 assigned dock + 85 allocated WIP + 50 uncovered; 3 lots
   are suggested, never reserved. Clearance is a declaration, not evidence.
4. Keep the console open. Use Stop local UI before copying or maintenance.
   Reopen Planning Demo.cmd to retain saved revisions and local review.

After interruption preserve all files, independently confirm every instance
process stopped, inspect retained output and use --cli recover
--confirm-stopped only after that review. No automatic reset, recovery or
deletion occurs. This is a single trusted local operator, loopback-only tool.

BOUNDARIES
No connection to manufacturing, shipping, identity or other external systems.
Plans cannot start production, reserve lot IDs, establish independent shipping
evidence or authorize shipment. A review alias is not authenticated identity.
The database backup omits inbox inputs and existing reports. For a complete
preservation copy, stop every instance process and retain the entire private
instance. No automatic restore, encryption or full-backup certification.
