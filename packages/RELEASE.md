## Qualification

Windows and Ubuntu independently build all nine ZIPs. Exact matching checksum
lists are required before publishing the verified Windows artifacts. An independent
release checker verifies all 12 assets, source and packaging pins, manifests,
component coverage and original Git bytes. The suite exercises three fictional
methodology examples, all eight family workshops (33 underlying CLI commands),
and the four newly included workbenches' fictional CLI demos from a fresh complete
archive. Consult the actual Actions run; configuration alone is not a pass.

Test Evidence's supplied demo explicitly runs four invented Python checks,
including expected refusal, mismatch and timeout. Evidence review does not make
failed checks pass. The other demos retain their documented execution boundaries;
Backup Recovery restores its own fictional bytes and deletes nothing. All private
workspaces, generated reports, histories, exports, backups and raw audit outputs
stay outside the source packages.

These are source/archive and fictional CLI workflow checks. They do not rerun
every application's GUI, hardware, service or production acceptance. The preserved
application README/validation records define their individual limits.

## Download and use

Download a ZIP and SHA256SUMS.txt from this release, verify its checksum, Extract
All into a new directory, then read START-HERE.md. Supply the selected module's
runtime/dependencies separately. The complete source package and the eight source
families include no installed Python/Node runtime, downloaded dependency binaries,
model weights, game payloads, credentials, real data or private operational state.
The three reviewed original fictional Local Site Builder screenshots retain their
source provenance. Hashes establish consistency, not publisher signatures.

[Portable Windows applications](https://github.com/TheOutlandsDev/outlands-public-tools/blob/main/docs/START-HERE.md)
remain separate downloads with their own included runtimes and acceptance records.
The source snapshot and packaging controls are independently pinned; preserved
repository docs may describe older/newer online indexes. PACKAGE-MANIFEST.json
and packages/catalog.json remain authoritative for this archive's exact contents.
