Download the complete source toolkit or one of eight family archives. The frozen
public snapshot contains 62 tool folders and six systems, with unchanged source,
tests, fictional fixtures, dependency notices and validation limits.

Each download adds START-HERE.md, an exact PACKAGE-MANIFEST.json and three worked
methodology records. Complete/release-QA archives run an eight-command fictional
walkthrough: source inventory and change review, equivalent/changed dependency
locks, and a deliberately missing document followed by a verified correction.

Use SHA256SUMS.txt before extraction. catalog.json and release-matrix.json record
every download URL, count and checksum. Source revision is
d34fd2d8b989352624294f9c45ee75f582e005cc; manifests separately identify the packaging
revision. Later commits and in-progress PRs are outside this fixed snapshot.

Python/Node.js/PowerShell/.NET, optional dependencies, Tk, native drivers, models
and games are installed separately according to each module's guide. This is
source distribution; no installed environment, private instance, credentials,
operational records, logs, downloaded dependency or game/runtime binary is bundled.

Windows/Ubuntu packaging CI verifies exact inventories and fresh-extraction
fictional workflows. It does not qualify every live device, GUI, service,
deployment or recovery scenario. Consult each application's retained evidence.
