# Provenance and license scope

Offline Assessment Record Contract Checker follows a fresh neutral public
specification, with authored fictional ledgers and a reviewed public MIT input
reader pattern. It is not an importer for a held assessment application, private
schema, evidence store or execution-history database.

The runtime and three JSON examples retain exact Git bytes from baseline
`63c35b86d36c7c5509dfb2584b09fcfae8c7b59e`. The runtime already displayed version
0.1.0. Standalone packaging introduces no reference/revision/outcome/result,
evidence/target verification, record mutation or path repair. New source
attributes preserve reviewed bytes; no normalization makes protected hashes pass.

All 44 method ASTs and 117 total assertion calls remain preserved: 116 assertions
inside tests plus one in the reader-error helper. Thirteen original/shared
helpers retain namespaced provenance: `local:submission`, `local:finding`,
`local:retest`, `local:records`, `local:changed_stat`,
`local:RecordFixture.metadata`, `local:RecordFixture.selected_records`,
`local:RecordFixture.by_id`, `local:RecordFixture.invoke`,
`local:RecordFixture.reader_failure_traceback`, `shared:load`,
`shared:Fixture.setUp`, `shared:Fixture.write`.
Explicit `python-ast-fields-json-v1` preserves full AST fields across interpreter
versions without weakening within-version equality. Only needed shared scaffold
is retained. In-process tests import the actual extracted module; an original
ROOT-relative subprocess uses an owned collection-shaped exact runtime copy,
verified before/after. Copied CLI tests use one copied script. No duplicate
runtime, donor or unrelated shared application is shipped.

Selected source, tests, docs and fictional examples retain the full
[MIT license](../LICENSE) and TheOutlandsDev identity. Standalone preparation,
qualification, documentation and fictional consumers used AI assistance without
exclusive-authorship claims. Python/stdlib and OS mechanisms retain their own
terms and are not bundled as binaries. Operator inputs/third-party material
are not relicensed.

No held assessment application, private schema, target, identity, narrative,
evidence, credential, source build or operational record was selected, read,
copied or executed. Actual ledgers/results and completed evidence remain private.
The private assessment application and unrelated historical rights stay uncleared.

Typed references, strictly later same-series revisions, explicit retest ownership
and highest declared numeric revision are metadata conventions. Highest includes
untested declared submissions, not actual chronology/build identity/latest testing.
Pending/not_run and closure_claimed/not_observed are claims, not performed
actions or proof of a fix. Invalid selected relationships block before latest/
outcome checks after ownership resolution; bad unselected history still requires
global review. Open/null records can be consistent without observed assessment.
Own record IDs/statuses/evidence remain identifying despite omitted references,
series/revisions and raw state/outcome fields.

The single reader samples identity after absolute normalization; it is not an
original-suffix precheck, atomic snapshot, hostile-filesystem or alias guarantee.
Use canonical trusted paths; no authorization, isolation or security proof follows.
Fictional Windows probes on Python 3.12.7/3.15.2 accepted canonical, leaf-dot,
leaf-space and parent-dot forms with exit 0/DECLARED_RECORDS_CONSISTENT;
parent-space returned 2/INPUT_PATH_INVALID. Input/runtime bytes were retained.
Mixed measured normalization behavior supplies no blanket suffix-refusal claim.
