# Changelog

## 0.1.0

- Initial standalone source ZIP for the existing single-script assessment
  declaration checker, retaining exact schemas, typed references, numeric
  revision/selection/outcome rules, ordered results, fixed errors and MIT license.
- Standalone guidance separates internal consistency from executed assessments,
  performed retests, evidence quality, fixes, authorization, isolation or security.
  Open and pending declarations can be consistent without claiming closure.
- Qualification selects fresh Windows/Ubuntu Python 3.12, 3.13, 3.14 and 3.15.2
  without pip/distributions, independent committed-source ZIP/build-manifest
  reproduction and optimized-helper refusal. Actual outcomes belong to validation.
- Preserve 44 original test method ASTs, 117 total assertions (116 in tests and
  one in a helper) and thirteen namespaced local/shared helper ASTs using canonical
  field encoding. A ROOT-relative original subprocess uses an owned hash-verified
  temporary runtime mirror; no duplicate runtime/donor/unrelated application ships.
- Preserve runtime and all three original JSON controls at exact baseline Git
  bytes. Post-normalization path checks remain unchanged; no original-suffix,
  relationship, workflow, runtime-verification or record-mutation fix is added.
  Measured Windows canonical/leaf-dot/leaf-space/parent-dot acceptance, with
  parent-space refusal, is disclosed without a blanket suffix-refusal claim.

No interpreter/dependency binary, actual ledger/result, evidence/attachments,
operational record, private source or raw diagnostic log is part of the ZIP.
