# Validation and interpretation limits

The dataset-integrity-checks workflow qualifies Python 3.12/3.13 on Windows and Ubuntu,
requiring native hardlink, parent symlink/junction, changed-input and overwrite checks.
Only opposite-platform methods may skip. Local volume skips are not native proof.

Known-answer/adversarial tests cover partition/hash/group overlaps, content-label
conflicts, complete identity accounting, withheld partial snapshots; absent and
disagreeing reviews, exact matched-pair denominators, three-reviewer pair weighting,
ambiguous slots and stale item revisions; full-record approval pins, policy/taxonomy
changes, explicit exclusion precedence, held-out records and missing/rejected approvals;
exact slice thresholds, zero minima, duplicate identity versus duplicate membership,
explicit overlaps, missing cases, unknown references and per-label zero counts.

Standalone CLI acceptance copies each directory independently, verifies source pins,
runs examples, writes fresh reports, refuses overwrite/source-tree output, checks raw
input hashes/fixed errors, and verifies no input mutations or target artifacts. The
connected invented HVAC flow checks four records, eight unanimous categorical reviews,
two approved training records and two held-out evaluation cases. An explicit test-only
operator adapter passes the cohort to the existing public Candidate Evaluation Gate
Planner; baseline accuracy is 1/2 and candidate 1/1 from supplied predictions, with no
inference. Separate acceptance proves a training approval does not clear a declared
train/test equipment-group overlap. There is no runtime dependency between tools.

These synthetic checks do not establish authentic data/approval provenance, correct
labels, representative sampling, real independence, absence of undeclared leakage,
privacy, rights, generalization, statistical significance or production suitability.
Original private source, schemas, training rules, models, records, configurations and
assets were not consulted or selected. No export, training or operational changes.
