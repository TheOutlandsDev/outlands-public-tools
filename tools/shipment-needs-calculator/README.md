# Offline Shipment Needs Calculator

Filter shipment records, total open demand, and identify active products
using the earliest retained ship date. The package includes the original
calculation logic, all 12 test cases, and a fictional five-row comparison
case with a matching part-to-modality mapping.

- [Download the source ZIP, checksums, and validation records](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/shipment-needs-calculator-v0.1.0)
- [Run the fictional comparison](SETUP.md)

Qualification covers Windows and Ubuntu with Python 3.12.16 and 3.15.2 and
pinned Pydantic 2.14.3. The calculation reads local data and runs offline.
