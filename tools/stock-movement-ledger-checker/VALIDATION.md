# Validation and interpretation limits

The stock-fulfillment-checks workflow qualifies Python 3.12/3.13 on Windows and Ubuntu.
Native hardlink, linked-parent, changed-input, fresh-file and overwrite fixtures are
required. Only opposite-platform methods may skip; local volume skips are not native proof.

Known-answer/adversarial tests cover opening/receipt/issue/adjustment conservation,
negative intermediate balances, future/missing histories, ordinal ties/gaps/reversal
and exact stock pins; inclusive inbound horizons, pending/cancelled/released/overdue
claims, aliased sources, exact item/unit, negative positions and stale snapshot nulls;
strict trigger boundaries, upward integer multiples, cap withholding, zero caps,
missing/stale policies and extreme signed deficits; full/partial/excess/missing receipts,
multi-shipment order coverage, ambiguous content/receipt slots, order/manifest revisions,
item/unit checks and visible unfulfilled orders. Every identity list checks complete
duplicate/conflict/rejected-row accounting and scope withholding. Public JSON/I/O helper
tests preserve source-tree, overwrite and fixed-error protections.

Actual standalone acceptance copies each tool separately, verifies source pins, runs
examples, writes fresh reports, refuses overwrite/source output, checks raw-input pins/
fixed errors and verifies unchanged inputs/no action artifacts. A connected invented HVAC
flow reviews a stock ledger, explicitly adapts a new current stock snapshot, computes
position and a capped-policy quantity proposal, then independently reviews declared
order/shipment receipt coverage. Overdue inbound, capped proposals and short receipts
remain review-required. A separate explicit adapter calls the existing public Material
Allocation Coverage Checker for a declared reservation and overreservation counterexample;
its engine is not duplicated or imported into these modules. A game crafting-token
ledger fixture contains no game assets, profiles or executable scripts.

These synthetic checks do not establish physical stock, complete business records,
genuine inbound eligibility, actual demand, correct replenishment policy, delivery,
privacy, rights or production suitability. Original private code, policies, schedules,
records, paths, credentials, customer/supplier identities and operating details were not
selected. No purchases, reservations, stock updates or shipment actions are performed.
