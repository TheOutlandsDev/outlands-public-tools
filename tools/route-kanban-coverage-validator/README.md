# Offline Route-to-Kanban Coverage Validator

Check a saved flow XML against a product's operation map and separate assignment rules. The report keeps steps in route order and checks both direct and product-specific assignments.

See the [usage guide](SETUP.md) for the fictional 38- and 40-step examples and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/route-kanban-coverage-validator-v0.1.0) for the source ZIP, checksums, and validation records.
