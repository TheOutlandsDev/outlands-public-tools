# Validation and interpretation limits

The cache-retry-checks workflow qualifies Python 3.12/3.13 on Windows and Ubuntu,
requiring native hardlink, linked-parent, changed-input, new-file and overwrite checks.
Only opposite-platform methods may skip; local volume skips are not native proof.

Known-answer/adversarial tests cover canonical key material, missing/unknown dependencies,
namespace/version pins, input/content conflicts and aliases; exact expiry/invalidation
boundaries, future creation, persistent snapshot invalidations, stale/future references
and ambiguous cache slots; capped delay arithmetic, exact due boundaries, zero delays,
unknown/missing receipts, over-cap and early histories, forbidden transitions and policy
pins; selected key/payload/operation/result reconciliation, state/result conflicts,
redundant claims, aliases, unresolved outcomes and legitimate terminal failure claims.
All identity lists preserve complete row accounting without latest-value selection.

Standalone CLI acceptance copies each directory independently, verifies source pins,
runs examples, creates fresh reports, refuses overwrite/source-tree output, checks raw
input pins/fixed errors and verifies no input mutations or target artifacts. A connected
invented HVAC exercise validates cache key material, reviews an expired/invalidated
snapshot at ordinal 40, explicitly binds a hypothetical refresh operation and reviews
a known-failure retry history due at ordinal 15. The ledger reconciles that supplied
failed claim without proving execution or authorizing retry. Separate unknown-outcome
acceptance blocks manual retry readiness and leaves ledger claims unresolved. A game
build fixture uses only invented dependency fingerprints, not assets or build commands.

These synthetic checks do not establish real cache state, authentic invalidations or
receipt histories, actual execution counts, real delivery, provider behavior, privacy,
rights or production suitability. Original private code, schemas, policies, caches,
records, paths, credentials and operating configuration were not consulted or selected.
No real cache mutation, retry, provider call, database write or target update.
