# Offline Game Server Configuration Validator

Validate saved declarations for expected runtime state, local HTTP or HTTPS
health URLs, and supported player probe types and ports. The command
reads a selected JSON file using the Python standard library. Diagnostics
describe the rejected field or rule without repeating input values.

- [Source ZIP, SHA-256 checksums, and validation records](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/game-server-configuration-validator-v0.1.0)
- [Usage guide and fictional configuration](SETUP.md)

All five original cases are preserved with fictional configurations.
Qualification covers Windows and Ubuntu with Python 3.12.16 and 3.15.2.
