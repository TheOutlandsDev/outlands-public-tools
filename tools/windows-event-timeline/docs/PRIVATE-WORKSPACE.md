# Private saved-event workspace

Keep explicitly selected, stable regular local JSON or XML metadata exports outside the extracted source. All selected files in a run use one explicit format. Qualification uses fictional saved metadata and does not query live event logs, decode EVTX/EVT binaries, invoke export commands or use real logs. Historical EXPORTING instructions are a separate manual workflow, not an action performed by the inspector or qualification.

This tool's own bounded XML reader and JSON helper are retained. XML permits encoded CR as text while identifying-field validators reject controls. JSON has its own structure budgets and does not inherit the XML text-line cap. No native XML parser or external resource resolution is used. Raw messages, payload/security/user data and input filenames are omitted; computer names remain internal even with details. Details expose supported canonical UTC/provider/channel/record identifiers. Hashes, positions, group IDs and structure remain identifying, so omission is not anonymization.

Timestamp arithmetic uses exact 100 ns integer ticks and explicit known offsets. Decimal-string intervals and record IDs preserve precision. Stable ties preserve input order without establishing causality. Grouping and gap thresholds are metadata observations, not diagnosis or event-loss proof. Record-ID duplicate/conflict checks require declared computer/channel/ID and stay within each selected file. No cross-file identity, host authenticity, clock accuracy, completeness or causal diagnosis is verified. Empty supported scope does not establish completeness.

Choose an existing parent you control and a fresh output name. Regular-file/link/alias checks, stable-input checks and cooperative JSON/XML/input/report bounds are not an OS sandbox, hostile-filesystem transaction, atomic snapshot or hard I/O deadline. Failed writes may leave a new partial report directory; preserve it and choose a fresh destination after fixing the cause. Unsigned hashes/manifests establish scoped consistency, not authenticity or host attribution.

The source release includes original MIT code, fictional examples, tests, packaging/bootstrap and qualification methods. Obtain CPython separately. No interpreter, native XML implementation, real log/export, binary event file, operational report, raw log, credential or third-party implementation is bundled.
