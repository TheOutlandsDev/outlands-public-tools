# Provenance and MIT scope

A local Test-WebcamStream.ps1 helper counted selected Windows event IDs around a test interval. This publication uses that generic event/time review use case in a fresh offline export parser. It contains none of the original camera capture, live query, private paths or device selectors.

The owner identified the local helpers as personal work. Original helpers remain
intact and fingerprinted in the private review record. Public parsers, reports,
tests, guides and fictional generators are fresh original code with reused
first-party MIT file/report infrastructure. Only generic mechanisms are retained;
no real logs/configurations, vendor implementations, device recipes, proprietary
templates, credentials or private report bytes are included or relicensed.
This selected-source review is not independent proof of every historical source's
exclusive authorship.

The Windows reader derives its original restricted XML infrastructure from the collection VINTF tool and extends numeric CR handling for discarded event payload text. It does not port a third-party parser.

MIT covers this original code/docs/tests and generated fictional examples.
Python remains a separately installed runtime under its applicable terms; no
runtime/parser package is bundled. Inspected inputs retain their own rights.
No upstream implementation is copied or granted a new license by inspection.

Format background was checked against primary sources on 2026-10-25; this
implementation has its own narrower documented subset:

- [Primary format reference 1](https://learn.microsoft.com/en-us/windows/win32/wes/eventschema-eventtype-complextype)
- [Primary format reference 2](https://learn.microsoft.com/en-us/windows/win32/wes/eventschema-timecreated-systempropertiestype-element)

Validation uses generated temporary data only. Live Windows log collection,
actual property state, filesystem permissions/policy and device deployment are
not part of the automated tests or source-publication evidence.
