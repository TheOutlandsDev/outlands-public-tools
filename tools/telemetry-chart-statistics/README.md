# Offline Telemetry Chart Statistics and Formatting

Summarize numeric sample series, choose readable chart axis ceilings, and
format byte counts, transfer rates, and durations. The two modules use only
the Python standard library and work with local data.

- [Download the source ZIP, SHA-256 checksums, and validation records](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/telemetry-chart-statistics-v0.1.0)
- [Run the synthetic example](SETUP.md)

The source ZIP preserves both original modules and all five original tests
byte-for-byte. Qualification covers Windows and Ubuntu with CPython 3.12.16
and 3.15.2.
