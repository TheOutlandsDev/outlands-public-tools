public MIT collection on 2026-10-25, with AI assistance. A private intake
prototype supplied only the high-level use case. Its source, business names,
policies, records, permissions model, branding, contacts, evidence, approvals and
assets were not copied into this package. No existing private prototype is
relicensed or replaced by this release.

The selected tracker code, tests, documentation and fictional examples are
original release work under the included MIT license. Required runtime components
(Python, SQLite and Tcl/Tk) are imported from the user's installation and retain
their upstream terms; their implementation and binaries are not bundled. There
are no pip package dependencies, copied vendor assets, fonts or third-party
application code in this tool. Owner-reported authorship and AI assistance are
not an independent guarantee of exclusive authorship.

Source distribution is exactly the source-check allowlist plus its manifest.
It excludes all SQLite databases, reports, backups, customer information, local
paths, credentials, installed runtimes and generated fixture outputs. Tests and
the optional demo create their own fictional records at runtime. Root collection
licensing does not grant rights over a user's input records or third-party work.
