# Offline Lot-Start Reservation Cancellation Preview

Preview cancellation of a saved lot-start reservation. Show the resulting state, retained lot IDs and proposed audit event. Replaying a saved cancellation preserves its reason and emits no second event.

See the [usage guide](SETUP.md) for a fictional example and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/lot-start-reservation-cancellation-preview-v0.1.0) for the source ZIP, checksums and qualification records.
