# Provenance and release boundary

The owner has a local C# `chain1` educational prototype with block hashing,
wallet and network experiments. A read-only review identified a reusable
hash-chain teaching/use-case concept, while its transaction, signing, balance
and network mechanisms needed substantial redevelopment. The public Hash
Journal is a fresh original implementation of a smaller offline event-journal
use case. It is not a production-currency release of that old project.

No historical wallet, transaction implementation, TLS setup, private key,
certificate, node configuration, operational record or original project file
was copied into this module. Original source-path hashes are retained privately;
the old source remains unchanged and is not retroactively relicensed by this
publication. No existing attribution or license notice was removed.

The new C# core, CLI, fixture harness, documentation and fictional examples were
authored for the requested public cleanup batch, with AI assistance. The owner
authorized MIT publication of eligible original work in OUTLANDS Public Tools.
Owner-reported personal authorship and this selected-source review do not prove
exclusive ownership of unrelated historical material.

The .NET SDK/runtime are installed separately. Using their standard-library
interfaces does not make their implementation original OUTLANDS work. No
runtime, dependency package or vendor implementation is bundled. Required
external notices remain applicable to any separately distributed runtime.

The explicit source manifest covers the selected public source only. Build
products, private journals, original-path records and local validation receipts
remain outside that source selection. There are no historical event datasets
or credentials in the generated fixtures.
