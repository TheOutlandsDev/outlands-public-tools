# Private chat qualification workspace

Use a new owned private directory outside the extracted source for fictional sessions, transcripts and acceptance outputs. Real prompts, responses, installed-model inventories, server logs and environment records remain private. Sessions are clear text, not encryption, anonymization or secure erase. POSIX fresh creation requests owner-only permissions; Windows inherits directory ACLs. Existing sessions are never replaced. Cooperative path checks do not eliminate hostile filesystem races; failed writes may leave a fresh partial file.

The offline help/demo opens no server/model/session and makes no HTTP request. Only explicit --connect commands use a selected loopback HTTP endpoint. Qualification starts disposable loopback HTTP fixtures on ephemeral ports, records exact authored requests/responses and then shuts them down. These are not Ollama, a model or real inference. No default Ollama port or independently running backend is contacted by acceptance. Output stays inert terminal text; there is no tool, shell, browser or arbitrary code execution facility.

All eight inference/backend flags remain false: actual Ollama used, real-model inference verified, model quality verified, GPU compatibility verified, backend cloud isolation verified, models downloaded, Ollama servers installed/started and real conversations used. Loopback routing and obvious cloud-name refusals do not attest to a backend's outbound behavior, logging, model provenance or licensing. Obtain and configure any real server/model separately under its own licenses; that is separate acceptance.

Keep original inputs unchanged and use fresh explicit save destinations. Character budgets are not token estimates. Context trimming retains whole user/assistant pairs and an initial system message; failed turns do not commit partial history. A socket timeout is not a hard whole-process deadline, and client interruption does not prove backend cancellation. Review raw session/transcript data privately before sharing.

The public release contains original MIT source, fictional examples, tests, the source builder, pinned Python preparer and qualification methods. It includes no interpreter, Ollama binary, model weights, private transcript, credential, raw operational log or private evidence packet. Hashes/manifests establish scoped byte consistency rather than authenticity, confidentiality, inference quality or readiness of a real model.
