# Changelog

## 0.1.0 — 2026-10-25

- Rebuilt the local Stephen/Steven chatbot use case as an original standard-library
  terminal client for a separately supplied Ollama server/model.
- Added explicit connection opt-in, installed-model selection, bounded conversation
  context, strict session import and fresh-file saves.
- Added loopback endpoint restrictions, disabled proxy/redirect use, bounded JSON
  handling and terminal-output escaping.
- Added an offline fictional demo, generated tests, HTTP fixtures, documentation,
  dependency/provenance records and public suggestion forms.
- No model, environment, private conversation or server configuration is bundled.
  Real model inference remains outside the recorded validation.
