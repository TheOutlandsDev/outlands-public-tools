# Offline Player Activity History Reporter

Build an activity history from saved daily totals, historical baselines,
archived records, and state observations. The report keeps player-hours
and connection-hours in separate totals. Availability-only records can
show state changes and always contribute zero activity.

- [Source ZIP, SHA-256 checksums, and validation records](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/player-activity-history-reporter-v0.1.0)
- [Usage guide and fictional example](SETUP.md)

This offline CLI uses the Python standard library. The qualification workflow
targets Windows and Ubuntu with Python 3.12.16 and 3.15.2.
