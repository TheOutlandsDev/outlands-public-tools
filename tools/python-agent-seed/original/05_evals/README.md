# Evaluation Tasks

Each eval contains:

- `task.md`: instructions for the coding agent.
- `starter/`: code the agent may edit.
- `tests/`: tests the result should pass.
- `scoring.md`: rubric.

These evals are intentionally small. They are for first-run behavior testing, not comprehensive benchmarking.

## Suggested scoring

- Correctness: 40%
- Tests pass: 25%
- Type clarity: 15%
- Security: 10%
- Minimality and maintainability: 10%
