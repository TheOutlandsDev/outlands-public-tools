# Contributions and suggestions

Feature ideas, clearer guides and small fictional bug reproductions are welcome
through the [repository issue forms](https://github.com/TheOutlandsDev/outlands-public-tools/issues/new/choose).
Include Python/OS versions, the source commit, expected behavior, actual fixed
codes and a tiny generated example. Never attach real firmware, identifying
reports, credentials, device identifiers or third-party files you cannot share.

Propose format expansion with primary specifications, explicit bounds and tests
for malformed input. Keep extraction, signature claims, device writes and
bootability assertions outside this metadata-only tool. Preserve MIT notices for
original collection code and retain applicable notices for any separately
proposed dependency. Run the test suite and source gate described in the README.
Source manifest updates must follow review; do not regenerate a manifest to
hide an unexpected change.
