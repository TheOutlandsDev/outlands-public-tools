# Provenance and license scope

A retained personal webcam troubleshooting wrapper supplied the use case for
USB connection observation. That wrapper has fixed local paths, ETW provider
setup and a camera-probe invocation. This public program is a fresh original
implementation of explicit present-only PnP polling and a neutral observation
model. No original wrapper body, paths, device identities, trace files, camera
probe implementation or historical diagnostic dataset is copied here. Its
original bytes remain unchanged and fingerprinted in the private review record.

The new Python model, bounded Windows adapter, CLI, Tk desktop, tests, guides
and fictional examples are original MIT work with AI-assisted development.
The inspection_support.py helper and its standalone tests are first-party MIT
reuse from OUTLANDS Public Tools. Historical ownership claims are not independent
proof of exclusive authorship. This package does not clear unrelated held work.

Primary references used to define the implementation boundary:

- [Microsoft Get-PnpDevice](https://learn.microsoft.com/en-us/powershell/module/pnpdevice/get-pnpdevice)
- [Python subprocess](https://docs.python.org/3/library/subprocess.html)
- [Python Tkinter](https://docs.python.org/3/library/tkinter.html)

No Microsoft/Python/Tk implementation, runtime, driver, model, native capture or
third-party fixture is bundled or relicensed. Separately supplied components
retain their applicable terms. MIT covers this original app, authored docs/tests
and fictional fixture design, not an inspected device, Windows or arbitrary
imported records. No paid API, hosting, account or key is required by the app.

Public examples contain invented booleans, relative elapsed times and fixed
codes. Real device lists, identifying runtime metadata and native logs stay
private. Ordinary GitHub source/commit metadata and required notices remain.
See the validation guide for the difference between generated tests, native
enumeration and an actual physical disconnect/reconnect test.
