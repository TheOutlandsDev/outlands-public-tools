# Contributing and suggestions

Bug reports, interface improvements and supported-format proposals are welcome
through the [app forms](https://github.com/TheOutlandsDev/outlands-public-tools/issues/new/choose).
Include OS/Python/Tk version, source commit, exact command or UI steps, expected
behavior and a minimal fictional replay sequence. State whether evidence is a
demo, generated test, saved sample or an actual native observation.

Do not attach actual device lists, instance IDs, serial-like identifiers, native
logs, private paths, customer records, credentials or unreviewed session reports.
Relative timing can identify a real session even when names are absent. Do not
claim a cause or complete USB event coverage from polling alone.

Run the source gate and relevant tests. Preserve MIT notices and scope. Tests
must not reset/unplug devices, change drivers/security/power settings, record
media or start live collection by default. Any new data field or backend needs
an explicit privacy/rights review, generated fixtures and honest acceptance
limits. Do not weaken a failed guard or skip native requirements to claim a pass.
