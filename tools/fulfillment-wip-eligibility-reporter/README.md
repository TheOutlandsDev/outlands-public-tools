# Offline Fulfillment WIP Eligibility Reporter

Separate verification lots from eligible production supply in a saved Kanban assignment report. Calculate eligible totals by product and apply optional Kanban overrides for exact product and operation pairs.

See the [usage guide](SETUP.md) for the fictional example and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/fulfillment-wip-eligibility-reporter-v0.1.0) for downloads and validation records.
