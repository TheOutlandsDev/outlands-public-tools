# Offline Telemetry Source Freshness Classifier

Turn saved stale and unavailable collector states into distinct freshness warnings. The classifier preserves the original incident evidence and fingerprint and reads a local snapshot.

See the [usage guide](SETUP.md) and [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/telemetry-source-freshness-classifier-v0.1.0) for the fictional snapshot, source ZIP, checksums, and validation records.
