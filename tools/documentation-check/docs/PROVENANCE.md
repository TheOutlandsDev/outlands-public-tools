# Provenance and license scope

Documentation Check's selected runtime and native Windows mechanisms were
already public original MIT source in OUTLANDS Public Tools. The filesystem
update adapted this collection's eligible public native I/O methods with
invented fixtures. The standalone release adds packaging, qualification,
standalone documentation and minimal test scaffolding with AI assistance.
It makes no claim of exclusive authorship or novel invention.

The five original documentation regression methods came from the collection's
combined test file. Their method bodies/assertions are preserved through
per-method AST comparison, with only the minimal standalone fixture/import
scaffolding selected. Unrelated tool imports and tests are outside this package.
The 40 existing portable/native I/O methods and historical
[FILESYSTEM.md](FILESYSTEM.md) contract are retained. Fresh copied-runtime
process fixtures use authored disposable trees and actual CLI invocations.

No real document tree, mapping, record, credential, original private helper,
capture, DLL, interpreter, report or third-party implementation is selected.
Held originals and unrelated historical rights remain uncleared. No notice is
removed or historical material retroactively relicensed. Source snapshots and
test results do not independently establish ownership of unselected material.

Selected original source, tests and docs retain the full [MIT license](../LICENSE)
and TheOutlandsDev copyright identity. Python/standard-library and operating-system
API implementations retain their own terms and are not bundled. Inspected
documents and actual reports retain their separate rights/privacy obligations.
PASS or a pattern-free audit does not clear confidentiality, semantic IP,
source rights or application behavior.

See the existing public
[filesystem-hardening review](https://github.com/TheOutlandsDev/outlands-public-tools/blob/main/docs/BATCH-28-DOCUMENTATION-CHECK-HARDENING.md)
and [collection licensing scope](https://github.com/TheOutlandsDev/outlands-public-tools/blob/main/LICENSING.md).
Their historical results remain separate from the standalone release's exact
source ZIP, fresh qualification receipts and published `VALIDATION.json`.
