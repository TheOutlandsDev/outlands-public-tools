# Offline Production Demand Deadline Reporter

Summarize overdue production demand and demand due within seven days from a saved Order Demand and WIP Allocation Reporter result. The calculation uses each row's remaining production demand and retains the supplied order revision hash. Shipped and logistics-ready quantities have already been accounted for upstream.
