# Provenance and license scope

Public Release Audit is existing public original MIT source for offline review
of a selected text export. Its Windows hardening reused this collection's
public MIT native mechanisms and invented disposable fixtures. Standalone
packaging, qualification, documentation and minimal test scaffolding were
prepared with AI assistance, without a claim of exclusive authorship.

The 19 original `AuditTests` bodies come from the combined collection suite and
are preserved through method-AST comparison. Minimal standalone scaffolding
avoids unrelated imports. The original 40 I/O methods and detector/CLI/POSIX/
report/manifest contracts remain the preservation boundary. The full shared
test file is unchanged and is not shipped. Copied processes use authored
disposable exports, markers and outputs; historical [WINDOWS.md](WINDOWS.md)
remains preserved.

Windows output-leaf behavior needs explicit report/manifest dangling-link
qualification. Any confined correction must retain exact patch review and
same-fixture before/after evidence, separately from successful release lanes.
Current runtime pins identify the reviewed release during execution, without
assuming baseline equality before that review.

No actual export/marker list, operational record/configuration, credential,
identifier, private path, original private helper, capture, model/corpus,
binary or third-party implementation is selected. Held originals and unrelated
historical rights remain uncleared. No notice is removed or retained original
retroactively relicensed by this release.

Selected original source/tests/docs retain the full [MIT license](../LICENSE)
and TheOutlandsDev identity. Python/standard-library and OS APIs retain their
own terms and are not bundled. Pattern silence, neutral examples, omitted
snippets and matching manifests do not establish ownership, confidentiality,
anonymity, semantic IP or publication clearance for inspected material.

See the public
[Windows review](https://github.com/TheOutlandsDev/outlands-public-tools/blob/main/docs/BATCH-26-PUBLIC-AUDIT-WINDOWS.md)
and [collection licensing](https://github.com/TheOutlandsDev/outlands-public-tools/blob/main/LICENSING.md).
Historical observations remain separate from fresh qualification and actual
release `VALIDATION.json` versions/counts/skips.
