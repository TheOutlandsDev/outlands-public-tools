# Provenance and license scope

This is fresh original MIT implementation with AI assistance. Its foundation is
the owner's local source-preservation workflow: verify a selected repository's
status and HEAD, check ancestry/changed-path boundaries, compare captured hashes,
and preserve canonical source bytes. The historical operational helpers retain
their private fixed paths, plans and records; none is executed by this module.

The public tool is a new reusable status reporter, not a copy of a finished
application. Its strict porcelain parser, configuration refusal rules, bounded
subprocess handling, report format, fixture repositories, documentation and tests
are original code. No source project, private receipt, remote URL, account data,
`.git` object payload or credentials are public fixtures.

The MIT license covers this selected original source/tests/docs and fictional
examples. Git and Python are separately installed and retain their own licenses;
neither implementation is bundled or relicensed. Repositories inspected by the
tool and their dependencies retain their existing terms. A local status report
does not establish authorship, permission to publish or exclusive ownership.

Primary Git documentation informs the supported machine-readable format and
operational controls; no third-party Git implementation is copied. See the
[format contract](FORMAT.md) for exact links and trust limits.
