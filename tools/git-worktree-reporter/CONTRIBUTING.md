# Contributing

Useful, bounded and reproducible improvements are welcome. Use the module's
[bug](https://github.com/TheOutlandsDev/outlands-public-tools/issues/new?template=git_worktree_bug.yml)
or [suggestion](https://github.com/TheOutlandsDev/outlands-public-tools/issues/new?template=git_worktree_suggestion.yml)
form. Describe supported behavior, expected result and a small authored repository
fixture. Share no real source, remote URLs, private filenames, `.git` data or logs.

Run the complete generated test suite and source gate. New Git commands, config
support or path layouts need documented side-effect and helper-execution review,
malformed/limit cases, and before/after repository control-file checks. Keep
unknown or incomplete data as an error or explicit unknown, not a successful
empty report. Never weaken Git's ownership protection or run arbitrary user code
to force a result. Existing notices and dependency rights must remain intact.

Original contributions to this module are made under its MIT license.
