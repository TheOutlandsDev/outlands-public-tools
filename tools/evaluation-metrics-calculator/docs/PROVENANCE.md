# Provenance and license scope

Offline Evaluation Metrics Calculator follows a fresh neutral public
specification for supplied aggregate confusion counts, using a reviewed public
MIT input-reader pattern. It is not a held model/application, dataset loader,
individual-record store, multilabel/probabilistic evaluator or model selector.

The runtime and three JSON examples retain exact Git bytes from baseline
`95f6197c4759b78acef52b70be7518b33dc2cc59`. The runtime already displayed version
0.1.0. Standalone packaging introduces no formula, ratio/undefined-result,
privacy/provenance verification or input-path repair. New source attributes
preserve reviewed bytes; no normalization makes protected hashes pass.

All 34 original method ASTs and 107 total assertions remain preserved: 96 inside
tests and 11 inside helpers. Ten canonical helper keys retain provenance:
`local:counts`, `local:changed_stat`, `local:MetricsFixture.metadata`,
`local:MetricsFixture.score`, `local:MetricsFixture.expanded_oracle`,
`local:MetricsFixture.invoke`, `local:MetricsFixture.reader_failure_traceback`,
`shared:load`, `shared:Fixture.setUp`, `shared:Fixture.write`.
Fraction and expanded-observation oracle bodies/imports remain exact. Canonical
`python-ast-fields-json-v1` encoding retains complete fields across interpreters
without weakening within-version equality. Only needed shared scaffolding is
retained. In-process imports select actual extracted source; an original
ROOT-relative subprocess uses an owned collection-shaped exact runtime copy,
verified before/after. Copied CLI consumers use one script. No duplicate runtime,
donor or unrelated shared application is shipped.

Selected source, tests, docs and fictional counts retain the full
[MIT license](../LICENSE) and TheOutlandsDev identity. Standalone preparation,
qualification, documentation and fictional consumers used AI assistance without
exclusive-authorship claims. Python/stdlib/OS retain their own terms and are not
bundled as binaries. Operator inputs/third-party material are not relicensed.

The official metric-definition references in [README.md](../README.md) are
bibliography, not bundled implementation or an API/default-policy equivalence
target. Runtime arithmetic uses raw formula numerators/denominators, with
explicit null/zero undefined output and no float reduction, rounding, smoothing,
averages, rankings or quality threshold. Precision, recall and direct-count F1
denominators are evaluated independently. Defined zero scores can return exit 0.

No held AI application, private schema, corpus, conversation, embedding, model,
prompt/response, identity, configuration or actual evaluation record was
selected, read, copied or executed. Actual inputs/results remain private and
their rights/provenance/representativeness/leakage remain unverified. Unrelated
source/data families and future exports stay uncleared. Per-class output can
reconstruct a binary confusion matrix; omitted raw matrices do not anonymize.

The reader samples identities after absolute normalization. Fictional Windows
probes on Python 3.12.7/3.15.2 accepted canonical/leaf-dot/leaf-space/parent-dot
forms with exit 0/METRICS_COMPUTED; parent-space returned 2/INPUT_PATH_INVALID,
preserving input/runtime bytes. Use canonical trusted paths; mixed measured
normalization is no blanket suffix, alias, race or hostile-filesystem guarantee.
