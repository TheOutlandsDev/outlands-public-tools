# Changelog

## 0.1.0

- Initial standalone source ZIP for the existing single-script confusion-count
  calculator, preserving expected-row/predicted-column orientation, exact raw
  unreduced ratios, independent undefined-result policy, fixed errors and MIT.
- Standalone guidance separates arithmetic from label/prediction provenance,
  privacy/anonymity, dataset quality and model/runtime acceptance. Defined zero
  metrics can return exit 0; no quality threshold or model ranking is applied.
- Qualification selects fresh Windows/Ubuntu Python 3.12, 3.13, 3.14 and 3.15.2
  without pip/distributions, independent committed-source ZIP/build-manifest
  reproduction and optimized-helper refusal. Actual outcomes belong to validation.
- Preserve 34 original method ASTs, 107 total assertions (96 in tests, 11 in
  helpers) and ten namespaced helper ASTs, including unchanged Fraction and
  expanded-observation oracles/imports. An original subprocess uses an owned
  hash-verified temporary mirror; no duplicate runtime/donor/unrelated app ships.
- Preserve runtime and three JSON examples at exact baseline Git bytes. Existing
  post-normalization path checks and mixed Windows suffix observations are
  disclosed; no formula, zero-division, privacy, alias or suffix fix is added.

No interpreter/dependency binary, actual counts/result, dataset/model, private
source, operational record or raw diagnostic log is part of the source ZIP.
