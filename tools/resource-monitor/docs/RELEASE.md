# Resource Monitor 0.1.1

[Focused source ZIP](https://github.com/TheOutlandsDev/outlands-public-tools/releases/download/resource-monitor-v0.1.1/resource-monitor-0.1.1.zip)

Adds Windows/Linux fictional-demo launchers, supported-Python checks, a short
[first-run guide](../START-HERE.md) and [extracted-ZIP acceptance](DOWNLOAD-CHECK.md).
The original API, data formats and optional live dependency pin are unchanged.
Python 3.12 or 3.13 is installed separately; the demo needs no pip packages.
Source, original fictional examples, tests, licenses and documentation only.
No runtime, psutil implementation, real metrics, reports or token is bundled.

SHA256SUMS.txt checks the ZIP; release-matrix.json records its exact source
revision and member count. The collection's downloads/build.py packages only
manifest-reviewed committed app blobs, with stable cross-platform ZIP bytes.
Windows and Ubuntu freshly extract, test and exercise the fictional HTTP/CLI
workflow before new publication. Existing releases are never overwritten.

JSON/CSV export endpoints, reopening bytes, bounded shutdown and token renewal
are exercised. Browser pause/export interaction is unverified in this patch;
Browser access was disabled during release review. History is memory-only,
exports require an explicit action and live sampling requires separate opt-in.
See [validation](VALIDATION.md) and [security](../SECURITY.md).
