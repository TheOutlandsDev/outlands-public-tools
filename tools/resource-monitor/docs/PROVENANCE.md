# Provenance and publication boundary

The owner selected resource monitoring as a useful application to develop from
the local project inventory. The older preserved monitoring drafts have an
explicit private-only provenance hold and unresolved authorship/public licensing.
Those files were not selected for publication and retain their original hold.
No historical implementation, configuration or collected record was copied or
adapted into this module.

This release is a newly authored generic implementation, developed with AI
assistance from a functional brief: aggregate CPU/RAM/network readings, a local
dashboard, bounded history, explicit exports and tests. The Python collector,
HTTP API, browser application, presentation helpers, tests and documentation are
original selected source. No old packet-sniffing or reputation implementation,
credential, address dataset, private log or real report is included.

The user authorized public MIT publication of eligible new original tools in
OUTLANDS Public Tools. This selected grant does not clear unrelated historical
material or independently prove exclusive authorship of all other local work.
No third-party implementation was copied into the module.

Live metrics use the separately supplied psutil library through its documented
public API. The installed 7.2.1 metadata/version and BSD 3-Clause license were
reviewed; the notice is retained. Python, browser, OS and psutil implementations
remain external and keep their own terms. See [dependency records](DEPENDENCIES.json).

Public examples use deterministic fictional values or a tiny generated live
sampling walkthrough. Actual machine histories, startup capability URLs,
test-runtime paths, build/check records and screenshots stay outside source.
The release source manifest lists selected bytes; it is not a blanket rights or
privacy clearance for every file on the computer.
