# Contributing

Suggestions, minimal reproductions and documentation improvements are welcome.
Use the collection's Resource Monitor bug/suggestion forms. Describe the problem,
expected result, source commit, OS, Python and psutil versions. Separate generated
fixture results from actual system sampling and browser observations.

Contributions must be original or carry compatible permissions and required
notices. The original code is MIT licensed. External runtime/dependency rights
remain separate. The private historical monitor drafts are not a public source
pool and their unresolved rights are not changed by this new implementation.

Run the Python suite, JavaScript suite and source gate before proposing changes.
Test samplers with generated values, including resets, unavailable fields and
clock boundaries. HTTP changes need loopback integration tests for token, Host,
Origin, route and request limits. Interface changes need a real browser check.

Keep capability tokens, real reports, activity histories, network addresses,
hostnames, usernames and personal screenshots out of public examples. No model,
dataset, packet capture, credential or third-party implementation is requested.
