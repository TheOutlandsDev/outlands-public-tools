# Changelog

## 0.1.0 — 2026-10-25

- New independent Python API and HTML/CSS/JavaScript dashboard for aggregate
  CPU, RAM and network counters, with explicit demo/live modes.
- Monotonic network rates, first-sample gaps, counter-reset handling and explicit
  unavailable/sampler-error states.
- Bounded memory history and explicit JSON/CSV exports.
- Loopback capability API with Host/Origin checks, static allowlist, CSP, request
  bounds and normal shutdown cleanup.
- Python/provider/HTTP/live fixtures, Node presentation tests, documentation,
  fictional examples and provenance/dependency records.

No historical private monitor code or collected data is included or relicensed.
