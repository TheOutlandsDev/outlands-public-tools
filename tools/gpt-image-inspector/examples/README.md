# Authored fictional examples

From this module folder run `python -B examples/generate.py --output ABSOLUTE_NEW_DIRECTORY`.
The parent must exist. Outputs are exclusively created and an existing directory
is refused. Keep fixtures/reports in an external private workspace. See the
[quick start](../README.md) for exact commands and expected exit codes.

The source release contains generators rather than actual images, module
binaries or device configurations. Generated examples are deliberately fictional
and unsuitable for deployment. They must not be booted, flashed, mounted or
installed as real system metadata.
