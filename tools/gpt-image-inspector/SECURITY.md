# Security and sensitive reports

Use trusted local files and output parents. This is not a hostile-filesystem
sandbox, firmware validator, runtime compatibility checker or deployment tool.
Default field omission does not anonymize hashes, ranges or metadata structure.
Keep real input files and reports private.

Do not submit sensitive material to a public issue. Use GitHub private
vulnerability reporting if available, or provide a non-sensitive fictional
reproduction and request a private reporting route. No private endpoint is
promised. Ordinary feature suggestions belong in the public tool forms.
