# Private batch replay review

Select one stable ordinary JSON file with explicit candidate batches and one reviewed receipt snapshot per supplied batch ID. This is an advisory planner. An exact, healthy committed snapshot can yield SKIP_ALREADY_COMMITTED; no supplied receipt yields MANUAL_REVIEW_NEW_BATCH only. Neither verifies a real commit or authorizes execution. Healthy unrelated committed history is allowed, while supplied failed/uncertain or unclean history and malformed/conflicting/alias/scope issues withhold the entire plan. Conflicting rows are withheld before later history checks, so do not infer extra issue codes for already-withheld groups.

Batch-list grouping and accounting are observed from the supplied JSON. Embedded source-record counts and source/mapping/preview/receipt pins remain caller declarations: source rows and referenced bytes are not loaded or independently counted. A hash does not authenticate a receipt, prove complete history, establish exactly-once execution or authorize a retry. All execution_authorized fields remain false, even on PASS. No import, retry, dispatch, reservation, database/journal update or network action is performed.

Reports retain symbolic IDs, decisions, counts, issues and fingerprints. Keep real inputs and outputs private; they are not anonymized. Use fully spelled, stable ordinary paths under trusted quiescent parents. Output must use a fresh external name under an existing parent. Native linked/multilink paths are refused. Windows creation uses CREATE_NEW and OPEN_REPARSE_POINT and refuses existing leaves, including dangling entries. Failed writes can leave unconfirmed partial output; inspect it and select a new name. Parent ACLs are inherited. Cooperative limits and sampled metadata do not establish an atomic snapshot, hostile-writer containment, transactional rollback, OS sandbox or hardware durability.

Only generic source and two invented JSON examples are published. Private batch/receipt histories, real source records, generated reports, SDKs, credentials and raw evidence remain local. Obtain Python separately. Qualification does not validate real business approval, receipt authority or safety of running an import.
