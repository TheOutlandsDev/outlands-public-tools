# Standalone qualification contract

The matrix targets ordinary CPython 3.12, 3.13, 3.14 and 3.15.2 on Windows x64 and Ubuntu x86_64. Runtime use needs the standard library only; no third-party Python distribution, native ELF parser, compiler or readelf executable is a runtime dependency. Actual Python patches, source/archive hashes, selected IDs, named skips and outcomes belong to release VALIDATION.json.

The qualification-only Python provisioner verifies exact standalone archive hashes from ORACLE-LOCK.json for all eight platform/minor selections, then extracts into a new owned prefix. It records actual interpreter identity/hashes without global installation, PATH changes, compiler installation or native parser overlay. This supplies exact patches when an action's default Windows installers do not provide them. Normal application users may choose an approved compatible Python; a version/archive pin is not a security certificate for its bundled libraries or a reproducible-native-build claim.

All 73 original methods and all runtime/demo bytes are preserved against the reviewed collection baseline, retaining 142 assertion calls, eight helpers, 21 runtime definitions and three demo definitions. Thirty copied-runtime process checks are added: 103 methods per lane and 824 executions across eight lanes, including 584 original and 240 copied-runtime executions. Runtime version 1.1.0 and report/manifest formats remain unchanged. Missing methods, failures, unsupported skips or invalid capability claims stop qualification.

Linux qualification requires the independent GCC/readelf oracle with logical version pins GCC 15.2.0 and GNU readelf 2.46, plus actual selected-executable versions, byte lengths and SHA-256 hashes recorded before/after. The [selected runner-image record](https://github.com/actions/runner-images/blob/ubuntu26/20261101.186/images/ubuntu/Ubuntu2604-Readme.md) supplies image context; it does not pin every compiler-toolchain bit or an installation archive. The oracle compiles tiny authored source into disposable fixture libraries, inspects their declared metadata and compares independent readelf observations. Inspected/generated libraries are never loaded or executed, and none is bundled. Compiler output hashes are evidence for that build, not a native-binary reproducibility promise. Windows records the exact Linux-oracle skip. Normal users need neither compiler nor readelf.

Applicable native symlink/junction and nonregular-input controls remain required in hosted qualification. Opposite-platform cases remain exact named skips; local Windows privilege error 1314 is separate evidence and cannot replace strict hosted coverage. The existing best-effort path/identity rules are preserved; no new universal ADS, hardlink, mount or race-proof guarantees are claimed.

Copied-runtime coverage separates clean graphs, mixed dependency findings, complete JSON stdout, fresh four-file reports, default hint absence and opt-in observations. It checks ELF32/ELF64 byte orders, metadata/string/range limits, malformed/truncated inputs, graph ambiguity/architecture/type/path decisions, source preservation, exact CLI statuses, escaped static HTML, independent three-payload manifest readback and retained partial-output/no-overwrite behavior. Hints remain observations and do not establish declared dependencies or runtime use.

The [thirteen-case guide](../USAGE.md) authors three demos and two extra tiny fixtures. It checks five complete report trees (fifteen payload hashes), one complete JSON-stdout case and four controlled stderr-JSON refusals. Seventeen fictional input files and the runtime/demo bytes remain unchanged; exactly 37 files are retained in the owned workspace. The clean/default/hint cases, expected review exit 2 and controlled error exit 1 are evaluated separately. No real application or phone data is used and no ELF is executed.

The source gate checks 29 finite text/source entries and member hashes; their source manifest is the thirtieth ZIP member. Privacy review selects 35 source/collection-metadata paths. Deterministic source ZIP construction fixes order, timestamps, attributes and compression; members must match committed source and independent builds must reproduce ZIP/build-manifest bytes. Fresh qualification uses new external extraction and no-pip/zero-distribution environments with exact runtime/fixture affinity. Interpreters, environments, GCC/binutils implementations, generated/compiled ELF files, firmware, real reports and raw logs remain outside the source ZIP.

The preserved [format](FORMAT.md), [earlier validation](VALIDATION.md), [example notes](../examples/README.md), [security policy](../SECURITY.md) and contribution notes retain historical observations. This contract and release VALIDATION.json define current acceptance. A passing result describes metadata candidates in supplied inputs only, not loader/ABI behavior, runtime success, phone/hardware compatibility, safety, ownership or permission to redistribute. Cooperative budgets and sampled filesystem identities are not hard native timeouts, atomic snapshots or a hostile-filesystem sandbox.
