# Offline Fulfillment Log Continuation Checker

Group consecutive allocation lines by week, order index, and part. Compare each group's ordered lot and Kanban sequence with a saved allocation report.

See the [usage guide](SETUP.md) for the fictional example and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/fulfillment-log-continuation-checker-v0.1.0) for downloads and validation records.
