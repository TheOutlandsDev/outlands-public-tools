# Offline Order Demand Lifecycle Replay Reporter

Replay saved order versions in memory to check their effects on remaining demand and recommended lot counts. The source release includes fictional inputs and 17 adapted test cases.

See the [usage guide](SETUP.md) for installation and examples and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/order-demand-lifecycle-replay-reporter-v0.1.0) for the source ZIP, checksums, and validation records.
