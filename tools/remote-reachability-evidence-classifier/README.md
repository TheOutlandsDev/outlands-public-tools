# Offline Remote Reachability Evidence Classifier

Classify saved reachability evidence using an explicit evaluation time. The
result is reachable, unreachable, pending, or stale and includes a fixed
reason. The classifier retains the original missing-evidence test with
fictional data.

- [Source ZIP, SHA-256 checksums, and validation records](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/remote-reachability-evidence-classifier-v0.1.0)
- [Usage guide and fictional inputs](SETUP.md)

Qualification covers Windows and Ubuntu with Python 3.12.16 and 3.15.2.
The runtime uses the Python standard library.
