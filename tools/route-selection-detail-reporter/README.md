# Offline Route Selection and Detail Reporter

Review a saved route snapshot with a local Python CLI. Select a flow and version, verify summary and selected detail counts against a supplied contract, and see repeated steps in their original route order.

See the [usage guide](SETUP.md) for commands and fictional sample files. See the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/route-selection-detail-reporter-v0.1.0) for the archive, SHA-256 checksum, and Windows and Ubuntu validation records.
