# Offline Planning Gap Register Validator

Check a saved gap-register CSV and list products awaiting timing review or business inputs. The validator keeps confirmed lot quantities separate from reference-only values and rejects approval and import claims.

See the [usage guide](SETUP.md) for the fictional example and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/planning-gap-register-validator-v0.1.0) for downloads and validation records.
