# Private workspace

Extract public source into a fresh directory. Choose another existing,
user-owned private parent for venvs, fictional fixtures, actual selected inputs,
inventory runs, classification output and qualification receipts:

```text
source/source-inventory-0.1.0/   reviewed source only
private/source-inventory/
  venv312/                      separately created interpreter environment
  fictional-demo/               fresh generated example
  input/                        narrowly selected trusted private tree
  reports/                      existing parent for fresh inventory runs
  classification-new/           fresh classifier output
  qualification/                extraction, venv/test work and private receipts
```

Do not put report output inside the inventoried tree. Input/report directories
must already exist and remain trusted/unchanged. Classifier output and example
destinations must be new with existing parents. All classifier paths are
absolute. No source folder or output destination is selected implicitly.

Use local quiescent paths, stop writers and keep the adjacent Windows backend.
Observed link/reparse and unsupported entry policies remain in force. Native
guards do not provide an atomic snapshot, hostile-filesystem sandbox, universal
I/O timeout, power-loss recovery or live-SMB guarantee. Filesystem roots and
unsupported Windows path spellings/providers are refused; do not bypass guards.

Existing files are not overwritten. Failure can leave partial or complete-looking
but unconfirmed output. Check the actual CLI exit/result before using a run;
inspect failures privately and choose fresh destinations. Requested 0700/0600
modes depend on OS/Python and inherited ACLs. They are not an encryption or
Windows confidentiality guarantee. Keep normal backups and private permissions.

Relative filenames, top-level names, hashes, modification times, counts and
categories can identify projects/content. Omitted roots/file bodies do not
anonymize reports. CLI arguments, shell history and redirection can retain
private information too. Keep actual reports outside public source control.

User-owned Python/venvs do not inherently need administrator access, but device
policy and OS prerequisites still apply. Never bypass policy or change privilege
settings merely to make a fixture pass. The CLI needs no packages or network.

The public source ZIP includes original code/tests/docs and fictional generators,
not real trees, reports, originals, runtime/dependency binaries, venvs or raw
diagnostics. Publish only designated reviewed source assets and sanitized
validation metadata. Use authored fictional reproductions in public issues.
See [USAGE.md](../USAGE.md) and [QUALIFICATION.md](QUALIFICATION.md).
