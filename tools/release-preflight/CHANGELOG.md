# Changelog

## 0.1.0

Initial standalone source release of Release Preflight, with full MIT notice,
self-contained documentation, fictional walkthrough, deterministic source ZIP
and fresh Windows/Ubuntu Python 3.12–3.15 qualification methods.

Correct only the top-level source-boundary constant block: add
`_SOURCE_DIRECTORY` and revise `REPOSITORY` to recognize literal structural
`tools/release-preflight` collection placement, otherwise protect the enclosing
standalone runtime directory. This permits an external private report from fresh
extraction without treating an unrelated ancestor as the source root. All runtime
function bodies, native backend bytes and three original example files remain
preserved. Manifest/launcher schemas, pins, limits, selected-file decisions,
stdout summaries and new-report handling retain their contracts.

Preserve 28 original shared and 47 original I/O methods. Add 26 copied-runtime CLI
methods and strict native-skip contracts. Actual fresh archive versions, results
and named skips are recorded in release `VALIDATION.json`; historical evidence
in [IO-SAFETY.md](IO-SAFETY.md) remains separate. No interpreter/dependency binary,
actual package/configuration/report or raw log is bundled.
