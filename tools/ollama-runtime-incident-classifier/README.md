# Offline Ollama Runtime Incident Classifier

Compare saved Ollama health with the expected runtime state. The read-only CLI preserves the original warning logic, evidence and incident fingerprints.

See the [usage guide](SETUP.md) and [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/ollama-runtime-incident-classifier-v0.1.0) for fictional snapshots, source ZIP, checksums and qualification records.
