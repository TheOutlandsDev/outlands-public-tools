# Changelog

## 0.1.0 — 2026-10-25

- Generalized the owner's fixed-path game-launch workflow into an original
  standard-library Windows command-line tool.
- Added explicit plan/launch actions, logical-processor or hexadecimal-mask
  selection, working directory and literal child arguments.
- Added suspended creation, affinity/normal-priority readback before resume,
  owned-child setup-failure cleanup and bounded optional wait observations.
- Added full-path best-effort duplicate checks, a fictional demo, disposable
  examples, portable/native fixture tests and detailed documentation.
- Published original MIT source with dependency/provenance boundaries and public
  bug/suggestion forms. Specific game compatibility remains separate validation.
