# Contributing

Suggestions, questions and small reproducible bug reports are welcome through
the collection's App Affinity Launcher issue forms. Describe the problem and a
useful result; contributing code is not required.

Use fictional paths and generated disposable programs. Do not attach proprietary
executables, games, saves, profiles, private launch receipts, credentials or
unredacted arguments. Confirm that you have rights to any submitted example.

For source changes, run the standard-library test suite and source gate described
in README.md. Separate portable fake-backend results from native Windows
execution. Include OS/Python versions, actual skips and the intended processor
group/architecture support. Never remove a check simply to make a failing test
pass. Retain required license and attribution notices.

Additional application compatibility claims need explicit tests of that
application. A created process, correct affinity mask or passing fixture does not
establish performance, game stability or usable startup. Keep reproduction
programs short and ensure every test cleans up only the process it created.

Original contributions accepted into this folder are intended to use its MIT
license. Third-party code and assets require their own compatible rights and
notices; the repository's license does not replace them.
