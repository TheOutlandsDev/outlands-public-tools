# Contributing

Suggestions, bugs and minimal fictional reproductions are welcome via the
[issue chooser](https://github.com/TheOutlandsDev/outlands-public-tools/issues/new/choose).
Select **Android Property Configuration Diff: Bug report** or **Android Property Configuration Diff: Suggestion**. Include the use case,
expected behavior, OS/Python version, source commit and generated input.

Do not attach real logs, private paths, customer data, device IDs, credentials or
unredacted reports. Contribute original work under MIT and preserve separately
licensed notices. Unknown syntax must remain explicit coverage. Tests must use
temporary generated inputs, not live log queries, permission changes or devices.
Review the diff, deliberately update the exact source inventory and run both
checks in README. Keep real runtime outputs outside pull requests.
