# Security and private data

Use trusted local files and controlled output parents. This tool is not an OS
sandbox or assurance of configuration, permission, device or runtime safety.
Default omission does not anonymize hashes, timing or structural observations.
Keep real inputs and identifying reports private.

Do not disclose sensitive data through public issues. Use GitHub private
vulnerability reporting if available, otherwise provide a non-sensitive fictional
reproduction and request a private route. No private endpoint is promised.
Ordinary feature suggestions belong in the public tool forms.
