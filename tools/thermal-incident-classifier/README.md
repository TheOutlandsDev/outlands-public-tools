# Offline Thermal Incident Classifier

Classify saved CPU, storage, and GPU readings using the original per-device temperature thresholds. The CLI uses the Python standard library and skips static limits such as TjMax.

See the [usage guide](SETUP.md) and [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/thermal-incident-classifier-v0.1.0) for the fictional snapshot, source ZIP, checksum, and qualification records.
