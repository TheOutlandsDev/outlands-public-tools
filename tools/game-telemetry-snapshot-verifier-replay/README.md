# Offline Game Telemetry Snapshot Verifier and Replay Tool

Verify a saved telemetry snapshot and replay its records into normalized events, descriptive actor statistics, and a training manifest for review. The package uses Python's standard library and includes fictional snapshots for all five game profiles.

See the [usage guide](SETUP.md) and [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/game-telemetry-snapshot-verifier-replay-v0.1.0) for the source ZIP, checksums, and validation records.
