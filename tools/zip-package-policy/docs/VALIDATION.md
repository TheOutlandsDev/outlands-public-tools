# Validation

Run the dependency-free PowerShell 7.2 or newer test harness from the tool directory:

```powershell
pwsh -NoProfile -File ./tests/Run-Tests.ps1 -WorkRoot "$privateWork/zip-policy-tests"
```

`WorkRoot` must be a new absolute directory outside this module. Fixtures are
generated there, retained for inspection and never written to the checkout. The
harness invokes the public CLI as a separate PowerShell process, asserts its
exit status and JSON, checks that stderr is empty and that absolute fixture paths
are absent from results, and rehashes every input after each invocation.

Coverage includes completed pass/findings/error states, hashes and sizes, exact
membership/case behavior, literal rather than regex matching, strict JSON fields
and duplicate keys, numeric types and policy contradictions, unsafe member names,
case/NFC duplicates, file/directory collisions, symlink metadata, entry/declared
size/text bounds, invalid UTF-8, empty archives, malformed/trailing ZIP data,
disagreement between local and central names, a sparse archive above the hard
limit, exclusive report creation and missing/relative paths. All fixtures contain
fictional text or generated bytes. No real package, installed app or device is
used. There is no test that silently passes when a required runtime is absent.

The repository CI runs the same harness on Windows and Ubuntu using PowerShell 7.2 or newer.
The source gate and parent publication review cover the explicit source allowlist,
original license scope, manifests and links. Tests support these narrow behaviors;
they are not evidence of safety of an arbitrary download, all ZIP variants,
application compatibility, unselected content CRC integrity, a privileged file
server or every possible concurrent mutation/race.
