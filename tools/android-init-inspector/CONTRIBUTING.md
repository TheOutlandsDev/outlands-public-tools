# Contributing

Suggestions, fictional format examples and bug reports are welcome through the
[issue chooser](https://github.com/TheOutlandsDev/outlands-public-tools/issues/new/choose).
Choose **Android Init Service Inspector: Bug report** or **Android Init Service Inspector: Suggestion**. Describe the use case,
expected behavior, OS/Python version and source commit. Include a minimal
fictional text example and remove identifiers, credentials and private reports.

Keep the documented subset honest: unsupported syntax must remain coverage,
not a guessed successful result. Tests must use authored temporary inputs and
must not require devices, privileged commands, Make/init/mount or network.
Original contributions are accepted under MIT; retain notices for any approved
separately licensed dependency. Do not contribute copied proprietary configs.
Run the two checks in README after changing the explicit source inventory.
