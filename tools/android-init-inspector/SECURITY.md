# Security and private inputs

Use trusted local text and an output parent you control. This program is not a
sandbox, firmware validator, sanitizer or assurance of boot/build/mount safety.
Never execute generated examples as actual system configurations.

Do not open a public issue containing credentials, customer data, firmware or
device identifiers. For a sensitive defect, use GitHub private vulnerability
reporting if enabled; otherwise share only a non-sensitive fictional
reproduction and ask for a private reporting route. No private endpoint is
promised. Ordinary suggestions belong in the public issue forms.
