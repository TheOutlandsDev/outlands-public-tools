# Provenance and license scope

Package Layout Checker adapts generic required-file checks, static Python AST
parsing, case-insensitive literal rules and aggregate results from an owner-
created project verifier. The public Windows backend adapts this collection's
public MIT native input mechanisms. Standalone packaging, qualification,
documentation and invented fixtures used AI assistance, without a claim of
exclusive authorship.

Only neutral declared-file rules and supported reader mechanisms are selected.
Business/project data validation, schemas, original operating paths, runtime
execution checks and private verifier code are excluded. No actual package,
manifest/literal list, record, credential, endpoint, user identifier, capture,
model/corpus, binary or third-party implementation is selected. Held originals
and unrelated historical rights remain uncleared.

The two runtime files remain preserved. The 33 original POSIX regressions and
31 Windows/portable methods retain their established behavior and explicit
platform scope. Copied CLI consumers use authored disposable packages only.
Historical [WINDOWS.md](WINDOWS.md) wording is preserved; its single review
hyperlink is changed to an absolute public URL for standalone resolution.
Historical results do not stand in for fresh qualification.

Selected original source, tests, examples and docs retain the full
[MIT license](../LICENSE) and TheOutlandsDev identity. Python/standard-library
and OS APIs retain their own terms and are not bundled. No notice is removed
or retained original retroactively relicensed by this release.

Fixed errors, source/literal omission and a declared PASS do not establish
privacy, anonymity, semantic IP clearance, ownership or permission to share
inspected content. Relative names and private manifest rules remain identifying.
Review them and any captured stdout independently before disclosure.

See the public
[Windows review](https://github.com/TheOutlandsDev/outlands-public-tools/blob/main/docs/BATCH-19-PACKAGE-LAYOUT-WINDOWS.md)
and [collection licensing](https://github.com/TheOutlandsDev/outlands-public-tools/blob/main/LICENSING.md).
Actual standalone versions/counts/outcomes/skips belong to release
`VALIDATION.json`, separately from historical evidence.
