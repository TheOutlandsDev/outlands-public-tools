# Provenance and license scope

Offline Workflow Plan Checker is a fresh neutral task dependency/state
convention using newly authored fictional metadata. Its sampled bounded reader
adapts this collection's existing public MIT checker pattern at commit
`dfe7479baa11a402b6e273de29ff770a0e5c7176`. It is not an importer for private
worker contracts, shell scripts, CI YAML or another workflow product's schema.
Reserved superscript device-name characters use explicit Unicode escapes.

The runtime and four JSON examples retain exact Git bytes from baseline
`15dd413079782809e915a3a8ec63b4e5e8a085c2`. The runtime already displayed version
0.1.0. Standalone packaging introduces no graph/state/result, execution or
input-path repair. New source attributes preserve reviewed bytes; no
normalization is used to make protected hashes pass.

All 46 original test method bodies, 106 assertion calls and nine original helper
ASTs remain preserved. Explicit `python-ast-fields-json-v1` encoding retains
full AST fields for stable comparison across supported Python versions,
without weakening within-version original/adapted equality. The adapter
selects the actual extracted checker/script directly; no unrelated suite,
runtime mirror, donor or shipped duplicate checker is needed.

The helpers are `task`, `plan`, `valid_plan` and `Fixture.setUp`, `file`,
`invoke`, `rejected`, `issues_for`, `withheld`; their full canonical field
hashes remain part of the preservation contract.

Selected source, tests, examples and docs retain the full [MIT license](../LICENSE)
and TheOutlandsDev identity. Standalone preparation, qualification, documentation
and authored fictional consumers used AI assistance without exclusive-authorship
claims. Python/standard-library and OS mechanisms retain their own terms and
are not bundled as binaries. The license grants no rights in operator inputs
or third-party workflow material.

No held original application, worker contract, source, configuration, actual
workflow, private record, credential or operational log was selected, read,
copied or executed. Only authored fictional declarations ship here; real
controls/results and operational evidence remain private. Unrelated historical
rights and future exports are not cleared by this selection.

Declared dependencies/states do not establish task execution, prerequisite
success, authorization, resource availability, concurrency/timing acceptance or
containment. IDs/counts/issues/order and eligibility can identify a design even
though raw states/prerequisites are omitted. All action/verification flags stay
false; output is advisory declaration review.

See the historical
[workflow-plan review](https://github.com/TheOutlandsDev/outlands-public-tools/blob/main/docs/BATCH-16-WORKFLOW-PLANS.md)
and [collection licensing](https://github.com/TheOutlandsDev/outlands-public-tools/blob/main/LICENSING.md).
Historical 46/44/2 evidence is separate from actual standalone versions/counts/
outcomes/skips in release `VALIDATION.json`.
