# Provenance and license scope

Project Workspace is an existing public original MIT implementation of a
generic original-preservation workflow, using a neutral authored layout and
control record. Its Windows hardening reused this collection's public MIT
native mechanisms and invented opaque fixtures. Standalone packaging,
qualification, documentation and minimal test scaffolding were prepared with
AI assistance, without a claim of exclusive authorship.

The six original `WorkspaceTests` method bodies come from the combined
collection suite and are preserved through method-AST comparison. Minimal
standalone scaffolding avoids unrelated tool imports. The original 40 safety
methods, runtime/POSIX bodies, template and [WINDOWS.md](WINDOWS.md) remain
preserved. Fresh copied-runtime consumer processes use authored disposable
inputs. The full combined collection test file is separate and is not shipped
in the standalone package.

No private original implementation, workplace-specific template, configuration,
record, identifier, credential, input/generated workspace, capture, model/corpus,
binary or third-party implementation is selected. Held originals and unrelated
historical rights remain uncleared. No notice is removed or retained original
retroactively relicensed by this release.

Selected original source, tests and docs retain the full [MIT license](../LICENSE)
and TheOutlandsDev identity. Python/standard-library and OS API implementations
retain their own terms and are not bundled. Copying bytes, neutral names and
matching hashes establish no ownership or right to disclose the input/output.
Ignore rules, fixed errors and successful checks do not clear confidentiality,
semantic IP or publication rights.

See the public
[Windows review](https://github.com/TheOutlandsDev/outlands-public-tools/blob/main/docs/BATCH-27-PROJECT-WORKSPACE-WINDOWS.md)
