# Contributing

Bug reports, feature requests and usability/format suggestions are welcome at the
[issue chooser](https://github.com/TheOutlandsDev/outlands-public-tools/issues/new/choose).
Select **Android VINTF Manifest Inspector: Bug report** or **Android VINTF Manifest Inspector: Suggestion**. Include the use case,
expected behavior, OS, Python/parser version, source commit and a minimal
fictional reproduction. Never attach real images, proprietary metadata,
credentials, unique identifiers or unredacted reports.

Contribute original work under MIT and retain applicable dependency notices.
Keep unsupported syntax visibly incomplete; do not guess runtime compatibility.
Tests must use generated temporary inputs and require no privileged/system or
device actions. Review the source diff and deliberate inventory update, then run
the source gate and suite listed in README. Reports are private outputs, not
source files to include in a pull request.
