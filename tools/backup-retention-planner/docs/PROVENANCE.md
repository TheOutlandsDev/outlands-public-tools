# Provenance and license scope

Backup Retention Planner is fresh neutral policy-planning code using newly
authored fictional metadata. Its bounded sampled input reader reuses reviewed
public implementation. No held operational source, private backup configuration,
source mapping, user record, credential or third-party backup payload is selected
or read. The standalone selection contains no actual backups, operational
plans/results, private source, raw logs or downloaded binaries.

The runtime and three fictional examples retain exact Git bytes from baseline
`0f06022ed4727c461cd0e0142879cc7de29bafae`. The runtime already displayed version
0.1.0. Canonical UTC timestamp syntax and the explicit clock-range check were
already repaired in that baseline for newer ISO parsing behavior. This release
does not add a new clock, policy rule or timestamp normalization.

The existing path guard checks normalized absolute components. Native Windows
measurements show canonical plan spelling and trailing-dot/space variants can
select the same plan. This retained behavior is explicitly documented rather
than described as original-spelling prevalidation. Use fully spelled trusted
canonical paths; no runtime alias fix is part of this source release.

All 39 original test method bodies remain preserved. Adapter scaffolding
provides an owned temporary collection-shaped mirror for the original
subprocess regression, byte-verified against the selected runtime. No duplicate
runtime, unrelated shared-suite imports, test-only donor implementation or
installed distribution is shipped. Additional copied-script CLI consumers use
only newly authored disposable metadata.

Selected original source, tests, examples and docs retain the full
[MIT license](../LICENSE) and TheOutlandsDev attribution. Standalone preparation,
qualification, documentation and fictional consumers used AI assistance without
exclusive-authorship claims. Python/standard-library and OS mechanisms retain
their own terms and are not bundled as binaries. The license does not grant
rights in operator inputs or third-party backup material; unrelated historical
rights remain uncleared.

`independent_full`, timestamps and pin flags are supplied declarations. The
planner does not independently establish snapshot existence, independence,
integrity, authenticity, redundancy, recoverability, free space or permission
to remove anything. KEEP/REVIEW decisions and six false action/verification
flags are advisory schema results, not actual backup operations. IDs and reason
relationships can remain identifying despite omitted dates/policy values.
