# Private workspace

Extract public source into a fresh directory. Choose a separate existing,
user-owned private parent for Python/venvs, fictional work, real plan controls,
stdout captures and qualification receipts:

```text
source/backup-retention-planner-0.1.0/  selected source only
private/retention-planner/
  venv312/                            separately created no-pip environment
  fictional_walkthrough.py            private copy of the usage driver
  fictional-demo/                     new owned fictional metadata only
  actual-plan.json                    real declaration, private
  captures/                           caller-selected stdout/diagnostics
  qualification/                      extraction, environment and receipts
```

Select the intended interpreter and `retention_plan.py` explicitly. Provide
`--plan FILE`; no backup root, environment/default plan, output writer,
installer, network action or deletion switch exists. Only the selected JSON
control is read; backup storage and contents are not enumerated or opened.
The planner prints JSON stdout. Shell redirection/caller code controls any
saved capture and may overwrite it; select new private capture paths.

Use caller-selected `as_of` metadata and supported declared independent full
snapshots. The planner never substitutes the machine clock. Actual dates,
policies, IDs and pin declarations can identify operations. Results omit dates
and policy values but retain IDs, counts, decisions and reason relationships.
Fixed errors omit selected paths/native details without anonymizing results,
caller logs or formatted library tracebacks. Keep real plans/results private
and review a separate export before sharing.

KEEP/REVIEW decisions are advisory. They do not verify backup existence,
integrity, authenticity, independence, recoverability, redundancy, available
space or deletion permission. Incremental/differential/deduplicated/reference-
dependent sets do not fit this declaration; do not strip dependencies to force
them into the schema. No file selection/deletion or command is generated.

Use stable ordinary controls under trusted quiescent local ancestors and fully
spelled canonical input paths. Windows normalization can trim trailing-dot/
space aliases before components are checked; those variants were measured
selecting the same canonical plan. No original-suffix prevalidation is provided.
The reader requires a supported regular single-link plan and verifiable file/
ancestor identities, with sampled checks before/during/after the bounded read.
Observed link/reparse/special/multi-link inputs and metadata changes are
refused. These checks are not an immutable snapshot, atomic transaction or
hostile-filesystem sandbox. Remote/mapped/cloud/virtual storage, mount or drive
rebinding, concurrent writers, blocked OS I/O, power loss and ACL privacy are
outside acceptance. No socket/DNS probe is made, while OS storage access may
still involve a network. Reads can affect access metadata; Python caches are
separate.

The selected plan is at most 64 KiB with 1–256 snapshots. These bounds and
policy limits are not total CPU/memory/JSON-depth/deadline or storage quotas.
Require complete JSON and the actual exit/status. Interruption or stdout failure
can leave partial capture. There is no planner-owned output tree to roll back;
the walkthrough retains its authored fictional work for inspection rather than
automatically deleting it. Requested file modes depend on OS/Python/ACL support
and are not a confidentiality guarantee.

User-owned Python/venvs do not inherently require administrator access. Respect
device policy and OS prerequisites without bypasses. No pip distribution,
network, model or account is required. Interpreters remain separately licensed.

Build/qualification outputs must be new private paths outside source with
existing parents. Publish designated reviewed source and sanitized actual
validation only, excluding actual plans/identifiers/results, backup contents,
source/work notes, personal paths, real operational timestamps, credentials,
private originals, interpreter/dependency binaries and raw logs. See
[USAGE.md](../USAGE.md), [QUALIFICATION.md](QUALIFICATION.md) and
[PROVENANCE.md](PROVENANCE.md).
