# Changelog

## 0.1.0

- Initial standalone source ZIP for the existing single-script advisory planner,
  retaining its declared-independent-full schema, policy/result behavior, fixed
  errors, displayed version and MIT license.
- Standalone usage, private-workspace and provenance guidance distinguish
  declared KEEP/REVIEW protections from backup validity, authenticity,
  independence, recoverability or deletion permission.
- Qualification selects fresh Windows/Ubuntu Python 3.12, 3.13, 3.14 and 3.15.2
  environments without pip or installed distributions, independent committed-
  source ZIP/build-manifest reproduction and optimized-helper refusal. Actual
  outcomes belong to release validation.
- Preserved all 39 original test method bodies and added copied single-script
  CLI consumers with exact native/platform skip contracts. A temporary verified
  runtime mirror supports the original subprocess fixture without shipping a
  second runtime or public sibling dependency.
- Retained runtime and all three fictional JSON examples at exact baseline Git
  bytes. The canonical UTC timestamp/clock check was already repaired in the
  baseline; this release adds no new policy/timestamp semantics.
- Documented the existing Windows normalization limit: trailing-dot/space input
  aliases can resolve to the canonical selected plan before path checks. Use
  fully spelled trusted canonical paths; no original-suffix refusal is claimed.

No interpreter/dependency binary, actual backup plan/result, private original
source, backup data or raw diagnostic log is part of the source package.
