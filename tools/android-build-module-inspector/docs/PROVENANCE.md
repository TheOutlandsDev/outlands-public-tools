for module names while walking a fixed offline build tree and comparing selected
file stems. This publication retains the generic selected-declaration review
use case in a fresh reusable parser/report implementation. It includes none of
the original tree, private paths, firmware inventory, vendor declarations,
configuration choices or generated historical reports.

The historical helper remains intact and fingerprinted in the private batch
record. The owner identifies it as personal work. That selected-source review is
not independent proof of exclusive historical authorship. The new tokenizer,
limited grammars, request comparison, tests, guides and fictional generators are
original MIT work, reusing first-party MIT file/report helpers from the collection.
No upstream parser body, runtime, test corpus or proprietary template is copied.

Primary format background was checked on 2026-10-26 against the official
[Soong documentation](https://android.googlesource.com/platform/build/soong/+/refs/heads/main/README.md).

limitations. This inspector's own smaller subset is documented separately; it
does not implement all Soong/Make syntax or type/build semantics. The reference
retains its own license and is linked rather than distributed or relicensed.
