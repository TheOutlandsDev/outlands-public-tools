# Standalone qualification contract

The target matrix is ordinary CPython 3.12, 3.13, 3.14 and 3.15.2 on Windows x64 and Ubuntu x86_64 with actual Expat 2.10.0. A Python version alone is insufficient. Each lane must attest the selected interpreter, loaded pyexpat/parser version, preparation source pins and actual artifacts before testing. A runtime reporting an older parser fails closed; no tuple/version-string bypass or skipped parsing suite can qualify it. Actual versions, artifact/source/ZIP hashes, test IDs, named skips and outcomes belong to release VALIDATION.json.

Runtime preparation requires existing CMake, a supported Visual Studio 2022 or Visual Studio 2026 generator with x64 C tools on Windows, or GCC, make and CPython build development headers on Linux. Windows builds a matching pyexpat extension with static Expat in a new owned standalone runtime, preserves the original extension backup and retains its base executable. Linux preserves the standalone distribution as a reference and builds matching CPython from pinned source with static Expat into a separate owned `built-python` prefix. It does not assume that an extension overlay can replace a reference interpreter's built-in pyexpat. Reference/source pins, actual selected executable/parser artifacts and compiler/CMake identity are recorded per lane. Identical native output across build paths/toolchains is not assumed. The recipe installs no prerequisites or system Python and needs no administrator/global installation.

All 59 original methods remain in the raw SvgTests suite, retaining 99 assertion calls (97 in tests and two in six supporting helpers). The runtime has only the raised `MIN_EXPAT` constant; its function/class bodies, the raw fictional generator and original fixture/test bodies remain preserved. Thirty copied-runtime methods execute fresh Python processes against copied source. Each lane selects 89 methods, or 712 executions across eight lanes. Missing methods, failures, unsupported skips or invalid capability claims stop qualification.

Strict hosted lanes must exercise applicable native symlink/junction/path safeguards. The original suite has one POSIX-FIFO skip on Windows and no required platform skip on POSIX; the new suite has one opposite-platform case per operating system. Two original and one copied Windows symlink cases may skip only on actual error 1314 in local nonstrict mode; that evidence cannot substitute for hosted native execution. Existing supported hardlink/ordinary-file behavior is not replaced by an invented blanket refusal. Parser security provenance remains mandatory regardless of platform capability.

The preserved suite and copied-runtime checks cover namespace/root validation, decimal dimensions, DTD/entity rejection, older-parser refusal, malformed XML/UTF-8, callback/byte/output limits, active/foreign markup, literal references/CSS uncertainty, default/private detail scope, no reference file/network access, report escaping and manifest readback, unchanged inputs, native path/nonregular refusal, fresh-only output and retained partial failures. Source SVG is never rendered, referenced content is not opened, and no real artwork is a fixture.

The [eleven-case guide](../USAGE.md) checks the fictional generator, clean/review/details/static escaping results and six expected refusals. Four complete three-file report trees are verified through independent byte-length/SHA-256 manifests, report fields and inert HTML structure. It compares whole stdout/stderr bytes and exit statuses, preserves fixture/runtime bytes and accepts no bytecode or unexpected application output in its private workspace. Expected exit 1 is a completed review result, not an infrastructure failure.

The source gate checks an explicit finite text/source inventory and member hashes. Deterministic ZIP construction fixes ordering, timestamps, regular-file attributes and compression; members must match committed source. Independent builds must reproduce ZIP and build-manifest bytes. Fresh extraction/no-pip environments must contain zero installed distributions with exact source/runtime affinity. Prepared interpreters, native parser libraries, build output, environments, artwork, actual reports and raw logs remain outside the source ZIP.

The historical [format](FORMAT.md), [validation record](VALIDATION.md) and [example notes](../examples/README.md) retain the former 2.7.2 floor and older observations. They cannot establish the new parser prerequisite or matrix outcomes; current acceptance is supplied by this contract and release VALIDATION.json. An unmodified standalone Python download containing Expat 2.9.0 correctly fails the current gate.

The updated floor and DTD rejection are not a security certificate. No result establishes safe rendering, sanitization, complete SVG/CSS validity, accessibility, copyright or visual acceptance. Default omission of raw text is not anonymization. Sampled native identity checks and parser limits are not atomic snapshots, hostile-filesystem isolation or hard native I/O deadlines. Use stable trusted local files and one operator; network/cloud storage, real artwork acceptance and adversarial mutation are outside qualification.
