# Private inspection workspaces

Choose an existing trusted private parent outside the source checkout and public/synchronized directories. Every generated demo/report path must be new. The fictional guide creates authored text only and never copies an actual document, portfolio or customer image.

Inspect source SVG as text; do not render it or open its references as part of this workflow. The generated HTML report contains escaped static observations and no embedded SVG, active link, script or external asset. The guide validates its markup programmatically rather than opening a browser.

Default reports omit many raw values but retain source hashes, dimensions, line numbers and structural counts. Those can identify a document. Private `--include-details` reports add raw reference and ID text, potentially exposing filenames, URLs or embedded payloads. Neither mode is an anonymizer. Keep real artwork, reports, manifests, paths, parser/build receipts and raw diagnostics private; review any sharing separately.

The tool does not sanitize, decrypt, execute or confer rights to artwork or referenced resources. A complete inspection is limited to declared markup and conservative literal-reference observations; it does not establish safe rendering, full standards validity, accessibility, ownership or visual quality.

Existing input/output files are not replaced. An I/O failure may retain a new incomplete report directory. Treat it as unconfirmed private output, preserve it for review and choose another new destination for a retry. The tool does not clean up, overwrite or roll back your files.

Use one operator with stable trusted local files and an interpreter whose actual parser meets the 2.10.0 floor. Parser version checks and bounded callbacks do not certify that all known or future vulnerabilities are absent. Sampled path/handle identities are not atomic snapshots, hostile-filesystem isolation or hard native I/O deadlines. Mapped/network/cloud storage and adversarial mutation are outside qualification. Follow applicable permissions and workplace policies.
