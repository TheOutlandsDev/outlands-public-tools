# Offline Workbook Snapshot Manifest Validator

Verify saved workbook bytes against their SHA-256, then compare the declared sheet, headers, worksheet dimensions, data rows, formulas, and external-link parts. The validator reads each snapshot locally and opens it with openpyxl in read-only mode.
