# Validation boundaries

The suite uses invented packet metadata, actual installed Scapy decoding of
generated IPv4/TCP/UDP/ICMP objects and a generated byte roundtrip. It opens no
capture interface, sends no packets, contacts no OTX endpoint and validates no
real API key. HTTP behavior is injected with synthetic transport responses.

Actual owned spawn-process fixtures test cooperative cancellation and forced
shutdown of an unresponsive invented worker. A real psutil snapshot validates
field shape/ranges without printing identities. Real withdrawn Tk widgets
exercise idle construction, demo rendering, confirmations, worker selection,
input refusal and explicit report save. CLI checks run actual processes and
optimized-Python refusals. Shared helper checks repeat first-party safeguards.

```text
python -B source_check.py
python -B -W error -m unittest discover -s tests -v
```

Optional-dependency and display qualification can be made mandatory:

```powershell
$env:NETWORK_MONITOR_REQUIRE_DEPENDENCIES='1'
$env:NETWORK_MONITOR_REQUIRE_TK='1'
python -B -W error -m unittest discover -s tests -v
```

Linux with Tk/display support:

```sh
NETWORK_MONITOR_REQUIRE_DEPENDENCIES=1 NETWORK_MONITOR_REQUIRE_TK=1 xvfb-run -a python3 -B -W error -m unittest discover -s tests -v
```

Configured Windows/Ubuntu CI installs the direct pins and requires those paths.
An unavailable required dependency or native Tk fails qualification; optional
developer skips are not passes. Actions and the collection review record actual
selected-revision outcomes, not implied success from workflow configuration.

The initial private draft had 31 generated methods passing. Actual dependency
tests then caught Scapy's string-subclass address handling and the nested-header
port issue; both were corrected. The final suite is larger and has a separate
recorded outcome. A missing native capture provider warning during offline decode
does not establish live capture support. No driver was installed for testing.

Live Scapy/Npcap interface acceptance, packet-drop accounting, long sessions,
external OTX availability/authentication/rate limits, network/proxy environments
and malicious-traffic detection quality remain unqualified. This is a source
release with those explicit experimental live-backend limits, not a qualified
intrusion-detection/security product. Local heuristics and remote pulse counts
do not establish malware or clean traffic.
