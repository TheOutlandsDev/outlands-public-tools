# Source provenance and license scope

Two retained desktop monitor versions supplied the existing packet/port/length
rules, resource display and OTX lookup use case. The owner directly confirmed
personal authorship, including AI assistance, in the current publication review.
That resolves the prior unverified-attribution hold for the selected source;
it is owner attribution, not independent proof of every historical influence.

The current adaptation separates effects, model, CLI, GUI and owned workers;
uses sanitized source review copies; removes automatic capture/network/file
behavior; corrects address/reputation interpretation, local-rule counts,
bounded capture shutdown and export privacy. The original two source files and
the prior sanitized snapshots remain byte-identical, privately fingerprinted.
Embedded original credentials, logs, IP CSVs and capture/history records are
excluded. No key value was copied into this public source.

MIT covers the owner's selected original source, adaptations, new tests/guides
and fictional examples. First-party inspection_support.py and support tests
retain MIT. No required upstream notice is removed. No third-party packet,
HTTP, system API or driver implementation is copied into this module.

Optional runtime dependencies are separately installed and retain their own terms:

- [Scapy 2.8.0](https://pypi.org/project/scapy/2.8.0/): GPL-2.0-only.
- [psutil 7.2.2](https://pypi.org/project/psutil/7.2.2/): BSD-3-Clause.
- [Requests 2.34.2](https://pypi.org/project/requests/2.34.2/): Apache-2.0;
  its separately resolved dependencies have their own notices.

This repository distributes this selected source, not a combined executable,
environment or capture driver. It does not grant MIT to Scapy or represent a
combined Scapy installation as MIT-only. Any separate combined redistribution
must satisfy the applicable dependency licenses. Requests and Scapy are lazily
used in separate optional worker paths. Npcap/native backends are separately
supplied under their own terms and are not bundled.

Primary behavior references:
[Scapy capture API](https://scapy.readthedocs.io/en/stable/api/scapy.sendrecv.html),
[psutil](https://psutil.readthedocs.io/en/stable/),
[Requests advanced behavior](https://requests.readthedocs.io/en/latest/user/advanced/),
[OTX API/SDK](https://github.com/AlienVault-OTX/OTX-Python-SDK).
Only API concepts/formats were consulted; no SDK implementation is bundled.

Public fixtures use documentation IPv4 ranges and invented packet records,
responses, keys and interface labels. No real network data or identifying
runtime metadata is selected. Ordinary source/commit metadata and required
notices remain. This review does not clear unrelated held applications.
