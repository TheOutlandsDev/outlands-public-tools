# Changelog

## 0.1.0

- Initial standalone source ZIP for the existing single-script saved-report
  comparator, retaining its CLI, parser, comparison semantics and MIT license.
- Self-contained fictional walkthrough compares complete matching, difference,
  coverage-review, reported-hash hint and fixed-error JSON/exit outcomes while
  preserving controls, pre-existing output and runtime bytes.
- Qualification selects fresh Windows/Ubuntu Python 3.12, 3.13, 3.14 and 3.15.2
  environments without pip or installed distributions, independent source ZIP/
  build-manifest reproduction and optimized-helper refusal. Actual results
  belong to release validation.
- Preserved the 45 original test method bodies, original example/control bytes
  and existing `.gitattributes`. The generator-compatibility test uses a pinned
  test-only public Source Inventory producer pair; the CLI has no producer
  dependency. Copied CLI consumers add explicit native and platform contracts.

The source package includes no interpreter/dependency binary, actual inventory,
original private source, operational capture or raw diagnostic log.
