# Offline Player Activity Interval Calculator

Turn saved server population intervals into observed time, online time,
player-hours, and connection-hours. The calculator uses a caller-supplied
fixed UTC offset for daily totals and the Python standard library.

- [Source ZIP, SHA-256 checksums, and validation records](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/player-activity-interval-calculator-v0.1.0)
- [Usage guide and fictional intervals](SETUP.md)

Both original interval cases are preserved. Qualification covers Windows
and Ubuntu with Python 3.12.16 and 3.15.2.
