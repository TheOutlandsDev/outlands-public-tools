# Offline Order Status and Lead-Time Calculator

Classify saved orders as Open, Docked, or Shipped and calculate calendar lead-time dates from a supplied part table. The tool resolves part aliases and reports the canonical part and its mapped modality. The bundled order and rule records are fictional.
