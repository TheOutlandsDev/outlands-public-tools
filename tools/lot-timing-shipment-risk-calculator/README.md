# Offline Lot Timing and Shipment Risk Calculator

Calculate timing and shipment priority for saved lot allocations using a fixed planning date. Report remaining days, schedule slack, and each order's highest-priority lot.

See the [usage guide](SETUP.md) for the fictional example and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/lot-timing-shipment-risk-calculator-v0.1.0) for downloads and validation records.
