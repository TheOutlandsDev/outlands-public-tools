# Private DOCX workspace

Select stable regular DOCX inputs explicitly in a trusted private directory outside the source checkout or extracted source. Qualification uses only invented documents. The runtime reads bounded ZIP/XML buffers; it does not extract archives, start Office, execute document content or follow external resources.

Default output contains a table index, counts and fingerprints; explicitly requested tables and paragraphs expose stored text in caller selection order. Document properties are omitted, while body text, sizes, hashes and structure remain identifying. This does not anonymize real documents or establish rights to publish them. Supported stored text is distinct from visible Word/LibreOffice layout, styles, automatic labels or general document compatibility.

The deliberately narrow OOXML subset rejects many ordinary features. Parser and ZIP bounds are cooperative application limits, not an OS sandbox or hard execution deadline. Keep inputs and ancestors quiescent. Native checks refuse linked/multilink routes and require fully spelled ordinary paths. The Windows writer includes the reviewed native create-new/reparse-point fix and rejects existing leaves, including dangling links, without creating their targets. No hostile-writer containment or atomic filesystem snapshot is certified.

Choose an existing parent you control and a fresh external output name. Existing files are never replaced. Failed writes may retain unconfirmed partial output; preserve it and choose a new destination. Windows permissions inherit from the parent. Obtain CPython separately: no interpreter, original document/template, generated report, account data, credential, raw log or third-party binary is bundled.
