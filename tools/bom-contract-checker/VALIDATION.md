# Validation and interpretation limits

The material-lot-checks workflow qualifies Python 3.12/3.13 on Windows and Ubuntu
with exact source pins, fictional HVAC declarations and mandatory applicable native
fixtures. Hardlink and parent symlink/junction cases must execute; only the opposite-
platform boundary method per tool may skip. Local volume skips are not native proof.

Known-result cases cover multi-level and diamond BOM arithmetic, direct leaf orders,
parallel edges, disconnected cycles and derived quantity refusal; explicit alias
chains, collisions, missing targets, thousand-node iterative traversal and canonical
stock totals; shared alias/canonical reservations, split demand, unreserved supply,
shortage/excess/overreservation and exact large integers; accepted/cancelled handoff
states, ties, missing terminal events, orphan/mismatched/duplicate receipts and
all-or-none cohort withholding. Every source row is accounted for.

Standalone CLI acceptance copies each directory independently, checks source pins,
runs invented examples, creates new reports, refuses overwrite/source-tree output,
and checks fixed errors, input pins, no input mutation and no target artifacts.
The actual connected four-tool exercise derives two motor/four filter requirements
from two fictional air-handler kits, resolves motor labels, checks reservations
with a shared inventory pin, then supplies an invented two-motor handoff receipt.
A separate case shows a consistent accepted handoff cannot override an inventory
shortfall. The exercise explicitly supplies all links; none are inferred.

These are synthetic functional and filesystem checks. They do not establish actual
equipment compatibility, sizing, approved BOMs, physical identities, stock amounts,
reservation locks, authentic delivery, operator authority, production readiness,
private-data clearance or rights to publish future inputs. No stock, reservation,
order, equipment setting or service action is changed. Original private programs,
schemas, policies, documents, assets and records were not selected or executed.
