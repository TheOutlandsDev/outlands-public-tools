# Offline Game Server TCP Session Counter

Count established TCP sessions and distinct peers from saved socket rows. Select the server by process ID and local port. Optionally count local connections separately. Reports contain aggregate counts.

See the [usage guide](SETUP.md) and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/game-server-tcp-session-counter-v0.1.0) for fictional inputs, source ZIP, checksums, and validation records.
