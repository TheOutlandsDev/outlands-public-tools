# Security scope

Use this editor only on trusted local storage and loopback. Do not port-forward,
reverse-proxy or bind it publicly. Export reviewed published files if you need a
static public site. Authentication and the local inbox are not public CMS hosting.

For a suspected vulnerability, use GitHub's **Report a vulnerability** option if
available. If it is unavailable, open a minimal issue asking for a private contact
channel without exploit details, credentials, private data or a working attack
against a real installation. Do not publish another person's private information.

There is no support SLA. Keep backups before changing a working site and review
dependency advisories. No test or advisory scan proves universal security.
