# Changes

## 1.0.0 - 2026-10-25

- Generalized the original local block editor into an MIT application with an
  original fictional site and no private brand/content/data.
- Added loopback-only access, Host/Origin checks, session-bound CSRF including
  opaque local webviews, strict cookies, login/contact limits and page validation.
- Checked raster upload signatures and capped multipart/file counts and sizes.
- Kept published metadata separate from private draft edits during menu refresh.
- Added hidden-password setup, exclusive data ownership, verified stopped-site
  backups, fresh-directory restore and public-only static export.
- Added generated integration tests, Windows/Linux CI, lock-based dependencies,
  retained notices, detailed examples and public suggestion/bug-report forms.
