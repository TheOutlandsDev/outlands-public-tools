# Provenance and MIT scope

Two local personal helpers, `patch_vehicle_storage.py` and
`patch_bmd_values.py`, used checked offsets/expected values when changing
game-specific binary data. This publication retains only that generic
review-before-write mechanism in a fresh, bounded exact-byte plan format.
It includes no old offsets, game-specific changes, inherited format parser,
game/mod asset, PAK/DMBU implementation or binary patch payload from those helpers.

The owner identified the selected investigation helpers as personal work.
The original files remain unchanged and fingerprinted in the private batch
review. That review is not independent proof of exclusive historical authorship.
The public planner, test fixtures, guides and generator are newly authored MIT
code. Stable-file and report infrastructure reuses first-party MIT source from
this collection. No upstream library implementation is copied or bundled.

The separately installed Python runtime retains its own terms. The
[Python file-opening reference](https://docs.python.org/3/library/os.html#os.open)
and [JSON behavior documentation](https://docs.python.org/3/library/json.html#standard-compliance-and-interoperability)
were consulted on 2026-10-26 to check API and validation assumptions. The tool
adds its own strict bounds/key/numeric rules rather than claiming default JSON
decoding is sufficient for an untrusted plan. References retain their own rights.

MIT covers newly authored source, documentation/tests and fictional generators.
Inspected binaries/plans and generated derivatives retain their own applicable
rights. Hash verification grants no right to redistribute input or candidate
content. No real binary, game asset, private capture or device recipe is selected.

Tests use generated data only. No actual application, firmware, game, protected
binary or device was patched or executed as publication evidence.
