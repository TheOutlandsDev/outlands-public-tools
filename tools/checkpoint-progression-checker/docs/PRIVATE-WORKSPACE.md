# Private checkpoint review

Select one stable ordinary JSON file with explicit expected batches and receipt declarations. The previous and proposed checkpoints are abstract nonnegative integer ordinals, not timestamps, database offsets or external watermarks. Every integer in (previous, proposed] must have accepted expected coverage and an exact healthy committed receipt. Any gap, rejected/conflicting/alias/scope/outcome/metadata issue or unexpected receipt withholds the entire suggested checkpoint. Healthy resolution counters alone do not establish eligibility. An equal empty window can pass with the unchanged ordinal and advancement eligibility false.

Batch-list grouping and accounting are observed from the supplied JSON. Embedded source-record counts and source/mapping/preview/receipt pins remain caller declarations: source rows and referenced bytes are not loaded or independently counted. Hashes do not authenticate receipts, verify previous checkpoint authority, prove complete history or establish exactly-once execution. checkpoint_written and previous_checkpoint_authority_verified remain false. This tool does not advance a checkpoint, import, retry, dispatch, poll, update a database/journal or perform a network action.

Reports retain checkpoint ordinals, list/resolution counters, issue positions/codes and an input fingerprint. Keep real inputs and outputs private; they are not anonymized. Use fully spelled, stable ordinary paths under trusted quiescent parents. Output must use a fresh external name under an existing parent. Native linked/multilink paths are refused. Windows creation uses CREATE_NEW and OPEN_REPARSE_POINT and refuses existing leaves, including dangling entries. Failed writes can leave unconfirmed partial output; inspect it and select a new name. Parent ACLs are inherited. Cooperative limits and sampled metadata do not establish an atomic snapshot, hostile-writer containment, transactional rollback, OS sandbox or hardware durability.

Only generic source and two invented JSON examples are published. Private expected/receipt histories, real source records, generated reports, SDKs, credentials and raw evidence remain local. Obtain Python separately. Qualification does not validate real business approval, receipt authority or safety of advancing an external checkpoint.
