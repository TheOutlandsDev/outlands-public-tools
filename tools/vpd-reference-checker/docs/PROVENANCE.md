# Provenance and MIT scope

This module is newly authored original Python source, tests, static report
markup/styles and fictional examples, developed with AI assistance. Its local
foundation is the owner's project-preservation helpers `prepare_video.py` and
`review_video_projects.py`: bounded JSON structure inspection, path-reference
listing and timeline entry counts. The public implementation replaces their
fixed locations, original data selections and one-off preservation behavior
with an explicit, reusable, bounded interface. Local original helpers remain
unchanged. No actual VPD project, UUID, recording, private path, export setting,
speed-curve serialization or `.userdata` session enters this module.

The [official VideoProc Vlogger project guide](https://www.videoproc.com/video-editing-software/guide-free-win/create-new-project.htm),
checked on 2026-10-25, identifies `.vpd` project files and describes the editor's
project/archive workflow. It supplies format identification, not a published
JSON schema, license grant or editor/version validation for this tool. Our JSON
positions are observational and the supported public fixtures are invented.
The tool is not affiliated with or endorsed by VideoProc/Digiarty.

No editor/native/parser implementation, proprietary media, third-party project,
plugin, image, audio, FFmpeg binary or external Python package is bundled.
Python's runtime/standard library, VideoProc software and all inspected inputs
retain their own terms. Only this original source, tests, documentation and
fictional fixtures are offered under [MIT](../LICENSE). Inspecting or describing
another file does not relicense it, certify its authorship, or grant permission
to redistribute referenced media.

The public fixture is deliberately a structural test input. Empty `.mp4`
placeholders demonstrate the limited meaning of a present regular file; they
are not sample recordings and are not editor acceptance evidence. The actual
owner-held project/media data remains private outside this source export.
