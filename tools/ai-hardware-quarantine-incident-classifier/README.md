# Offline AI Hardware Quarantine Incident Classifier

Report a critical AI incident when a saved telemetry snapshot shows a latched hardware quarantine. The CLI preserves the original AI incident scope, reason truncation, and fingerprint.

See the [usage guide](SETUP.md) and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/ai-hardware-quarantine-incident-classifier-v0.1.0) for the two fictional examples, source ZIP, checksums, and qualification records.
