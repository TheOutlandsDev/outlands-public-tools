# Separately obtained packages

NumPy, Pillow, Matplotlib and their resolved dependencies are obtained separately
from PyPI using requirements.lock; their binaries are not redistributed in this
source ZIP. DEPENDENCIES.json links exact-version metadata and license identifiers.
Preserve upstream notices if distributing a separate runtime. The pinned standalone
CPython SDK has its own license and is downloaded separately, not bundled. The
included Rev 3b engine is already-public first-party MIT source. No model, original
microscopy image or vendor XML is redistributed. An advisory lookup is an observation,
not a security certification or a guarantee against future advisories.
