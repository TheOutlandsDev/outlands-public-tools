# Private fstab comparison workspace

Use two explicitly selected, stable regular local text files in a private directory outside the extracted source. Select Linux or Android format explicitly. The reader compares a documented subset of saved declarations and never mounts/probes a filesystem, edits a configuration or connects a device. Qualification uses fictional inputs; bootability, effective flags and actual device state are not verified.

Only exact decoded unique mount targets are paired. Duplicate targets on either side remain ambiguous and are excluded from change pairing and relative order. Option and Android fs_mgr flag order/duplicates remain text; no runtime-equivalence or override winner is inferred. Unsupported rows make coverage incomplete even for identical inputs. Empty/comment-only inputs may have no supported findings without proving completeness.

Default reports omit input filenames and raw field values. Explicit details disclose selected declarations. Hashes, line numbers, target groups and structural observations remain identifying, so omission is not anonymization. Keep real configs and reports private. Only the selected text files are read; declared device/source/mount paths are not followed.

Choose an existing parent you control and a fresh output name. Regular-file/link/alias checks, stable-input checks and cooperative resource bounds are not an OS sandbox, hostile-filesystem transaction, atomic snapshot or hard I/O deadline. Failed writes may leave a new partial report directory. Preserve it and select a fresh destination after fixing the cause. Unsigned hashes/manifests establish scoped consistency, not authenticity or boot/mount safety.

The release includes original MIT source, fictional examples, tests, packaging/bootstrap and qualification methods. Obtain CPython separately. No interpreter, real configuration, device payload, operational report, raw log, credential or third-party implementation is bundled.
