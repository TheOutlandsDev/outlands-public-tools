# Security and private workspaces

This program changes only its explicitly selected managed workspace when you
request initialization, import, activation, deactivation or recovery. Preview,
status and listing do not authorize later mutations. The engine rechecks actual
state and hashes. Imported originals remain separate. Keep trusted local parents,
quiescent files and enough disk space; close programs that may write managed data.

The supported path/tree checks refuse links/reparse routes, hardlinked regular
files, special files, unsupported names and ambiguous paths. These checks are
not an operating-system sandbox against a hostile concurrent writer replacing
ancestors or editing the workspace. Windows inherited ACLs and complete metadata
privacy are not established by ordinary file-mode requests. Use a private folder
you control and appropriate independent filesystem permissions.

Manifests/journals/profile names and GUI/CLI results can identify files or users.
They are private operational data, not anonymized support output. The public
source package contains only authored code, instructions and fictional fixtures;
it does not include your workspace. Hashes check consistency, not ownership,
authenticity, semantic safety, game compatibility or freedom from harmful input.
Imported files are copied as bytes and never executed by this manager.

No network or upload feature, game detection, shell evaluation, game launch,
device operation, delete or purge command is implemented. The manager does not
validate a mod's rights, code, behavior, loader support or platform compatibility.
A game may still alter a profile after you connect its loader to the active path.

If an operation fails, stop other mutations and review status. Keep partial
stages, previous trees and journals intact; use documented recovery. Unknown or
changed files require review rather than forced overwrite. Retained copies grow
with use; there is no automatic cleanup. Hash/readback and requested flushes do
not prove power-loss durability or an atomic snapshot.

Report ordinary issues with minimal fictional examples through the
[issue forms](https://github.com/TheOutlandsDev/outlands-public-tools/issues/new/choose).
Do not post secrets or real workspace files publicly. A vulnerability report
should describe affected versions and a synthetic reproduction without exposing
private inputs. This source release makes no universal security guarantee.
