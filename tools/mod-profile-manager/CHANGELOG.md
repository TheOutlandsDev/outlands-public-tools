# Changelog

## 0.1.0 — standalone qualification release

- Preserve six runtime/generator files, all 118 originals and four historical
  records; add thirty copied-runtime CLI checks and exact source/archive gates.
- Qualify pinned CPython 3.12–3.15 on Windows/Ubuntu with separately measured,
  hash-bound Tcl/Tk components/display and required native widget checks.
- Add an independent fictional activation/retention/recovery guide with complete
  manifests, actual random-ID relations, native lock/refusal and immutable sources.
- Publish the source ZIP, checksums, guide, validation JSON and build manifest.
  No actual games/mods/saves, gameplay, power loss or full metadata are qualified.

Earlier [validation](docs/VALIDATION.md), provenance, format and examples records
remain unchanged. Synthetic interruptions/native-widget fixtures remain distinct
from real deployment and do not establish a universal rollback/durability claim.
