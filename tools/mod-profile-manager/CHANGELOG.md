# Changelog

## 0.1.0 — 2026-10-26

- Original bounded managed-profile engine with verified imports, explicit plans,
  activation/deactivation, retained copies and operation recovery.
- CLI and optional Tk desktop interface, with fictional examples and tests.
- Detailed supported scope, privacy, provenance and community instructions.

This is an initial source release. Acceptance uses generated files rather than
real game installations, mod collections or game-runtime compatibility tests.
