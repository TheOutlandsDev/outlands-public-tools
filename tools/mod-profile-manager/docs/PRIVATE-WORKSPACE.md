# Private managed profile qualification workspace

Use new owned private directories outside the extracted source for fictional source trees, managed workspaces and evidence. All generated fixtures are invented regular-file payloads, not installable mods. Preserve real profiles, saves, configuration and game installations separately; they are not inspected or changed during qualification.

The manager controls only its own fixed active directory and retained copies. A preview is read-only and reserves nothing; mutation revalidates current state. Source imports remain unchanged and managed copies are independently hashed. Switching/deactivation retain earlier active trees. Recovery examines documented intent/stage/retention/commit state; it is not a universal disk-repair or power-loss guarantee. Do not manually remove drifted or retained evidence to force a pass.

Windows native no-replace renames and byte-range locks and Linux renameat2/no-replace plus advisory locks are exercised using owned fictional roots. Applicable links/hardlinks, streams, identities and unsupported names remain guarded. Case-fold aliases are measured rather than assumed. Cooperative checks do not eliminate hostile concurrent ancestor mutation or harden untrusted network filesystems.

CLI and native Tk evidence are separate. Every formal full-suite lane requires ten real withdrawn-widget tests in addition to 108 non-widget originals. Tcl/Tk components and scripts bind to the hash-pinned Python recipe in GUI-LOCK.json. Ubuntu uses an owned Xvfb display. A missing binding/display is a failure, not GUI acceptance. Controller fakes test ordering and cancellation without replacing the real engine/widget flow.

All eight out-of-scope claims remain false: real game files used, real mod profiles used, game integration verified, gameplay verified, saves accessed, external game directories modified, power-loss durability verified and full metadata preservation verified. Windows ACLs/ownership/timestamps/alternate streams and live game-loader integration are outside this acceptance.

The public release contains original MIT source, fictional generator, tests and reproducible packaging/qualification methods. Obtain Python/Tcl/Tk and any display provider separately under their own licenses. No interpreter, Tcl/Tk binary, X server, real game asset/mod, save, actual workspace, private inventory, raw operational log or credential is bundled. Hashes establish selected byte consistency, not authenticity, executable safety, rights or gameplay compatibility.
