# Provenance and MIT scope

Two local personal `manage_mods.py` helpers supported game-specific status and
enable/disable workflows with selected manifest hashes. This publication takes
that general profile-management use case and supplies a new bounded managed
workspace implementation. No original game paths, process selectors, game/mod
assets, existing manifests, game-specific configuration or helper implementation
body is copied into the public module.

The owner identified those helpers as personal work. Their preserved originals
remain unchanged and fingerprinted in the private review record. This review is
not independent proof of exclusive historical authorship. The new engine, CLI,
desktop, tests, guides and fictional examples are original MIT work, with
AI-assisted development. First-party file/path/report ideas are reused from
OUTLANDS Public Tools under MIT. The larger Safe File Mover engine is not
bundled or imported, and its earlier validation is not claimed for this program.

Native API and file-operation behavior were checked against primary references:

- [Python file operations](https://docs.python.org/3/library/os.html)
- [Linux rename and no-replace semantics](https://man7.org/linux/man-pages/man2/rename.2.html)
- [Windows file locking](https://docs.python.org/3/library/msvcrt.html#msvcrt.locking)
- [Tkinter](https://docs.python.org/3/library/tkinter.html)

References and separately installed runtimes retain their applicable rights and
notices. No upstream implementation, native library, runtime or third-party
fixture is copied or granted MIT by this project.

MIT covers the original program, tests, authored documentation and generated
fictional fixture design. Imported files, resulting active copies, retained
content and private state retain their own rights. No inspected file becomes
MIT-licensed merely because it is copied or hashed. The public source review
does not clear any unrelated held employer/client project or confidential data.

Acceptance uses disposable generated profiles only. No real game installation,
save, proprietary profile, live loader, device or production directory was
activated, modified or accepted as part of publication testing.
