# Fictional examples

From the module folder run `python -B examples/generate.py --output ABSOLUTE_NEW_DIRECTORY`.
The parent must exist and the output directory must be new. All generated data
is authored and fictional. Keep generated inputs/reports outside the source tree.
See the [quick start](../README.md) for inspector commands and expected results.

No real event logs, device configurations, filesystem metadata or credentials
are packaged. Examples are not suitable for installation or system changes.
