# Fictional examples

Run `python -B examples/generate.py --output ABSOLUTE_NEW_DIRECTORY` from the
module folder. The parent must exist. The generator creates only the declared
text fixtures, refuses an existing directory and does not use any real config.
See the [quick start](../README.md) for exact inspector commands and expected
exit codes. None of the generated configs is suitable for installation, boot,
mounting or copying payloads. Keep generated reports outside the source tree.
