# Contributions and suggestions

Bug reports, documentation improvements and supported-format proposals are
welcome in the [issue forms](https://github.com/TheOutlandsDev/outlands-public-tools/issues/new/choose).
Include OS/Python version, source commit, command shape, expected versus observed
behavior and the smallest invented reproduction. Avoid real firmware, personal
paths, credentials, device identifiers and identifying reports.

Keep the module standard-library only and metadata-only unless a proposal first
defines a clear new scope and limits. Cover behavior and malformed input with
meaningful tests. Preserve exact findings versus coverage distinctions and the
fresh-output/read-only boundaries. Run the documented tests and source check.
The project maintainer updates the reviewed source inventory after review.

Contribute only material you are authorized to offer under MIT. External format
references retain their own licenses. No vendor binaries or copied upstream
implementations should enter the source package.
