for neutral flat settings. Its sampled bounded input handling adapts this
collection's public MIT Connection Plan Checker pattern. It is not a general
JSON Schema interpreter or importer for a private application schema, arbitrary
expression, script, reference resolver or environment configuration.

baseline `bcab806833c7e03ead327a73e8e8f905d42939af`. The runtime already displayed
version 0.1.0. Standalone packaging adds no scalar/rule/result, settings-default,
runtime verification or input-path repair. New source attributes preserve
reviewed bytes; no normalization makes protected hashes pass.

All 44 original method bodies, 129 total assertion calls and twelve local/shared
helper ASTs remain preserved. There are 128 assertions inside test methods and
one in `ContractFixture.reader_failure_traceback`. Explicit `python-ast-fields-json-v1` encoding
retains full AST fields across supported Python versions without weakening
within-version original/adapted equality. Only needed shared `Fixture`/`load`
scaffolding is retained, avoiding unrelated applications. In-process imports
select the actual extracted checker; a ROOT-relative subprocess test needs an

Passing declared constraints does not establish application acceptance,
