# Offline Game Log Snapshot Exporter

Turn saved logs for Rust, DayZ, SPT, Modern Warfare / IW4x, and Project Zomboid into SHA-256 snapshots for the [Offline Game Telemetry Snapshot Verifier and Replay Tool](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/game-telemetry-snapshot-verifier-replay-v0.1.0). The exporter uses Python's standard library.

See the [usage guide](SETUP.md) for a fictional walkthrough and qualification details.
