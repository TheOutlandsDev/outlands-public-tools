# Offline Planning Source Candidate Reviewer

Review a saved candidate bundle with orders, work-in-progress, a lot-start log, and a last-lot registry. The reviewer verifies file lengths and SHA-256 digests, compares orders with an optional saved baseline, and reports lot ID collisions.
