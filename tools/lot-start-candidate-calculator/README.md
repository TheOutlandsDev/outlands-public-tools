# Offline Lot-Start Candidate Calculator

Calculate lot counts, planned capacity, and candidate IDs from uncovered demand, observed IDs, and a saved product policy. The calculator accepts the JSON emitted by the Offline Lot-Start Reservation Policy Projector.

See the [usage guide](SETUP.md) for the fictional example and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/lot-start-candidate-calculator-v0.1.0) for downloads and validation records.
