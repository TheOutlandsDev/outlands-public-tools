# Security and privacy

This is experimental source for a game-mod process, not a sandbox. Enabling it
can change bots and normal game outcomes. Use a separate disposable solo install
and verified profile/config backups before tests. Fika spawning is blocked and
gameplay has not been qualified. Do not bypass a managed client's integrity policy.

Use private GitHub vulnerability reporting if offered. Otherwise open a minimal
public issue requesting a private channel without exploit details or private
data. There is no guaranteed response time. Redact game logs before sharing;
never upload profiles, account/session data, proprietary DLLs or private addresses.

Runtime gates, expected-profile/group ownership and stale-callback checks are
defensive source mechanisms. Core fixtures and a matching-SDK compile do not
prove their behavior under the Unity runtime, every backend/AI mod, hostile
filesystem, native stall or game update. External component terms still apply.
