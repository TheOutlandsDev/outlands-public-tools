# Provenance and publication boundary

The starting point was the owner's local Friendlies 0.3.0 draft: one plugin file
and a project file, preserved separately with original-path hashes. It contained
a paste-placeholder line, fixed private SDK paths and a speculative spawn-method
search. Its roles/faction did not govern bot creation; friendly/follow behavior
was not established. No authorship/license notice was removed. Those originals
remain unchanged and are not replaced by this public rewrite.

The selected release core, typed adapter, UI, follow logic, tests, examples and
documentation were freshly authored for this requested cleanup, with AI assistance.
They retain the draft's intended squad/faction/preset use case while replacing its
unsupported mechanisms. The owner authorized experimental source-only MIT release
and chose solo first after being informed gameplay could not be tested here.
Owner-reported personal authorship and this review are not independent guarantees
of exclusive ownership of unrelated historical materials.

Local read-only managed metadata inspection established public type/member
signatures. The compiler read the same local SDK references; no game assembly,
method body, generated API report, IL dump, vendor implementation, proprietary
asset, real profile, server configuration or private path is part of this source.
No inspected game/mod assembly was executed by the metadata inspector or core
tests. Client gameplay itself was not run.

The original release files are MIT licensed. Runtime/game references retain
their own terms; references and names do not grant redistribution rights.
BigBrain's public extension API is credited to DrakiaXYZ; BepInEx/HarmonyX are
credited to their maintainers. No external framework implementation was copied.
No Fika, MoreBotsAPI, SAIN, PitFireTeam or other companion-mod implementation is
included or relicensed. Consult THIRD-PARTY-NOTICES.txt for the scoped notices.

The local SDK installation includes a legacy LGPL text in a file labelled for
BepInEx, while the upstream BepInEx 5.4.23.2 tag publishes an MIT license. This
release makes no blanket license claim over that installed distribution and
redistributes none of it. Dependency bundling would require its own complete
notice/license review. This does not change the selected original source grant.

All public files are selected by an explicit source manifest. Private SDK
fingerprints, original-path hashes, compiled products and inspection/build
receipts remain outside the public source stage. No plugin was installed into
the managed client and no save/profile was changed.
