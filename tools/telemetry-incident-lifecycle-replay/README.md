# Offline Telemetry Incident Lifecycle Replay

Replay saved observations and operator actions through the original incident lifecycle rules in a fresh temporary SQLite database. Track clean samples, acknowledgement, resolution and resolved-only cleanup.

See the [usage guide](SETUP.md) and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/telemetry-incident-lifecycle-replay-v0.1.0) for the fictional recording, source ZIP, checksums, and qualification records.
