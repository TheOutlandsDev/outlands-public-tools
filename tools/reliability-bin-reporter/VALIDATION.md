# Validation and interpretation limits

The probability-integrity-checks workflow qualifies Python 3.12/3.13 on Windows and
Ubuntu, requiring native hardlink, linked-parent, changed-input, new-file and overwrite
checks. Only opposite-platform methods may skip; local volume skips are not native proof.

Known-answer/adversarial tests cover exact vector sums without epsilon/renormalization,
missing classes/vectors, decimal normalization and ambiguity; explicit label direction,
complete squared-error denominators, missing/unknown evidence, stale scope pins and
withheld partial aggregates; exact half-open bin boundaries including one, empty bins,
gaps, overlaps/nested unions, signed gaps and fixed weighted summaries; monotone/flat
maps, complete domains, ambiguous inputs, revision rules, identity changes, decimal
spellings and full 64-point bounds. All identity lists preserve complete row accounting.

Standalone CLI acceptance copies each directory independently, verifies source pins,
runs examples, creates fresh reports, refuses overwrite/source-tree output, checks raw
input pins/fixed errors and verifies no input mutations or target artifacts. A connected
invented four-case HVAC exercise validates full vectors, explicitly projects the declared
positive class, computes total squared error 3/8 and mean 3/32, reconciles identical
binary scopes in three fixed bins with weighted absolute gap 1/4, and reviews a revised
map without applying it. A separate game NPC vector sums exactly to one. Missing
outcome acceptance withholds both error and bin aggregates rather than scoring a subset.

These are synthetic functional checks, not model inference, calibrated confidence,
authentic outcome labels, independent holdouts, representative sampling, statistical
significance, private-data clearance, fitted-map provenance or production suitability.
Original private code, calibration policies/parameters, models, records, data, paths,
credentials and operational configuration were not consulted or selected. No fitting,
map application, model update or operational action is performed.
