# Changelog

## 0.1.0

- Publish a standalone source-only Markdown Document Builder qualification for
  Windows x64 and Ubuntu x86_64 with CPython 3.12, 3.13, 3.14 and 3.15.2.
- Preserve both runtime files, all 72 existing test methods and the fictional
  Markdown example. Retain the distinct POSIX and Windows write-failure policies.
- Pin the full selected dependency closure and installer with artifact hashes,
  platform/ABI locks and fresh offline installation verification.
- Add 30 copied-runtime CLI/package checks, exact native skip contracts, source
  manifests, deterministic source ZIP packaging, usage and validation records.
- Keep generated DOCX packages, wheels, interpreters, environments and raw logs
  outside the published source artifacts. Visual Office rendering remains a
  separate acceptance step.
