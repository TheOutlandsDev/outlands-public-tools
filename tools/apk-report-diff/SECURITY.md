# Security and private data

This tool reads selected local text and writes fresh private reports. It does
not inspect app safety, install software or grant redistribution rights. Input
and output limits reduce accidental resource use but are not a sandbox against
a hostile local user or every filesystem race.

Keep real captures, APKs, identifying reports and credentials out of public
issues. Use a small fictional reproduction when possible. Use GitHub private
vulnerability reporting if available; otherwise request a private contact route
without disclosing sensitive details. No private endpoint is promised. Do not
post exploit details with private data in ordinary public suggestions.

Default field omission is not anonymization. Text hashes, field presence/order
and counts can identify source material. Review JSON, HTML and manifest together
before sharing. Details explicitly includes supported identities and values.
