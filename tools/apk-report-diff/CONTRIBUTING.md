# Contributions and suggestions

Bug reports and suggestions are welcome in the collection's
[issue forms](https://github.com/TheOutlandsDev/outlands-public-tools/issues/new/choose).
Choose APK Metadata Report Diff and give expected behavior, source commit,
OS/Python version and the smallest fictional saved-text reproduction.

Use generated names and values. Do not attach proprietary APKs, real captures,
private paths, account/device identifiers, application inventories, credentials
or unredacted reports. Review output including hashes before sharing. Unsupported
syntax should produce coverage, not silently become an absent declaration.

Changes should retain the documented bounds, conservative ambiguity handling,
fixed errors, no automatic capture and original-code license boundaries. Add a
meaningful regression fixture and update grammar/examples when extending scope.
Run unit tests and the exact source inventory gate. Coordinate public source
manifest changes with the reviewed allowlist; do not weaken guards to pass a test.

Contribute only material you have rights to provide under the module's MIT
license; retain applicable existing notices. Read [security](SECURITY.md) for
handling issues that could expose private information.
