# Offline Repeated-Block WIP Workbook Extractor

Check a supplied SHA-256 and extract typed work-in-progress rows from a saved inventory workbook with 26 repeated header blocks. The report retains workbook row numbers and provides a records array for the WIP Supply Normalizer.
