# Offline Automatic Lot-Start Configuration Projector

Project a saved planning policy into automatic lot-start calculator rules. Use the replay export with the Order Demand Lifecycle Replay Reporter. The examples use fictional products and orders.

See the [usage guide](SETUP.md) and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/automatic-lot-start-configuration-projector-v0.1.0) for the source ZIP, SHA-256 checksums and qualification records.
