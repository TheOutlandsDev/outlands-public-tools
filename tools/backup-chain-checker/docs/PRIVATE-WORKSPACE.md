# Private workspace

Extract public source into a fresh directory. Choose a separate existing,
user-owned private parent for Python/venvs, fictional work, actual declarations,
stdout captures and qualification receipts:

```text
source/backup-chain-checker-0.1.0/  selected source only
private/backup-chain/
  venv312/                         separately created no-pip environment
  fictional_walkthrough.py         private copy of the usage driver
  fictional-demo/                  new owned graph metadata only
  actual-plan.json                 real declaration, private
  captures/                        caller-selected stdout/diagnostics
  qualification/                   extraction, environments and receipts
```

Select the intended interpreter and `chain_check.py` explicitly. Provide
`--plan FILE`; no backup root, default/environment plan, output writer,
installer, restore command or deletion switch exists. Only the selected JSON
control is read; backup storage/contents are not enumerated or opened. The
checker prints JSON stdout. Shell redirection/caller code controls captures
and may overwrite them; select new private capture paths deliberately.

The model accepts one selected restore-point ID and bounded full/incremental
single-parent declarations. Series and sequence labels remain unverified
metadata, not temporal or content evidence. Unsupported vendor/dependency
formats must use another review process; do not strip fields or invent a
parent link to force an actual set into this schema.

Results omit series labels, sequence values, parent fields, selected paths and
native details but retain IDs, counts, local issue relationships and selected
declared order. Those fields can identify an operational design. Fixed errors
do not anonymize caller logs, captures or formatted library tracebacks. Keep
real controls/results private and review a separate export before sharing.

All declarations are checked, including unrelated branches. A clean selected
order can coexist with overall review. A selected local/ancestor issue blocks
the entire order; cycle descendants are not mislabeled cycle members. None of
these observations establishes backup existence, content validity, authenticity,
completeness, independence, application consistency, restorability or deletion
authority. No restore or removal command is generated.

Use fully spelled trusted canonical paths and stable ordinary files. Original
components are checked before absolute-path normalization and checked again
afterward. Input must have supported ordinary single-link/type/ancestor
identities. Observed links/reparse/special/multi-link inputs and sampled changes
are refused. Checks do not retain an immutable/atomic snapshot, deny all writers
or establish a hostile-filesystem boundary. Arbitrary mount/drive aliases,
rebinding, remote/cloud/virtual/live storage, blocked OS I/O, power loss and ACL
privacy remain outside acceptance. OS reads can involve network storage without
a socket/DNS probe. Reads can affect access metadata; Python caches are separate.

The selected control is at most 64 KiB, with 1–256 snapshots and bounded tokens/
sequences. These are not total CPU/memory/JSON-depth/deadline or storage quotas.
Require complete JSON and the actual exit/status; interruption or stdout
failure may leave partial captures. There is no checker-owned output tree to
roll back. The walkthrough retains authored fictional work for inspection,
without automatic cleanup. Requested modes depend on OS/Python/ACL behavior
and are not a confidentiality guarantee.

User-owned Python/venvs do not inherently need administrator access. Respect
device policy and OS prerequisites without bypasses. No pip distribution,
network, model or account is needed; interpreters remain separately licensed.

Build/qualification outputs must be new private paths outside source with
existing parents. Publish reviewed source and sanitized actual validation only,
excluding real backup metadata/data/results, IDs/dependencies, personal paths,
credentials, original private source, interpreter/dependency binaries and raw
logs. See [USAGE.md](../USAGE.md), [QUALIFICATION.md](QUALIFICATION.md) and
[PROVENANCE.md](PROVENANCE.md).
