## 0.1.0

- Initial standalone source ZIP for the existing single-script declared graph
  checker, retaining its schema, graph/target/result behavior, fixed errors,
  displayed version and MIT license.
- Standalone usage, private-workspace and provenance guidance distinguish
  declared consistency/target order from actual backup contents, authenticity,
  recoverability or deletion authority.
- Qualification selects fresh Windows/Ubuntu Python 3.12, 3.13, 3.14 and 3.15.2
  environments without pip or installed distributions, independent committed-
  source ZIP/build-manifest reproduction and optimized-helper refusal. Actual
  outcomes belong to release validation.
- Retained all 43 original test method bodies, 105 assertion calls and eight
  helper ASTs with explicit canonical field encoding. Copied single-script CLI
  consumers add exact native/platform contracts without a runtime mirror,
  test-only donor or shipped duplicate checker.
- Preserved runtime and four fictional JSON examples at exact baseline Git
  bytes. Existing original-path component validation precedes normalization;
  this release introduces no timestamp/retention rule, alias fix or graph change.

No interpreter/dependency binary, actual backup/control/result, private original
source, operational metadata or raw diagnostic log is part of the source ZIP.
