# Offline Game Event Normalizer and Actor Statistics Reporter

Normalize saved event records and calculate descriptive actor statistics using the original event mappings. The CLI uses Python's standard library and accepts fictional or already sanitized telemetry.

See the [usage guide](SETUP.md) and [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/game-event-normalizer-actor-statistics-reporter-v0.1.0) for examples, source ZIP, checksums and qualification records.
