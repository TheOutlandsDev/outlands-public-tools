# Offline Server Inventory Fallback Reporter

Replay a saved inventory result or failure. Keep the previous server list and counts when the saved cache is usable, and report fresh, stale, or unavailable health.

See the [usage guide](SETUP.md) and [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/server-inventory-fallback-reporter-v0.1.0) for the fictional recording, source ZIP, checksums, and qualification records.
