# Validation and interpretation limits

The visual-integrity-checks workflow qualifies Python 3.12/3.13 on Windows and Ubuntu,
requiring native hardlink, linked-parent, changed-input, new-file and overwrite checks.
Only opposite-platform methods may skip; local volume skips are not native proof.

Known-answer/adversarial cases cover complete image/annotation/taxonomy snapshot pins,
unannotated images, stale dimensions/revisions, identity accounting and withheld scopes;
simple/concave polygons, redundant collinear vertices, both windings, half-unit/large
areas, crossings, touches, adjacent backtracking, repeated closing vertices, zero edges,
contact-detail caps and vertex budgets; exact box conversions and rational round trips,
half-open extents, nonintegral/outside/degenerate refusals, normalized snapshot equivalence
and mixed valid/invalid diagnostics; explicit category mappings, full annotation approvals,
subset counts, stale unused references, missing/rejected approvals and every count mismatch.

Standalone CLI acceptance copies each complete tool independently, verifies source pins,
runs examples, writes fresh reports, refuses overwrite/source-tree output, checks raw
input pins/fixed errors and verifies no input mutation or target artifacts. A connected
invented HVAC exercise reconciles two images/two annotations, analyzes polygon/rectangle
geometry (areas 800 and 1,600), explicitly adapts envelopes to exact normalized boxes,
round-trips those boxes and reviews the pinned handoff. A separate game-box CLI checks
invented hitbox fractions. Counterexamples prove reference consistency is not polygon
validity and a pinned approval does not establish geometric/image alignment.

These are functional synthetic checks of declarations, not authentic image bytes,
actual object boundaries, correct labels, reviewer identity, privacy clearance,
publication/export rights, COCO/YOLO compatibility or production suitability. No original
private code, schemas, policies, assets, annotations, models, datasets or configuration
was consulted or selected. No image access, rasterization, repair, training or export.
