# Fictional transfer walkthrough

Extract the [Verified Transfers 0.1.0 source ZIP](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/verified-transfers-v0.1.0). Supply ordinary CPython 3.12, 3.13, 3.14 or 3.15; qualification selects 3.15.2 for that minor. Keep both runtime files adjacent in the flat extracted folder. The runtime uses only the standard library and native OS APIs. No administrator privilege, activation, account, execution-policy change or package installation is part of these commands. File/executable permissions and workplace policies still apply.

Choose an existing trusted private parent outside the extracted source, collection checkout and public/synchronized folders. All paths below are fictional placeholders; substitute the actual source, Python and private parent. Choose a new environment path. The optional no-pip environment does not install dependencies.

```powershell

& $py -I -B (Join-Path $source 'transfer.py') --help
```


The literal collection path `tools/verified-transfers` protects its collection root. This flat download protects its runtime directory. Outputs must also be new, have an existing parent and be disjoint from their selected source. This layout rule does not locate every Git checkout or provide a sandbox. Windows help has a fixed program name; POSIX help may include the invoked path. There is no `--version` feature.

## Run all thirteen examples unchanged

Save the following single Python block as `fictional_walkthrough.py` in your private parent. Run it with assertions enabled, as shown. It creates a new uniquely named workspace and retains five invented inputs: two tiny source files, two opaque state files and a reviewed inventory. It runs thirteen fresh CLI processes and checks whole JSON/stdout/stderr bytes, exit statuses, unchanged input/runtime bytes and exact output trees. It never executes the fictional `widget.py` payload.

For this exercise the reviewer authors the inventory directly and records its exact-byte hash before invoking `package`. A real inventory, including one generated by an external auditor, still needs independent ownership, privacy and license review. Do not accept a bundle's self-reported hash as independent authentication. Obtain and retain its expected manifest pin through a trusted channel.

The opaque fixture is invented stopped-state data. The stopped flags are operator assertions only: no process inspection, stop, service operation, application validation or consistency test occurs. Five successful operations return exit 0. Eight refusals return exit 2 with the complete fixed error object. Successful outputs include manifest hashes; this is not anonymization or encryption.

PowerShell:

```powershell
& $py -I -B (Join-Path $privateWork 'fictional_walkthrough.py') (Join-Path $source 'transfer.py') $privateWork
```

Ubuntu:

```sh
"$py" -I -B "$private_work/fictional_walkthrough.py" "$source/transfer.py" "$private_work"
```

```python
import hashlib
import json
import os
from pathlib import Path
import shutil
import subprocess
import sys
import tempfile

if not __debug__:
    raise RuntimeError("ASSERTIONS_REQUIRED")
assert len(sys.argv) == 3
script = Path(sys.argv[1]).resolve()
parent = Path(sys.argv[2]).resolve()
assert script.is_file() and script.name == "transfer.py"
assert parent.is_dir() and not parent.is_symlink()
assert not getattr(parent, "is_junction", lambda: False)()
runtime = {name: hashlib.sha256(script.with_name(name).read_bytes()).hexdigest()
           for name in ("transfer.py", "transfer_windows.py")}
work = Path(tempfile.mkdtemp(prefix="fictional-transfers-", dir=parent))
assert not work.is_relative_to(script.parent)
source = work / "reviewed-source"
state = work / "stopped-state"
source.mkdir()
state.mkdir()
source_bytes = {"README.md": b"# Fictional widget\nReviewed example source.\n",
                "widget.py": b"def label():\n    return 'fictional-widget'\n"}
state_bytes = {"counter.txt": b"7\n", "slot.dat": b"\x00\x01FICTIONAL-SLOT\xff\n"}

def rows(files):
    return [dict(path=name, size=len(data), sha256=hashlib.sha256(data).hexdigest())
            for name, data in sorted(files.items())]

def encoded(value):
    return (json.dumps(value, indent=2, ensure_ascii=True) + "\n").encode("utf-8")

def bundled(files, format_name):
    raw = encoded(dict(schema_version=1, format=format_name, inventory=rows(files)))
    pin = hashlib.sha256(raw).hexdigest()
    return pin, {"MANIFEST.json": raw,
                 "MANIFEST.sha256": (pin + "  MANIFEST.json\n").encode("ascii"),
                 **{"payload/" + name: data for name, data in files.items()}}

fixtures = {}
for root, files in ((source, source_bytes), (state, state_bytes)):
    for name, data in files.items():
        path = root / name
        path.write_bytes(data)
        fixtures[path.relative_to(work).as_posix()] = data
inventory_path = work / "reviewed-inventory.json"
inventory_bytes = encoded(dict(schema_version=1, inventory=rows(source_bytes)))
inventory_path.write_bytes(inventory_bytes)
fixtures[inventory_path.name] = inventory_bytes
# This pin is calculated from our independently authored, reviewed fixture bytes.
inventory_pin = hashlib.sha256(inventory_bytes).hexdigest()
source_pin, source_bundle = bundled(source_bytes, "reviewed-source-package-v1")
data_pin, data_bundle = bundled(state_bytes, "opaque-data-handoff-v1")
package = work / "new-source-package"
backup = work / "new-data-bundle"
restored = work / "new-restored-state"

def file_metadata(path):
    value = path.lstat()
    return (value.st_dev, value.st_ino, value.st_size, value.st_mtime_ns,
            value.st_birthtime_ns if os.name == "nt" else value.st_ctime_ns,
            value.st_nlink)

initial_metadata = {name: file_metadata(work / name) for name in fixtures}
refusal = dict(status="ERROR", code="TRANSFER_REFUSED_OR_FAILED",
               partial_destination="retained")
outcomes = []

def success(operation, files, format_name, pin):
    return dict(status="VERIFIED", operation=operation, format=format_name,
                files=len(files), bytes=sum(map(len, files.values())),
                manifest_sha256=pin)

def run(label, arguments, expected, exit_code=0):
    result = subprocess.run([sys.executable, "-I", "-B", str(script), *map(str, arguments)],
                            cwd=work, capture_output=True, timeout=30)
    expected_text = json.dumps(expected, sort_keys=exit_code == 0) + os.linesep
    assert result.returncode == exit_code, (label, result.returncode)
    assert result.stdout == expected_text.encode("utf-8"), label
    assert result.stderr == b"", label
    outcomes.append(dict(case=label, exit_code=result.returncode,
                         stdout=json.loads(result.stdout)))
    for name, data in fixtures.items():
        assert (work / name).read_bytes() == data, name
        assert file_metadata(work / name) == initial_metadata[name], name
    assert runtime == {name: hashlib.sha256(script.with_name(name).read_bytes()).hexdigest()
                       for name in runtime}

package_args = ["package", "--source", source, "--manifest", inventory_path,
                "--expected-manifest-sha", inventory_pin, "--destination", package]
run("package-reviewed-source", package_args,
    success("package", source_bytes, "reviewed-source-package-v1", source_pin))
run("verify-source-package", ["verify", "--bundle", package,
    "--expected-manifest-sha", source_pin],
    success("verify", source_bytes, "reviewed-source-package-v1", source_pin))
run("refuse-existing-package", package_args, refusal, 2)
run("refuse-wrong-review-pin", ["package", "--source", source, "--manifest", inventory_path,
    "--expected-manifest-sha", "0" * 64, "--destination", work / "not-created-source"], refusal, 2)
run("refuse-unconfirmed-backup", ["backup", "--source", state,
    "--destination", work / "not-created-backup"], refusal, 2)
run("backup-fictional-stopped-state", ["backup", "--source", state,
    "--destination", backup, "--confirm-stopped"],
    success("backup", state_bytes, "opaque-data-handoff-v1", data_pin))
run("verify-data-bundle", ["verify", "--bundle", backup,
    "--expected-manifest-sha", data_pin],
    success("verify", state_bytes, "opaque-data-handoff-v1", data_pin))
restore_args = ["restore", "--bundle", backup, "--destination", restored,
                "--expected-manifest-sha", data_pin]
run("refuse-unconfirmed-restore", restore_args, refusal, 2)
run("restore-new-destination", [*restore_args, "--confirm-stopped"],
    success("restore", state_bytes, "opaque-data-handoff-v1", data_pin))
run("refuse-existing-restore", [*restore_args, "--confirm-stopped"], refusal, 2)
run("refuse-wrong-bundle-pin", ["verify", "--bundle", backup,
    "--expected-manifest-sha", "0" * 64], refusal, 2)
run("refuse-source-package-restore", ["restore", "--bundle", package,
    "--destination", work / "not-created-source-restore", "--expected-manifest-sha",
    source_pin, "--confirm-stopped"], refusal, 2)
tampered = work / "tampered-copy"
shutil.copytree(backup, tampered)
(tampered / "payload" / "counter.txt").write_bytes(b"8\n")
run("refuse-tampered-payload", ["verify", "--bundle", tampered,
    "--expected-manifest-sha", data_pin], refusal, 2)

expected_tree = dict(fixtures)
for prefix, files in ((package.name, source_bundle), (backup.name, data_bundle),
                      (restored.name, state_bytes), (tampered.name, data_bundle)):
    expected_tree.update({prefix + "/" + name: data for name, data in files.items()})
expected_tree[tampered.name + "/payload/counter.txt"] = b"8\n"
actual_tree = {path.relative_to(work).as_posix(): path.read_bytes()
               for path in work.rglob("*") if path.is_file()}
assert actual_tree == expected_tree
assert not list(work.rglob("*.pyc")) and not list(work.rglob("__pycache__"))
assert len(outcomes) == 13
print(json.dumps(dict(outcomes=outcomes, fixtures_preserved=5,
                      expected_files=len(expected_tree), unexpected_files=0,
                      runtime_bytes_preserved=True), sort_keys=True, indent=2))
```

The retained workspace has exactly nineteen files: five input fixtures, two four-file bundles, a two-file restore and a four-file deliberately tampered copy. The tampered copy changes only its own counter payload. The source, original bundle, restored data, reviewed inventory and runtime bytes stay unchanged. No bytecode or other application files are accepted. The three refused new destinations are absent.

A handled error reports `partial_destination: "retained"` even when refusal occurred before creating one. Actual late I/O failure or interruption may retain an unconfirmed partial destination; these thirteen examples do not inject such a failure. Do not use that output as a verified backup. Keep it private and choose a different new destination for a retry. The tool never cleans up, overwrites or rolls back your files. Native failure/partial-output controls are covered separately by the qualification suite.

Review [qualification](docs/QUALIFICATION.md), the historical [I/O guide](IO-SAFETY.md) and [private workspace guidance](docs/PRIVATE-WORKSPACE.md) before applying the method. Use one operator with trusted stable local files. Sampled I/O checks are not atomic snapshots, a hostile-filesystem sandbox, encryption or real application-consistency proof.
