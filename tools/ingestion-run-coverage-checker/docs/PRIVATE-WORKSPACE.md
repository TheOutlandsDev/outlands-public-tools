# Private ingestion run coverage review

Select one stable ordinary JSON snapshot with explicit expected batches and receipt declarations. The accepted expected cohort must be nonempty; sequence positions need not be contiguous. Every accepted expected batch ID needs an exact healthy committed receipt. Extra accepted receipt groups are unexpected. Any malformed/conflicting/alias/stream/outcome/count/metadata or missing/unexpected receipt issue withholds all declared_totals and makes cohort_complete false. Positive resolved counters alone do not establish cohort completeness. There are no checkpoint-window or advancement semantics.

Issue-free totals sum embedded source-count declarations once per unique matched batch. Batch-list duplicates are separate from declared source-row duplicates. The tool observes supplied JSON-list grouping and accounting; it does not load source records or referenced source/map/preview/receipt bytes, recompute source-record counts, authenticate commits, verify actual store contents or establish exactly-once execution. No ingestion run, import, retry, repair, database/journal update or network action is performed.

Reports retain list/resolution counters, issues, input fingerprints and either declared source totals or null. Real inputs and reports are private and are not anonymized. Use fully spelled stable ordinary paths under trusted quiescent parents. Output needs a fresh external name under an existing parent. Native linked/multilink paths are refused. Windows creation uses CREATE_NEW and OPEN_REPARSE_POINT and refuses existing leaves, including dangling entries. Failed writes may retain unconfirmed partial output; inspect privately and select a fresh name. Parent ACLs are inherited. Cooperative limits and sampled metadata do not establish an atomic snapshot, hostile-writer containment, transactional rollback, OS sandbox or hardware durability.

Only generic source and two invented JSON examples are published. Private expected/receipt histories, source records, generated reports, SDKs, credentials and raw evidence remain local. Obtain Python separately. Qualification does not establish business approval, complete external history or production ingestion safety.
