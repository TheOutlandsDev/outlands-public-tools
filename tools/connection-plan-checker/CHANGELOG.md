  loopback-binding checker, retaining its schema, tuple conflicts, ordering,
  fixed errors, displayed version and MIT license.

  distinguish declaration equality from actual socket reuse/bind behavior,
  port availability, connection success and operational acceptance.

  source ZIP/build-manifest reproduction and optimized-helper refusal. Actual
  outcomes belong to release validation.
- Preserve all 41 original test method ASTs, 103 assertion calls and nine required
  original/shared helper ASTs with explicit canonical field encoding. The
  adapter retains only needed scaffolding without unrelated applications;
  one original ROOT-relative subprocess method uses an owned test-only runtime
  mirror with pre/post exact hashes. Copied CLI consumers use one script; no
  duplicate runtime, donor or unrelated application is shipped.
- Preserve runtime and both fictional JSON examples at exact baseline Git
  bytes. Path components remain checked after absolute-path normalization;
  measured Windows leaf dot/space and parent-dot acceptance, with parent-space
  refusal, is disclosed. No suffix/alias fix or runtime listener check is added.

No interpreter/dependency binary, actual plan/result, operational record,
private original source or raw diagnostic log is part of the source ZIP.
