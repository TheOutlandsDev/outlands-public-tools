# Provenance and license scope

Connection Plan Checker is a fresh neutral implementation of selected
owner-reported connection-planning methods. It accepts only a bounded neutral
loopback binding declaration, not private launcher, firewall/policy, diagnostic,
vendor networking or operating-configuration formats.

The runtime and two fictional JSON controls retain exact Git bytes from baseline
`379045c6755a747c9eaa62dad9f3babe9d06e7d3`. The runtime already displayed version
0.1.0. Standalone packaging introduces no tuple/result, socket/bind/availability
check or input-path repair. New source attributes preserve reviewed bytes;
no normalization is used to make protected hashes pass.

All 41 original method bodies, 103 assertion calls and nine original/shared
helper ASTs remain preserved. Explicit `python-ast-fields-json-v1` encoding
retains full AST fields for stable comparison across supported Python versions,
without weakening within-version equality. The adapter retains only needed
shared `Fixture`/`load` scaffolding, selects the extracted checker/script and
avoids unrelated applications. One original ROOT-relative subprocess method
requires an owned test-only hierarchy containing an exact extracted runtime
copy. Its hash is verified before and after testing; in-process imports remain
the actual extracted module. Copied CLI tests independently use one copied
script. No donor, duplicate shipped checker or unrelated application is required.

Canonical helper keys retain source provenance: `local:binding`, `local:plan`,
`local:changed_stat`, `local:PlanFixture.metadata`, `local:PlanFixture.invoke`,
`local:PlanFixture.reader_failure_traceback`, `shared:load`,
`shared:Fixture.setUp` and `shared:Fixture.write`.

Selected source, tests, examples and docs retain the full [MIT license](../LICENSE)
and TheOutlandsDev identity. Standalone preparation, qualification, documentation
and authored fictional consumers used AI assistance without exclusive-authorship
claims. Python/standard-library and OS mechanisms retain their own terms and
are not bundled as binaries. The license grants no rights in operator inputs
or third-party material; an owner's statement and fresh implementation do not
independently resolve ownership of all historical material.

Original operational launchers, policy installers, collectors, configurations,
source mappings, keys, credentials, identities, private endpoints and captured
records are excluded. No original private implementation is copied or executed.
Only authored fictional declarations ship; actual controls/results and
operational evidence remain private. Unrelated rights/future exports are uncleared.

Repeated exact transport/address/port declarations are metadata conflicts,
not proof of socket exclusivity, reuse, dual-stack behavior, port availability,
listener startup, connection success or safe configuration. Four result flags
remain false. IDs/check order/conflict relationships can identify a design even
though binding transport/address/port fields are omitted.

Path checks occur after absolute-path normalization; no original-component
suffix guard is added. Fictional Windows probes on Python 3.12.7/3.15.2 accepted
canonical, leaf-dot, leaf-space and parent-dot spellings with exit 0, while
parent-space returned exit 2/`INPUT_PATH_INVALID`, preserving input/runtime
bytes. Use canonical trusted paths; mixed observations are distinct from
hostile-filesystem/alias guarantees or a blanket suffix-refusal claim.
