# Offline Outbound Event Identity and Lot Allocation Checker

Compute the event identity for a saved revision hash, order row ID and version. Read paired lot IDs and quantities, preserving their order and rejecting ambiguous values.

See the [usage guide](SETUP.md) for a fictional example and the [GitHub release](https://github.com/TheOutlandsDev/outlands-public-tools/releases/tag/outbound-event-identity-allocation-checker-v0.1.0) for the source ZIP, checksum and qualification records.
