# Changelog

## 0.1.0

- Initial standalone source ZIP for the existing single-script supported-lock
  comparator, retaining its CLI, narrow grammar, version-text/hash comparison
  semantics and MIT license. The runtime already displayed version 0.1.0.
- Self-contained fictional walkthrough checks complete matching/equivalent,
  version-text, hash-only, mixed-change and fixed-error JSON/exit outcomes,
  preserving locks, extras, pre-existing output and runtime bytes.
- Qualification selects fresh Windows/Ubuntu Python 3.12, 3.13, 3.14 and 3.15.2
  environments without pip or installed distributions, independent committed-
  source ZIP/build-manifest reproduction and optimized-helper refusal. Actual
  outcomes belong to release validation.
- Retained all 41 original test method bodies and their validator-parity helper.
  Two pinned public test-only validator files support parity without becoming
  CLI dependencies. Copied CLI consumers add exact native/platform contracts.
- Preserved original `.gitattributes` and all five example files byte-for-byte,
  including BOM/line endings; no private real locks or artifacts were selected.

No interpreter/dependency binary, actual dependency/environment configuration,
package artifact, original private source or raw log is part of this source ZIP.
